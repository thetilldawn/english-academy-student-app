# 인증 E2E 작업 안내

- `public/`은 로그인이 필요 없는 읽기 검사만 둔다. DB 쓰기나 비밀값을 사용하지 않는다.
- `authenticated/`는 승인된 고정 Preview와 가짜 학생만 사용한다. Production 주소와 DB는
  `support/environment.ts`에서 먼저 거부하고 `/api/preview-identity`의 실제 배포 환경·DB·호스트도 대조한다.
- 인증 쓰기 시나리오는 `authenticated-preview` 실행 묶음에서 한 번만 순차 실행한다. 360·768·1440
  화면 검사는 쓰기를 반복하지 않고 공개 또는 이미 만들어진 화면의 읽기 검사로 분리한다.
- 가짜 학생은 관리자 공개 API로 만들고, 학생 코드가 로그·첨부·영수증에 들어가지 않게 한다.
- 학생 ID를 받은 즉시 `test-results/e2e-manifests`에 기록한다. 정상 종료와 별도 복구 단계 모두 해당
  실행이 만든 정확한 학생 ID만 관리자 삭제 API로 정리한다. 시험·포인트·
  오답 감사 이력은 제품 정책대로 보존하며, 정리가 실패하면 작업을 완료로 보고하지 않는다.
- `support/`는 환경 차단·브라우저 품질 검사처럼 여러 시나리오가 공유하는 도구만 둔다. 업무 흐름은
  기능별 spec에 둔다.
- `page.waitForTimeout()`으로 정상 동작을 추측하지 않는다. URL, 응답, 접근 가능한 상태 문구 또는
  제한 시간이 있는 재조회로 완료를 확인한다.
