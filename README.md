# 영어 학습실

선생님이 학생·접속코드·시험범위를 직접 관리하고, 학생은 회원가입 없이 전달받은 코드로 단어시험을 푸는 앱입니다.

## 현재 구현

- 관리자 이메일·비밀번호 로그인
- 학생 생성과 12자리 접속코드 발급·재표시·교체·즉시 차단
- 학생 코드 인증 뒤 180일 HttpOnly 쿠키 유지
- 코드 교체·차단 시 해당 학생의 기존 접속 전부 무효화
- 학생별 단어시험 범위·문항 수·제한시간·통과점수·재시험 허용 설정
- 영어→한글 / 한글→영어 4지선다 50:50
- 문항별 즉시 피드백, 첫 풀이 오답만 1회 재풀이
- 최초 점수·재풀이 후 점수·미해결 단어와 문항별 결과
- 능률 VOCA 어원편 고등 2025개정 3,001행 가져오기 드라이런

필수형용사 500은 구조화된 검수본이 아직 없어 데이터셋만 `검수 대기`로 남겼습니다.

## 로컬 확인

```powershell
npm install
npm run verify
npm run dev
```

실제 Supabase 연결값과 비밀키는 `.env.local`에만 둡니다. 실제 학생정보와 어휘 원본·검수본은 Git에 들어가지 않습니다.
