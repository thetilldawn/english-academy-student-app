# 기능 작업지시서 양식

복사 위치: `docs/work-orders/<APP-번호>.md`. 절차는 [개발 기준](../개발_지시서와_검증_기록.md).
상태·우선순위를 별도로 선언하지 않고 루트 대장의 해당 번호를 참조한다.

## 공통 머리말

- 작업 번호 / 사용자 요청 출처 / 기존 보완·새 기능·대체·우선순위 변경:
- 확정된 범위 / 하지 않을 일 / 로컬·DB·배포 권한 경계:
- 코드 기준 커밋·브랜치 / 설치 Next·React 버전 / 참조한 공식 문서와 확인일:
- 가까운 AGENTS·기능 소유자·흐름 지도 / JSON 기록 위치 / 검증 설명 위치:

|---|---|---|---|

- 변경/확인만/해당 없음과 이유: 경로, UI, 상태, 계산, 데이터, API, 캐시, 비동기 화면, 보안, 스타일, 검사.

  아래 공통 상태표에 유지할 부품·실제 쉬운 문구·복구 행동과 회귀 T번호를 적는다.
- 미결정 D번호와 출처 또는 기존 합의: 하나라도 남으면 기능 전체 구현 보류.
- 검사 사례·예상 결과·복구 방법. 브라우저 확인 필요 여부와 이유.

작은 수정은 위 내용으로 축약하되 JSON의 영향·검사 연결은 생략하지 않는다.

## 공통 상태·문구·검사 연결표 — 작은 수정도 필수

원요구 4번은 데이터·API·기능 검사와 오류·대체 화면의 실제 표시를 함께 설계하라는 요구다.
판정/문구/Next.js 경계 기준은 [개발 기준 3절](../개발_지시서와_검증_기록.md)을 따른다.

| R번호·상태 | 발생 조건·응답 계약(trigger) | 표시 위치·공용 부품(component)·동작(behavior) | 실제 쉬운 한국어 문구(message) | 보존·복구 행동(recovery) | 검사 T번호·예상 결과 |
|---|---|---|---|---|---|
| R… / 초기 대기·갱신 | | | | | |
| R… / 미입력·미선택 | 필수인지 선택값인지, 빈 검색어의 의미 | | | | |
| R… / 정상 빈 결과 | 현재 조건으로 성공한 0건인지, 선택 필드 null인지 | | | | |
| R… / 입력 오류 | 필수값 누락·유효하지 않은 값 | | | | |
| R… / 조회 실패 | 첫 조회·갱신·이전 0건 뒤 새 검색 실패 | | | | |
| R… / 저장 실패 | 실패 확정인지 결과를 모르는지 | | | | |
| R… / 인증·권한 실패 | | | | | |
| R… / 404 | 주소/대상 없음과 통신 실패 구분 | | | | |
| R… / 예상 밖 예외 | | | | | |

- 쉬운 문구 검토: 무엇이 안 됐는지·다음 행동이 이해되는가? 영어 오류 원문·개발 용어·확인 못한 원인 단정은 없는가?
- 실패와 `없음` 동시 표시 금지, `검토 중`으로 실패 숨김 금지, 재시도 성공·입력 보존·늦은 응답을 T에 연결한다.
- `error-ui`는 상태/복구, `ui-copy`는 실제 문구/버튼 검사를 뜻한다. 한 T에 두 주제를 넣어도 사례는 각각 적는다.
- 해당 없음은 이유와 기존 계약을 적는다. 문서·내부 도구만 바꾸는 경우 전체 표 제외 이유를 영향표에 적는다.

## 결정과 기준 변경

| D번호 | 미결/확정·사용자/내부 | 질문·권장안·대안·영향 | 답변·결정 출처 |
|---|---|---|---|
| D1 | | | |

- 사용자 미결정이 있으면 기능 전체 보류. 질문을 모아 플랜 모드에서 답변받은 뒤 기록하고 착수한다.
- 새 기준: 기존 기준으로 해결 못하는 이유 / 대안 / 영향 소비자 / 검사 / 복구 / 채택 출처.
- 기준 S번호별 제안·채택·구현·검증·폐기와 근거 버전을 구분한다.
- 필수 요구 제외는 이유와 해당 결정 D번호가 필요하다. 내부 판단으로 사용자 요구를 제외하지 않는다.

## 설계 관문

- R↔소유자/흐름/파일↔설계↔T 연결, 영향표 모든 행, 사용자 미결정 0을 확인한다.
- 예정 파일·흐름은 명시한다. 완료 때 실제 등록·연결로 바뀌어야 한다.
- 실행할 단위/컴포넌트/통합/권한/자료·정답 노출/캐시/실패/구조/빌드 및 화면 검사를 정한다.
- R→발생 조건→상태/부품→실제 문구→복구→T가 비어 있으면 설계 미완료다. 404와 쉬운 문구 검사를 빠뜨리지 않는다.
- 설계 검사 결과와 자체 검토 근거를 기록한다. 이것은 구현·검증 완료가 아니다.
