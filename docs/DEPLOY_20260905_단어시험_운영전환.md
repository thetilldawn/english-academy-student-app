## 자료 상태와 실제 운영 권한

원본 파일의 `target_environment: preview`와 `production_apply_allowed: false`는 파일 제작
당시 상태이며 기존 해시·검토 근거를 보존한다. 실제 운영 사용은
`private.simseok_production_approvals_v1`의 정확한 여섯 자료와
`private.simseok_production_receipts_v1.status=active`로 별도 허용한다. 공용 사전 승인으로
해석하지 않는다. 이전 고1 3·4과와 일반 사전 shadow 문항은 운영 승인에 포함하지 않는다.

자료 가져오기는 `scripts/import-simseok-production.ts`로 먼저 쓰기 없는 검사를 하고,
`--apply --approval DEPLOY-20260905-01 --expected-project-ref xdxhswjgksukjmpbzqgz`를
명시한 경우만 운영에 숨김 상태로 저장한다. 여섯 묶음·발음 보완을 재검산한 뒤
`activate_approved_simseok_production_v1()`로 함께 공개한다. 동일 파일 재실행은 쓰기 0건이다.

영영풀이·예문 시험의 현재 지원 범위는 날짜 없는 단일 회차다. 날짜 없는 여러 회차 분할은
일반 영어↔뜻 경로에서 지원한다. 패러프레이징 앱, 전체 사전 정제, 자이 7회 37→36번 후보
재분류는 이번 릴리즈에 임의로 섞지 않는다.

## 전환과 복구

기존 운영 RPC 권한 회수부터 호환 함수 설치까지 중간 장애가 없도록 DB 변경 묶음은 한
거래로 실행한다. 이미 적용한 파일과 예약 작업은 제외하고, 원본 각 파일의 최상위
BEGIN/COMMIT만 검증해서 제거한다. 원본 migration은 수정하지 않는다. 개별 파일 SHA와
묶음 SHA를 로컬 배포 기록에 남긴다.

이전 운영 배포는 보존한다. 복구 때 앱만 이전 운영 판본으로 돌려도 구 public RPC가 최신
검증 경로로 동작한다. 학생 데이터를 지우는 DB 일괄 되돌림은 하지 않는다.
