## 남은 서버키 상태

기존에 제공된 Supabase 서버키는 Supabase API에서 `Invalid API key`로
거부됐다. 이 키는 Vercel에 등록하지 않았다. 관리자 로그인 자체는
공개키 기반 Auth와 관리자 프로필 검증으로 복구됐지만, 서버 권한이
필요한 학생 코드 로그인·일부 상세 기능·어휘 실제 적재 전에는 유효한
서버키가 필요하다.
