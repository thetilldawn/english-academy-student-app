# 보안 및 시험 규칙

## 학생 접속

- 공개 학생 회원가입은 없다.
- 관리자가 학생을 만들면 혼동 문자를 뺀 12자리 코드가 생성된다.
- 검색용 코드는 HMAC으로, 다시 보여줄 코드는 AES-256-GCM으로 따로 저장한다.
- 성공한 학생 접속에는 256비트 임의 세션 토큰을 발급한다.
- 운영 쿠키는 `Secure`, `HttpOnly`, `SameSite=Lax`, `Path=/`, 180일이다.
- 코드 교체·차단은 코드 세대를 올리고 기존 학생 세션 전체를 즉시 폐기한다.
- 로그인 실패 제한은 DB 트랜잭션 안에서 코드별 5회/15분, IP별 10회/15분으로 적용한다.

## 관리자

- Supabase Auth에서 직접 만든 관리자만 로그인한다.
- `admin_profiles`에서 활성 상태인 계정만 관리화면을 사용할 수 있다.
- 브라우저 관리자에게 공개 테이블 직접 쓰기 권한을 주지 않는다.
- 학생 생성·코드 교체·차단·시험 배정은 검증된 RPC로만 변경한다.
- 학생코드 열람은 캐시하지 않고 감사기록을 남긴다.

## 단어시험

- 출제 범위와 학생은 관리자가 정한다.
- 기본 방향은 영어→한글과 한글→영어 50:50이다.
- 각 문항은 서로 다른 보기 네 개를 사용한다.
- 같은 한글 뜻이 여러 영어 단어의 정답이 되는 경우 한글→영어 문항에서 제외한다.
- 같은 표제어가 범위에 여러 번 있으면 가장 앞 원본 행을 출제 기준으로 사용하되 원본 행 자체는 삭제하지 않는다.
- 첫 시험에서는 문항마다 즉시 정답 여부를 보여준다.
- 첫 시험이 끝나면 결과와 틀린 단어를 먼저 보여주고, 학생이 `재시험 시작`을 눌렀을 때만 오답을 순서대로 한 번 더 푼다.
- 결과 검토 화면에는 제한시간을 적용하지 않는다. 재시험을 시작하면 첫 시험과 같은 단계별 제한시간을 새로 부여한다.
- 통과 여부는 최초 점수를 기준으로 판단한다.
- 재시험에서 맞힌 단어와 끝까지 틀린 단어는 별도로 기록한다.
- 제한시간이 끝나면 미응답을 포함해 결과를 확정하고 시험을 종료한다. 미응답 단어는 점수에는 오답으로 포함하되, 실제로 한 번도 답하지 않은 단어는 누적 오답장에는 넣지 않는다.
- 같은 학생·같은 배정에는 진행 중 시험을 하나만 허용한다.
- `응시 시작 마감`은 새 시험을 시작할 수 있는 마지막 시각이다. 마감
  전 또는 마감 없음 상태의 무응시는 `응시 전`, 마감 시각과 같거나
  지난 무응시는 `미응시 마감`으로 파생한다.
- `미응시 마감`은 배정-학생 연결에서 계산하며 가짜 응시 행을 만들지
  않는다.
- 마감 전에 이미 시작한 첫 시험·재시험은 각 단계의 제한시간을
  따르고, 첫 시험 결과 검토 단계는 배정 마감 뒤에도 자동 종료하지
  않는다.
- 종료 시각이 지난 실제 응시는 service-role 전용 일괄 확정 함수가
  initial·retry 단계만 잠그고 `시간 종료`로 확정한다. review 단계는
  대상에서 제외한다.
- 배정 삭제로 미응시 이력이 사라지지 않도록 배정-학생 외래키는
  `RESTRICT`를 사용한다. 학생은 삭제하지 않고 접속 차단으로
  비활성화한다.

## 자료 경계

- 어휘 원본 엑셀과 PDF는 `영어/` 자료 영역에 둔다.
- 앱 Git에는 원본 교재·실제 학생정보·실제 성적 내보내기를 넣지 않는다.
- `data/import/`는 로컬 검수·가져오기용이며 Git에서 제외한다.
- Supabase Secret key와 암호화 키는 `.env.local`과 배포 환경변수에만 둔다.
# 오답 이력과 표시 기준

- `student_vocab_state.unresolved_wrong_count`는 현재 미해결 상태이며 누적 오답 이력으로 사용하지 않는다.
- 완료 또는 시간 종료된 시험에서 학생이 실제 제출한 오답만 `student_vocab_wrong_events`에 불변 이벤트로 기록한다.
- 첫 시험 오답은 1회, 재시험에서 다시 제출한 오답은 추가 1회로 센다. 미응답은 오답 횟수에 포함하지 않는다.
- 이벤트는 `(quiz_question_id, wrong_stage)`로 중복 기록을 막으며, 완료 처리나 만료 처리가 반복되어도 횟수가 다시 증가하지 않는다.
- 각 문항은 응시 생성 시점에 이전에 완료된 시험의 누적 오답 횟수를 `prior_wrong_count`로 고정한다. 현재 시험이나 동시에 진행 중인 다른 시험의 답변으로 표시가 바뀌지 않는다.
- 검증된 정규 어휘 연결이 있으면 `canonical_lexeme_id_snapshot`으로 과거 occurrence를 잇고, 연결이 없으면 같은 `vocab_entry_id`만 사용한다.
- 학생 화면에는 누적 횟수를 0, 1, 2 이상으로 줄인 단계만 전달한다. 정답 번호나 과거 선택지는 전달하지 않는다.
