## 관리자 응답 제한 보완

- Proxy, 관리자 인증, 관리자 내역 읽기에 요청 ID와 단계별 소요시간 기록을 연결했다.
- 관리자 인증은 5초, 관리자 대화형 요청 전체는 7초, 내역 읽기는 7초 안에 끝나도록 했다.
- Supabase가 중단 신호 뒤 내부 재시도를 계속하는 경우에도 바깥 Promise가 즉시 끝나도록 했고,
  제한시간으로 취소된 인증 fetch는 재시도하지 않는 `408` 응답으로 바꿨다.
- 관리자 권한 검사는 생략하지 않았고 쓰기·답안 저장 경로에는 이 읽기용 fetch를 연결하지 않았다.
- 관리자 상위 오류 화면을 추가해 제한시간·설정 오류가 무한 로딩 대신 재시도 가능한 화면으로 간다.
- 승인된 Preview 공개 연결값으로 로컬 production 서버를 재현했을 때 내역 하드 새로고침은 약
