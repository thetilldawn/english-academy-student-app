# 학습 관리·학생 중심 개편 계획 v2

- 기준일: 2026-08-07
- 작업 기준: `redesign` Preview
- 상태: 1차 UI 구현 완료, 독립 검수·일괄 배정·학습 자료 스키마 대기
- 운영 원칙: Preview의 staging 데이터만 사용하고 사용자 확인 전 `main`에 병합하지 않는다.

## 1. 먼저 확인된 현재 상태

### 2025 장문독해 단어장

- 현재 Preview에 보이는 `고3 장문독해 2025-03 검토본`은
  `pending_review` 자료다.
- 원문·뜻·출처 occurrence를 확인하기 위한 검토본이며, 단어 사전 ID와
  승인된 뜻·발음 연결이 끝나지 않아 `ready` 시험 자료가 아니다.
- 따라서 현재 상태로는 실제 단어 시험을 배정할 수 없다.
- 시험에 쓰려면 다음 순서가 필요하다.
  1. 2025 전체 항목을 기존 단어 사전과 연결
  2. 문맥 뜻·구동사·숙어·의도적 오류를 최종 판정
  3. 뜻과 발음 승인
  4. 앱 import 패키지 생성
  5. staging 적재
  6. 최소 4문항과 실제 범위 시험 배정·응시 검증

### 현재 관리자 화면의 구조 문제

- `/admin/assignments`에 검토용 단어장, 학생 선택·배정, 시험 원본 삭제,
  학생별 배정·내역이 서로 다른 기준으로 위아래 연결되어 있다.
- `시험별 관리`와 `배정 관리`는 사용자 입장에서 구분 기준이 불명확하다.
- 학생 모달은 `내역 / 오답 / 관리` 순서이고, 탭별 높이가 달라 창이
  계속 움직인다.
- 학생 관리와 시험 관리가 서로 다른 카드·정렬·상태 표시를 사용해 같은
  학생과 시험을 두 화면에서 다르게 읽게 된다.
- 모바일은 정보 묶음마다 선을 추가해 PC·태블릿과 다른 구조로 보인다.

## 2. 관리자 정보 구조

전역 네비게이션은 다음 네 영역으로 유지하되 이름을 바꾼다.

1. `Overview`
2. `학생 관리`
3. `학습 관리` — 기존 `시험 관리`
4. `내역`

각 페이지의 반복되는 영문 eyebrow·큰 제목·설명 문단은 제거한다. 본문
첫 줄에는 현재 위치를 짧은 breadcrumb로 표시한다.

```text
Overview
학생 관리
학습 관리 / 단어
학습 관리 / 다른 학습
내역
```

PC·태블릿·모바일 모두 같은 정보 순서를 사용하고, 화면 폭에 따라 열만
접는다. 모바일에서만 별도 구분선을 반복해 넣지 않는다.

## 3. 학습 관리 화면

### 최상단 탭

- 페이지에 들어오자마자 `단어 / 다른 학습` 탭이 가장 먼저 보인다.
- `단어`는 현재 기능을 제공한다.
- `다른 학습`은 지문·문법·모의고사 구조가 확정될 때까지 빈 상태와
  후속 안내만 표시한다.
- `단어장 검토` 패널은 학습 관리에서 제거한다. 수정·승인 기능이 없는
  읽기 전용 검토 자료를 운영 동선에 섞지 않는다.

### 검색과 필터

- `학생 선택` 제목과 설명은 제거한다.
- 돋보기 아이콘이 있는 검색창 하나에서 이름·학교·학년·단어장을 모두
  검색한다.
- 검색창 아래 `필터` 아코디언을 두고 다음 그룹을 각각 태그 선택으로
  제공한다.
  - 오답 유무: 전체, 오답 있음, 2회 이상 오답, 재시험 필요
  - 학교별
  - 학년별
  - 단어장별
- 선택한 필터는 아코디언을 닫아도 검색창 아래 활성 태그로 남긴다.
- `초기화`와 결과 학생 수를 같은 줄에 둔다.

### 학생 중심 목록

시험 원본 목록과 학생별 배정 목록을 따로 세로 배치하지 않는다. 화면의
기본 행은 학생 한 명이다.

각 행은 고정된 열 순서를 사용한다.

1. 이름
2. 학교·학년 태그
3. 현재 학습 자료 태그
4. 다음 할 일 또는 배정 상태
5. 마감 또는 최근 종료 시각
6. 상태·점수
7. 우측 동작

행 전체 클릭 또는 `보기`는 학생의 학습 상세를 연다. 우측 동작은 상태에
따라 다음처럼 제한한다.

| 상태 | 행 동작 |
|---|---|
| 배정 전 | 배정 |
| 미응시·응시 시작 전 | 수정, 배정 취소 |
| 응시 중 | 보기만 가능 |
| 완료·미통과·미응시 마감 | 내역 보기, 내역 삭제 |
| 배정 취소 | 내역 보기, 내역 삭제 |

- `전체 시험 취소`, `시험 전체 삭제` 문구는 기본 목록에서 제거한다.
- 여러 학생에게 묶여 있던 내부 시험 원본은 화면의 주 관리 단위로 쓰지
  않는다. 학생별 배정을 모두 취소·삭제한 뒤 서버가 사용하지 않는 원본을
  정리하거나 보관한다.
- 완료·미응시 마감 후에는 수정 버튼을 표시하지 않는다.
- `내역 삭제`는 목록 표시만 숨기며 성적·오답·감사 원본은 보존한다.

### 기본 정렬

학습 관리와 학생 상세의 시험 목록은 같은 비교 함수를 사용한다.

1. 마감 없는 미완료 배정 — 오래 배정된 것부터
2. 마감 있는 미완료 배정 — 가까운 마감부터
3. 응시 중 — 시작한 시각이 오래된 것부터
4. 미응시 마감·미통과·재시험 필요 — 상태가 확정된 최신순
5. 통과 완료 — 완료 최신순
6. 취소·삭제 표시 내역 — 처리 최신순

Overview는 이 전체 정렬을 그대로 복사하지 않고, 조치 중요도에 따라
`미응시 마감 → 미통과·재시험 필요 → 임박 → 마감 없음`만 보여준다.

## 4. 일괄 배정

- 기본 선택은 0명으로 두어 실수로 필터 결과 전체에 배정하지 않게 한다.
- 각 학생을 직접 체크할 수 있고 `현재 필터 결과 전체 선택`을 별도
  동작으로 제공한다.
- 하단 고정 작업 바에는 선택 인원과 다음 동작만 표시한다.
  - `단어 시험 배정`
  - `오답 재시험 배정`
  - 선택 해제
- 같은 설정을 선택 학생 전원에게 적용하되, 각 학생의 `다음 범위`는
  학생별 진도에서 계산한다.
- 학생별 다음 범위가 서로 다르면 최종 확인에 학생별 범위를 표로 보여준다.
- 범위를 강제로 동일하게 덮어쓰는 동작은 별도 선택일 때만 허용한다.
- 일괄 생성은 학생 수만큼 브라우저 요청을 반복하지 않고 서버 트랜잭션
  하나로 처리한다. 한 명이라도 생성 불가하면 생성 전 오류 목록을 먼저
  보여준다.

## 5. 학생 관리와 학생 상세 모달

### 학생 목록

- 학생 관리도 학습 관리와 같은 학생 행·태그·상태 컴포넌트를 재사용한다.
- 학생 추가는 목록 위의 간결한 동작으로 유지한다.
- 학교·학년을 강제로 카드 그룹 제목으로 반복하지 않고 필터와 태그로
  탐색한다.

### 고정 크기 모달

- 모달 바깥 크기는 탭에 따라 바뀌지 않는다.
- 데스크톱·태블릿은 `height: min(760px, calc(100dvh - 32px))` 수준의
  고정 작업면을 사용하고, 모바일은 전체 화면형 작업면을 사용한다.
- 학생명·학교·학년과 탭은 상단에 고정한다.
- 탭 본문만 스크롤한다.
- 모달 상단의 반복 eyebrow와 설명 문단은 제거한다.

탭 순서는 다음으로 변경한다.

1. `학습 관리` — 기본 탭
2. `계정 설정`
3. `내역` — 맨 오른쪽

기존 오답 화면은 독립 탭이 아니라 `학습 관리 > 단어`의 상태·상세로
통합한다.

### 학습 관리 탭

상단에는 학생의 활성 학습 자료를 분류별로 보여준다.

- 주 단어장 1개
- 시험 대비 단어장 여러 개
- 교과서 범위 여러 개
- 부교재 범위 여러 개
- 모의고사·지문 범위 여러 개

표시 예:

```text
[주 단어장] 능률 VOCA 어원편
[시험 대비] 마석중 3-1 중간 대비 단어
[교과서] 천재(이) [2015] 3,4,Sp
[부교재] 12-18쪽
[모의고사] 2025 고3 6월 31-40번
```

학습 자료 블록 우측의 빈 원형 `+` 버튼은 호버·포커스 때만 색이 채워진다.
누르면 페이지를 이동하지 않고 모달 내부 작업면이 오른쪽에서 왼쪽으로
전환된다. 전환 화면 상단에는 뒤로가기 아이콘과 다음 제목을 둔다.

- `단어 학습 관리`: 다음 범위 시험 배정, 틀렸던 단어 포함, 오답만 보기
- `지문 학습 관리`: 차후 지문·해석·문법 과제와 시험 배정

기본 화면 아래에는 최근 숙제·시험 5개만 표시한다. `전체 보기`를 누르면
같은 모달 본문 안에서 나머지를 스크롤한다. 목록 데이터·정렬·상태 동작은
학습 관리에서 해당 학생으로 필터한 결과와 동일하다.

### 계정 설정 탭

- 이름·학교·학년 수정
- 접속 코드 보기·공유·교체
- 접속 차단·재개
- 학생 삭제

단어장과 시험범위는 계정 정보가 아니므로 이 탭에서 제거한다.

### 내역 탭

- 단어·다른 학습 유형, 상태, 기간으로 필터한다.
- 시험을 열면 첫 응답·재응답·정답과 오답을 확인한다.
- 시험별 보기와 전체 오답 모아보기를 모두 제공한다.
- 일반 운영에서는 단어를 하나씩 골라 재시험을 만들지 않는다. 오답
  수준과 현재 미해결 상태로 배정한다.

## 6. Overview

최근 내역 8개를 그대로 나열하는 현재 영역은 제거한다. 교사가 지금
조치할 학생만 다음 순서로 구역을 나눠 표시한다.

1. `미응시 마감` — 학생, 학습 종류, 마감 시각
2. `미통과·재시험 필요` — 학생, 점수, 남은 오답
3. `곧 마감` — 가까운 마감순
4. `마감 없음` — 오래 배정된 순

각 행을 누르면 페이지 전환 없이 해당 학생 학습 상세 모달을 연다. 통과
완료와 일반 과거 내역은 `내역`에서 확인한다.

## 7. 공통 읽기 모델과 데이터 구조

학생 관리·학습 관리·Overview가 서로 다른 계산을 하지 않도록 서버에서
공통 `StudentLearningSummary`를 만든다.

```text
student
active learning sources
next recommended vocabulary range
active assignments
recent 5 activities
wrong summary
urgency bucket
available actions
```

새 학습 자료는 자유 문자열 하나로 저장하지 않는다.

```text
student_learning_sources
- student_id
- source_type: primary_vocab | exam_vocab | textbook | supplement | mock_exam | passage
- source_id 또는 승인된 자료 참조
- display_label
- range_metadata
- active
- sort_order
```

- `range_metadata`는 교과서 판·과·Special Lesson, 부교재 쪽수, 모의고사
  연도·월·문항처럼 유형별 검증 스키마를 사용한다.
- 주 단어장은 학생당 활성 1개만 허용하고 나머지 자료는 복수 허용한다.
- occurrence의 학교·학년·시험·지문 출처 태그와 이어져 나중에 출현 빈도와
  중요도를 계산할 수 있게 한다.
- 기존 `current_vocab_dataset_id`는 1차 이관에서 주 단어장 source로
  투영하고 호환 기간 뒤 제거 여부를 결정한다.

## 8. 2025 단어장과 앱 연결

2025 자료는 원문 순서와 출제 출처를 잃지 않고 다음 두 층으로 나눈다.

1. 공통 단어 사전
   - dictionary ID, 뜻 ID, 발음 변이, 승인 상태
2. 2025 장문독해 manifest·occurrence
   - 연도, 회차/자료, 지문, 문항, 원문 표현, 문맥 뜻, source role

앱에는 승인된 사전 투영과 시험용 manifest만 넣는다. `observe`처럼 문맥에
따라 뜻이 달라지는 항목은 manifest가 사용할 sense ID와 표시 뜻을 정하고,
표현 전체가 의미 단위인 숙어·구동사는 expression 레코드로 연결한다.

첫 앱 검증은 staging의 가짜 학생 1명만 사용한다.

1. 2025 승인 배치 import
2. 해당 자료를 주 단어장 또는 시험 대비 단어장으로 연결
3. 출처 범위로 4문항 배정
4. 학생 응시·오답·재시험
5. occurrence가 결과와 분리되어 유지되는지 확인

Preview에 불필요한 대량 더미 학생·시험을 다시 만들지 않는다.

## 9. 구현 배치

### 배치 A — 2025 시험 가능 상태 만들기

상태: `보류`. 후보 데이터와 출처 연결은 보존됐지만 동일 입력 해시에 대한
뜻·표현·발음 독립 2회 검수가 일치하지 않아 승인 데이터로 승격하지 않는다.

- 사전 연결·뜻/표현/발음 승인
- 앱 import 패키지와 staging 적재
- 가짜 학생 1명으로 실제 배정 확인

완료 조건: `pending_review`가 아니라 승인된 별도 dataset으로 최소 4문항을
생성하고 끝까지 응시할 수 있다.

### 배치 B — 정보 구조와 공통 목록

상태: `1차 구현 완료`.

- 네비게이션 `학습 관리` 변경
- breadcrumb와 상단 `단어 / 다른 학습` 탭
- 검토 패널·시험별 관리·배정 관리 세로 구역 제거
- 공통 검색·필터 아코디언·학생 행·정렬 함수
- 상태별 동작 메뉴

### 배치 C — 학생 상세 작업면

상태: `1차 구현 완료`. 단어 학습 하위 화면에서 오답 관리와 새 배정 창을
페이지 이동 없이 열 수 있고, 계정 설정에서 이름·학교·학년을 수정한다.

- 고정 높이·고정 헤더·본문 스크롤
- `학습 관리 / 계정 설정 / 내역`
- 최근 5개와 전체 보기
- 단어 학습 관리 내부 슬라이드와 뒤로가기
- 페이지 이동 없는 학생별 배정

### 배치 D — 일괄 배정과 학습 자료

상태: `보류`. 원자적 서버 트랜잭션과 `student_learning_sources` 이관을
함께 설계해야 하므로 현재 단일 학생 배정 API를 브라우저에서 반복 호출하는
임시 구현은 넣지 않는다.

- 직접 선택과 필터 전체 선택
- 학생별 다음 범위 미리보기
- 원자적 일괄 배정
- `student_learning_sources`와 기존 주 단어장 이관

### 배치 E — Overview

상태: `1차 구현 완료`. 일반 최근 내역 대신 조치할 항목만 네 구역으로
표시한다.

- 최근 내역 제거
- 미응시·미통과·임박·마감 없음 조치 목록
- 학생 상세 모달 재사용

각 배치는 `redesign` Preview에서 승인받은 뒤 다음 배치로 넘어간다.

## 10. 검증 기준

- 가짜 학생은 기본 1명, 다중 선택 검증 때만 최대 3명 사용한다.
- 모바일 390px, 태블릿 768/820px, PC 1440px에서 같은 정보 순서를
  유지한다.
- 긴 이름·학교·단어장·교재 범위에서 버튼 열이 밀리지 않는다.
- 학생 모달은 탭 전환과 내부 슬라이드 전환 때 외곽 높이가 변하지 않는다.
- 키보드로 탭, 필터 아코디언, 태그, 모달 뒤로가기, 닫기를 조작할 수 있다.
- 배정 전 미리보기와 실제 생성의 학생·범위·문항 수가 일치한다.
- 취소 가능 상태와 내역 삭제 가능 상태가 상태표와 일치한다.
- Preview의 모든 쓰기는 staging에만 기록된다.

## 11. 이번 계획 밖에 두는 작업

- `다른 학습`의 실제 지문·해석·문법·모의고사 엔진
- 해석 커리큘럼 19개 챕터 구현
- 자동 AI 배정
- 전체 2023~2025 자료 동시 승인
- 운영 DB 마이그레이션과 Production 병합

## 12. 사용자 확인 가능 기본값

폼을 사용할 수 없는 환경이어서 다음 안전한 값을 기본안으로 기록했다.

- 2025 단어장: 사전 연결·승인 뒤 실제 시험 배정
- 일괄 배정: 기본 0명, 직접 선택, `현재 필터 전체 선택` 제공
- 학습 자료: 주 단어장 1개와 분류별 복수 자료

구현 전에 사용자가 다른 값을 지정하면 이 세 항목만 수정하고 나머지
정보 구조는 유지한다.
