# DAY 문제은행·학생 중심 시험 관리 v1

- 기준일: 2026-07-29
- 운영 주소: https://english-academy-student-app.vercel.app
- 범위: 능률 VOCA 2025 DAY 배정, 고정 문제은행, 학생별 순서, 응시 전환 최적화

## 구현 결과

- 어휘 3,001개를 `DAY 01~60`과 보충단원 7개, 총 67단원으로 구조화했다.
- 시험 배정은 행 번호 대신 시작 DAY·끝 DAY를 사용한다.
- 배정할 때 문제와 보기·정답을 `assignment_questions`에 한 번만 확정한다.
- 학생이 시험을 시작할 때 문제를 다시 만들지 않고 문제은행을 복사한다.
- `DAY 순서`는 원본 순서를, `무작위`는 동일 문항의 `order_index`만 바꾼다.
- 보기와 정답은 학생마다 다시 생성하지 않는다.
- 시험 화면은 첫 진입 때 전체 문항을 한 번 받고 브라우저 상태에 유지한다.
- 정상 답안은 POST 응답의 다음 문항 ID로 이동하며 전체 시험 GET은 0회다.
- 응답 유실·409·다음 상태 누락 때만 전체 시험을 1회 다시 읽어 복구한다.
- 학생 선택 화면에서 최근 시험과 다음 추천 DAY를 표시한다.
- 통과하면 다음 DAY, 미통과하면 같은 범위, 미응시면 첫 DAY를 제안한다.
- 시험 관리에 직접 들어가면 학생을 자동 선택하지 않아 오배정을 막는다.
- 학생의 현재 단어장은 선택 사항이며 학생 관리에서 나중에 바꿀 수 있다.
- 내역은 모바일·태블릿에서 행 전체를 누르는 카드로 표시한다.
