## 원인과 수정

- 기존 학생 생성은 필요한 학생코드 설정뿐 아니라 앱 전체 서버 설정을
  한꺼번에 검사해 DB 호출 전에 503으로 중단됐다.
- 학생 생성·로그인·세션·서버 DB 연결의 설정 검사를 기능별로 분리했다.
- API 오류는 폼 안에 표시하고, 서버에는 비밀값·학생정보 없이 원인 종류만
  기록한다.
- 현재 단어장 자유입력을 없애고 검수 완료·활성 단어장 선택으로 바꿨다.
- 학생은 단어장 표시명이 아니라 `vocab_datasets.id` FK를 저장한다.
- 구형 생성 RPC를 제거하고 FK를 `NOT NULL`로 만들어 우회 생성을 막았다.
