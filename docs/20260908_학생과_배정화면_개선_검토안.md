## 1. 이번 확인 결과

- 기준: 로컬 HEAD `f554aa1`, 실행 코드 `ee7be43`, Next.js 16.2.12. 기존 미추적 `tmp/`는 보존한다.
- 코드 조사 뒤 운영 앱브라우저에서 학생 목록→지정 학생 상세→닫기를 읽기 전용으로 확인했다. 학생 정보 저장·배정·응시·DB 설정 변경은 실행하지 않았다.

## 4. 확인이 필요한 학교 관련 기준

- **D1 학교 필터 제안:** 선택한 학교 전용 자료와 학교 공통 자료를 **서로 구분해 함께 표시**한다. 학교만 바꿨다고 공통 단어장이 사라지지 않게 한다. 현 카탈로그에는 학교 연결 필드가 없으므로 UI 버튼만 추가하면 정확한 검색이 되지 않는다. 확인된 자료 출처에서 학교 연관성을 연결하고, 근거가 부족한 자료를 임의로 전용/공통으로 확정하지 않는다.
- **D2 학교 검색 제안:** 공식 학교 검색을 기본으로 하되, 결과가 없거나 조회가 실패하면 **직접 입력도 허용**한다. 기존 학교명이 자동 덮어써지지 않으며 학생 정보를 외부 학교 API에 보내지 않는다.
- 공식 나이스 학교기본정보 API는 운영 호출에 인증키가 필요하다. 현재 앱 구현·환경 계약에는 해당 연결이 없다. 기존 승인된 설정에서 키 존재 여부를 확인하고, 없으면 새 계정·약관·키 발급을 임의 진행하지 않는다. 샘플 5건 응답을 완전한 검색으로 제공하지 않는다.
- D1/D2가 확정되기 전 학교 기능 전체는 조사·설계만 진행한다. 학교 API를 연결하려고 기존 학생 저장 오류 수정을 누락하거나 우선순위를 뒤집지 않는다.

| 문항 지원 상태 조회 실패 | 같은 영역에 `출제 자료를 확인하지 못했습니다. 다시 불러와 주세요.` + 다시 불러오기. 미지원으로 바꾸지 않음 |

| 상세 없음 | 조회 성공 뒤 실제 대상 없음일 때만 학생 없음 안내·목록으로 이동. 권한 노출 정책 보존 |
| 저장 확정 성공 | 폼 안에 `학생 정보를 저장했습니다.`. 최신 기준 버전 반영, 필요한 목록만 갱신 |
| 저장 실패 | 폼 안에 `학생 정보를 저장하지 못했습니다. 입력한 내용은 유지됩니다.` + 재시도. 내부 오류 원문 금지 |
| 저장 결과 불명확 | `저장 결과를 확인하지 못했습니다. 최신 정보를 확인해 주세요.`. 자동 중복 제출 금지, 후속 조회로 먼저 판정 |
| 변경 충돌 | 입력 보존, 최신 기준 버전/값을 확인할 수 있게 안내한 뒤 다시 저장 |
| 학교 결과 0건 | 정상 응답에서만 `검색한 학교가 없습니다.`. D2 확정 시 직접 입력 제공 |
| 학교 조회 실패 | `학교 목록을 불러오지 못했습니다.` + 다시 검색. D2 확정 시 기존 입력/직접 입력 유지 |
| 인증 실패 | 개인 자료 숨김, 로그인 안내. 같은 관리자의 모달 보존 규칙으로 계정 변경을 우회하지 않음 |

## 7. 검사 계획과 완료 판정

- T01: 모달 열기/닫기/다른 학생/뒤로/앞으로/직접 주소/새로고침. 배경 DOM·입력·스크롤·더보기 유지와 목록 요청 수를 따로 측정. 탭 복귀·계정 변경·저장 후 갱신 보호 회귀.
- T02: 초기/만료 후 진입/재시도/성공/실패/상세 404/오답 영역 404를 각각 검사. 오류가 로딩을 덮거나 실패를 0건으로 표시하면 실패.
- T03: 로컬 가짜 응답과 격리 검사에서 실제 폼·Action 경계를 연결해 성공·409·401·503·결과 불명확을 확인한다. 실제 환경의 승인된 테스트 학생은 정상 저장·후속 조회·검사 입력 복구만 확인하고 운영 장애나 권한 오류를 일부러 만들지 않는다. 실학생 변경 금지. 현재 저장 원인 미확정을 해결하기 전 완료로 올리지 않음.
- T04/T05: 학교 null/학년 null/긴 이름/삭제 학생, 추가 학생별 요청 없음, 배정의 상세 링크와 선택 독립·내역 초기 선택·배정 액션 복귀.
- T06/T07: 책 미선택/자동 선택/오래된 선택/실패/모든 지원 방향, 키보드/터치 도움말. 빈 숫자/001/붙여넣기/경계값/휠/터치 스크롤/키보드 입력.
- T08/T10: 연속·비연속·역순 DAY/과, 다른 연도·기관·시행, 메타정보 부족, 단일/일괄/예외 학생. 표시 전후 단위 ID·실제 회차·개수·공개·마감 계산 불변.
- T09/T12: 복합 필터/검색 취소·이전 응답/학교 동명/0건/실패/키 미설정. 출처 없는 학교·저자·출판사 추측 금지, 학생 자료 외부 전송 없음.
- T11/T14/T15: 모바일/PC·밝음/어두움·긴 제목/날짜·2단계 모달·Escape·focus 복귀·스크롤바 자리·동작 줄이기. 0→1명/많은 선택/전부 해제에서도 목록 위치 안정.
- T13: 보류는 완료·취소로 바뀌지 않음, 기록 보존·다음 자체 일정 유지·자동 재배정 없음.
- 관련 단위/통합 검사→구조/타입/lint/빌드→필요한 실제 화면 순서. 예전 전체 2910검사 통과는 이번 문제 해결의 근거로 재사용하지 않는다.
- 구현 전 기능 소유권 지도와 v1 R/D/T 설계 관문, 구현 후 현재 파일 지문에 연결한 검증 기록·완료 관문을 적용한다. UI 검사·로컬 통과·Preview·Production 상태를 혼동하지 않는다.
