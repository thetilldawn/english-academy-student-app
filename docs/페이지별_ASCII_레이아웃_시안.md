# 학생 앱 페이지별 ASCII 레이아웃 시안

- 기준일: 2026-07-29
- 상태: 선택 완료된 비교용 기록
- 현행 확정본: [확정 화면구조·반응형 배치 v1](확정_화면구조_반응형_v1.md)
- 대상: 현재 구현된 기능 페이지 11개
- 제외: API, 공통 레이아웃 파일, 오류·404 화면, 아직 구현하지 않은 기능
- 표현 범위: 정보 순서, 영역 크기, 주요 동작 위치
- 제외 범위: 색상, 폰트, 아이콘 모양, 그림자, 여백 수치, 애니메이션

학생 화면은 모바일 세로폭을, 관리자 화면은 데스크톱 가로폭을 기준으로
그렸다. 오류문은 평소에는 보이지 않고 실제 입력·요청 실패 뒤에만 해당
입력이나 동작 가까이에 표시한다.

이 문서의 `권장` 표시는 선택 전 제안이다. 구현에는 현행 확정본을
사용한다.

## 빠른 권장 조합

| 페이지 | 권장안 | 핵심 이유 |
|---|---|---|
| 첫 화면 `/` | C | 학생이 코드를 바로 입력해 한 단계를 줄임 |
| 학생 코드 `/code` | A | 공유 링크로 들어왔을 때 가장 단순함 |
| 학생 시험목록 `/student` | C | 지금 해야 할 시험을 먼저 보여줌 |
| 시험 진행 `/student/attempt/[id]` | C | 문제와 네 보기를 한 화면에 고정 |
| 학생 결과 `/student/result/[id]` | C | 다시 볼 단어를 점수보다 먼저 확인 |
| 관리자 로그인 `/admin/login` | A | 불필요한 설명 없이 로그인에 집중 |
| 관리자 현황 `/admin` | B | 해야 할 작업과 이상 상태를 먼저 확인 |
| 학생·코드 `/admin/students` | B | 학생 목록을 중심으로 코드를 빠르게 관리 |
| 시험 배정 `/admin/assignments` | B | 많은 입력을 순서대로 나눠 실수를 줄임 |
| 결과 목록 `/admin/results` | A | 현재 정보량에는 표가 가장 빠름 |
| 응시 상세 `/admin/results/[id]` | C | 첫 풀이와 재풀이 변화를 문항별로 확인 |

## 1. 첫 화면 `/`

필수 기능: 학생 진입, 관리자 진입, 공개 회원가입이 없다는 짧은 안내.

### A안 · 중앙 선택형

```text
+------------------------------+
|                              |
|       [E] 영어 학습실         |
|                              |
|   [ 학생 접속코드 입력 ]       |
|   [ 관리자 로그인 ]            |
|                              |
|  회원가입 없이 코드로 접속      |
+------------------------------+
```

### B안 · 대상 분리형

```text
+-----------------------------------------------+
|                 영어 학습실                    |
+-----------------------+-----------------------+
| 학생                  | 관리자                 |
| 받은 코드로 접속       | 관리자 계정으로 접속    |
|                       |                       |
| [ 학생 입장 ]          | [ 관리자 로그인 ]       |
+-----------------------+-----------------------+
|         공개 회원가입은 사용하지 않음           |
+-----------------------------------------------+
```

### C안 · 학생 즉시 입력형 `권장`

```text
+------------------------------+
|       [E] 영어 학습실         |
|                              |
| 학생 접속코드                 |
| [ ABCD-EFGH-IJKL          ]  |
| [       바로 입장          ]  |
|                              |
| 회원가입 없이 코드로 접속      |
| 관리자 로그인 >               |
+------------------------------+
```

이 안을 선택하면 `/code`의 입력 폼을 첫 화면에서도 재사용한다. `/code`는
학생에게 바로 전달할 수 있는 전용 접속 주소로 유지한다.

## 4. 시험 진행 `/student/attempt/[id]`

필수 기능: 첫 풀이·재풀이 단계, 시험명, 타이머, 진행률, 문제 방향,
4지선다, 즉시 피드백. 한 화면 안에서 문제와 네 보기가 함께 보여야 한다.

### A안 · 세로 집중형

```text
+------------------------------+
| 첫 풀이  시험 A        04:32  |
| [===========-------]  7/20   |
| 알맞은 뜻을 고르세요           |
|                              |
|           abandon            |
|                              |
| [1] 버리다                   |
| [2] 얻다                     |
| [3] 유지하다                 |
| [4] 설명하다                 |
|------------------------------|
| 정답/오답 피드백              |
+------------------------------+
```

### B안 · 문제·보기 분할형

```text
+-------------------------------------------------+
| 첫 풀이 · 시험 A       [진행 35%]        04:32  |
+----------------------+--------------------------+
| 7/20                 | [1] 버리다               |
| 알맞은 뜻을 고르세요   | [2] 얻다                 |
|                      |                          |
|      abandon         | [3] 유지하다             |
|                      | [4] 설명하다             |
+----------------------+--------------------------+
| 정답/오답 피드백 · 키보드 1~4                   |
+-------------------------------------------------+
```

### C안 · 속도형 2×2 보기 `권장`

```text
+------------------------------+
| 첫 풀이 · 시험 A  7/20  04:32 |

|                              |
| 알맞은 뜻을 고르세요           |
```

## 7. 관리자 현황 `/admin`

## 8. 학생·접속코드 `/admin/students`

필수 기능: 학생 추가, 이름·학교·학년·상태·코드 차수, 코드 보기·복사,
교체·차단·재개. 코드 결과와 확인은 작은 대화상자로 표시한다.

### A안 · 추가 폼·목록 분할형

```text

+------------------------+----------------------------------+

| 학교 [____] 학년 [___]  | [코드 보기] [교체] [차단]         |
| 메모 [____________]     |----------------------------------|
|                        | 이바다  마석고 · 고2  [차단됨]     |
| [학생과 코드 만들기]     | [새 코드로 재개]                 |
+------------------------+----------------------------------+
```

### B안 · 학생 목록 중심·작업 패널형 `권장`

```text
+-----------------------------------------------------------+
```

## 10. 시험 결과 목록 `/admin/results`

필수 정보: 학생, 시험, 회차, 상태, 첫 점수, 재풀이 후 점수, 통과,
시작시각. 시험명을 눌러 응시 상세로 이동한다.

### A안 · 전체 표형 `권장`

```text
+--------------------------------------------------------------------+
| 시험 결과                                                          |
+--------+------------+------+--------+--------+--------+------+------+
| 학생   | 시험       | 회차 | 상태   | 첫점수 | 최종   | 통과 | 시작 |
| 김하늘 | 시험 A  >  | 1    | 완료   | 85     | 95     | O    | 10:20|
| 이바다 | 시험 A  >  | 1    | 진행중 | -      | -      | -    | 10:15|
| 박구름 | 시험 B  >  | 2    | 종료   | 60     | 70     | X    | 09:30|
+--------+------------+------+--------+--------+--------+------+------+
```

### B안 · 점수 비교 행형

```text
+-----------------------------------------------------------+
| 시험 결과                                                  |
|-----------------------------------------------------------|
| 김하늘 · 시험 A · 1회                         [상세 >]    |
| 첫 점수 85  ---------->  재풀이 후 95       [통과]        |
| 완료 · 시작 10:20                                       |
|-----------------------------------------------------------|
| 이바다 · 시험 A · 1회                         [상세 >]    |
| 첫 점수 -   ---------->  재풀이 후 -        [응시 중]     |
| 시작 10:15                                               |
+-----------------------------------------------------------+
```

### C안 · 시험별 묶음형

```text
+-----------------------------------------------------------+
| 시험 결과                                                  |
+-----------------------------------------------------------+
| 시험 A · 응시 기록 5건                                    |
| 김하늘  1회  완료   85 -> 95  통과  10:20  [상세]          |
| 이바다  1회  진행중  -  ->  -   -     10:15  [상세]          |
|-----------------------------------------------------------|
| 시험 B · 응시 기록 4건                                    |
| 박구름  2회  종료   60 -> 70  미통과 09:30 [상세]          |
+-----------------------------------------------------------+
```

실제 묶음 기준은 같은 제목이 아니라 고유한 시험 배정 ID를 사용한다.

## 11. 관리자 응시 상세 `/admin/results/[id]`

필수 정보: 학생·시험·회차·시작시각, 첫 점수·최종 점수·미해결 수·시간,
각 오답의 문제·첫 선택·재풀이·정답·상태, 결과 목록 복귀.

### A안 · 지표·오답 카드형

```text
+-----------------------------------------------------------+
| 김하늘 · 시험 A · 1회 · 10:20              [결과 목록]    |
+-------------------+-------------------+-------------------+
| 첫 점수 85         | 최종 점수 95       | 미해결 1 · 04:21  |
+-------------------+-------------------+-------------------+
| 첫 풀이 오답과 재풀이                                     |
| abandon [다시 맞힘]                                       |
| 문제 / 첫 선택 / 재풀이 / 정답                            |
|-----------------------------------------------------------|
| maintain [다시 틀림]                                      |
| 문제 / 첫 선택 / 재풀이 / 정답                            |
+-----------------------------------------------------------+
```

### B안 · 학생 요약·문항 표 분할형

```text
+----------------------+------------------------------------+

| 시험 A · 1회          |------------------------------------|

|                      | abandon  얻다    버리다  버리다 맞힘 |
| 첫 점수 85            | maintain 얻다    얻다    유지  미해결|

| [결과 목록]           |                                    |

```

### C안 · 문항 변화 흐름형 `권장`


## 공통 상태 배치

```text
평상시       : 안내성 경고 없음
입력 오류    : 해당 입력 바로 아래
요청 실패    : 실행 버튼 바로 위 또는 작업 패널 안
처리 중      : 누른 버튼의 문구와 비활성 상태로 표시
빈 목록      : 목록이 있어야 할 영역 안에 한 줄로 표시
위험 동작    : 코드 교체·접속 차단을 실행할 때만 확인창 표시
```
