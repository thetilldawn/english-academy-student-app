# 반응형 화면구현 검증

- 검증일: 2026-07-29
- 범위: 학생 인증·시험·결과와 관리자 로그인·현황·학생·배정·결과
- 기준 문서: [확정 화면구조·반응형 배치 v1](확정_화면구조_반응형_v1.md)

## 구현 결과

- `/`에서 학생 코드를 바로 입력하고 `인증`으로 접속한다.
- `/code`는 별도 화면 없이 `/`로 이동한다.
- 관리자 로그인은 `/admin/login`에만 둔다.
- 초기 화면에는 오류나 연결 안내를 표시하지 않고 실제 실패 뒤에만
  오류를 표시한다.
- 학생 시험목록은 지금 할 시험을 우선하고, 결과는 다시 볼 단어를 먼저
  보여준다.
- 시험 진행은 공통 상단바를 숨긴 전체화면이며 모바일에서도 보기를
  2×2로 유지한다.
- 관리자는 모바일 하단 메뉴, 태블릿 상단 메뉴, PC 좌측 메뉴를 사용한다.
- PC 학생관리는 학교·학년 그룹, 학생 목록, 선택 학생 작업의 3영역이다.
- 시험 배정은 4단계 입력과 시험명·범위·문항·시간·점수·학생 수의
  실시간 최종 요약을 제공한다.
- 모바일 결과표는 학생·시험 열을 고정하되 나머지 열이 보이도록 고정
  폭을 줄였고 표 자체는 가로로 이동한다.
- 코드 표시에는 브라우저 기본 모달 대화상자를 사용해 초점 이탈,
  Escape 닫기, 닫은 뒤 초점 복원을 처리한다.

## 반응형 기준

| 화면 | 확인 크기 | 결과 |
|---|---:|---|
| 모바일 | 360×800 | 중앙 인증 카드, 가로 넘침 0 |
| 태블릿 | 768×1024 | 480px 인증 카드, 가로 넘침 0 |
| PC | 1440×900 | 480px 중앙 인증 카드, 가로 넘침 0 |

관리자 보호 화면은 세션이 없으면 `/admin/login`으로, 학생 보호 화면은
`/`로 이동하는 것이 정상이다. 실제 학생·관리자 데이터 화면은 인증
세션 없이 우회하지 않았고, 운영 빌드·라우트 계약 검사와 코드 검토로
구조를 검증했다.
