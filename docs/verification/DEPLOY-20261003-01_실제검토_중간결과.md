## 운영 전환에서 남은 검증

운영 구형 fa4357 화면은 새 참조형 배정의 NULL 본문을 직접 읽는 경로가 있다. 새 시작만 막더라도 진행 시험 종료의 자동 후속 배정이 생길 수 있으므로 단순 SQL→앱 전환으로 무오류를 주장할 수 없다. 구형 기반 임시 호환 앱의 준비/예문 단어보기 두 조회를 먼저 보완하는 방법을 검토했다. 이는 아직 구현·검증 결과가 아니다.

운영 SQL 묶음은 시작 제어를 먼저 설치한 뒤 별도 거래로 새 시작을 중지하고, 나머지를 보존 거래로 적용하는 안이다. 기존 답 제출을 차단하지 않고 새 앱 확인 뒤 재개해야 한다. 기존 행의 원래 열과 새 nullable 열, M07이 의도한 목록 표시 변경, 함수 권한, 동시에 들어온 답, SQL 간 설정 차이를 구분해 결합 검증할 필요가 있다. 운영 사본·기존 본문 정리·공간 회수·공지·관리자 분리·발음 추가를 완료했다고 주장하지 않는다.
