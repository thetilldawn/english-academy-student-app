# 단어장 범위 편집과 저장 보완 결과

2026-09-21 · APP-20260921-01 · 로컬 구현 및 검증 기록

지적받은 화면을 자료별 범위 편집 방식으로 고쳤다. 이번 결과는 수정된 앱과 가짜 자료로 검사한 결과다. 운영 앱, 운영 DB, 실제 템플릿과 학생 기록에는 아직 적용하지 않았다.

## 바뀐 사용 흐름

1. **용도와 대상**: 직전 대비·유형별 학습 등 용도를 정하고 필요할 때 학교·학년·학기·시험을 붙인다.
2. **자료와 범위**: 모의고사, 수능, 교과서, 단어장 등을 묶음으로 추가한다. 각 묶음에 맞는 조건만 표시한다.
3. **전체 확인과 저장**: 실제 포함 범위와 단어 수, 자동 태그, 수정 가능한 제안 이름을 확인하고 저장한다.

| 지적한 문제 | 보완한 동작 |
|---|---|
| 유형·연도를 바꿔도 담긴 범위가 그대로 남음 | 편집 중인 묶음의 실제 포함 목록을 즉시 갱신한다. 다른 교재·자료 묶음은 유지한다. |
| 수능이 11월로 섞여 있음 | ‘수능’으로 별도 선택하며 ‘2025년 시행 · 2026학년도’처럼 구별한다. |
| 수능 유형 선택이 안 되는 이유를 알 수 없음 | 등록된 유형과 미등록 유형을 구별한다. 현재 운영 등록은 장문독해뿐이며, 화면 변경으로 없는 자료를 만들어 내지는 않는다. |
| 필수 입력 없이 저장되거나 생성 버튼이 막힘 | 이름·확정 범위·실제 포함 단어를 검사한다. 오류는 입력 아래와 빨간 테두리로 표시하고 저장을 막는다. |
| 조건만 저장된 빈 템플릿 | 열기만으로 원본을 바꾸지 않는다. ‘저장된 조건으로 범위 채우기’에서 실제 자료를 채운 뒤 새 버전으로 저장할 수 있다. |
| 태그를 직접 작성해야 함 | 실제 포함 범위와 용도·대상에서 자동 생성한다. 기존 수동 태그는 별도로 보존한다. |
| 새 만들기·빈 틀·준비 파일 메뉴가 중복 | ‘범위로 새로 만들기’로 통합했다. 빈 틀 버튼과 준비 파일 불러오기를 제거했다. 미확정 범위는 같은 편집 화면에서 명시적으로 선택한다. |
| 자료 종류와 무관하게 DAY·교과서·문제번호가 모두 표시됨 | 모의고사/수능은 연도·유형·문제번호, 교과서는 교재·과, 단어장은 교재·DAY로 나눈다. 직전 대비에는 여러 묶음을 함께 넣는다. |
| 기존 월별 책과 새 조합이 혼동됨 | 기존 책을 유지하면서 확인된 출처에 따라 ‘원본 단어장’과 ‘범위로 만든 단어장’을 구분한다. |
| 다른 화면으로 이동하면 작성 내용이 사라질 수 있음 | 새로 만들기·다른 구성 사용 전 폐기 확인, 상위 배정 창을 닫을 때도 초안 보호를 연결했다. |

### 실제 브라우저

실제 앱을 로컬 주소에서 새로 빌드했고, 인증·자료 요청은 가짜 로컬 응답만 사용했다. PC 1280×720와 모바일 390×844에서 조작했다.

1. 새 만들기의 빈 이름·범위에서는 저장 불가를 확인했다. 중복 빈 틀/파일 입력 메뉴는 없다.
2. 2024~2026년 주제 3범위·12단어를 고른 뒤 교과서를 추가했다. 모의고사를 장문독해로 바꿔도 교과서 1범위가 남았다.
3. 수능을 더해 5범위·20단어를 저장했다. 수능 표기는 학년도/시행연도로 나타나고 주제는 ‘미등록’, 장문독해는 선택 가능했다. 모의고사의 9월 표기는 해당 자료 태그로 유지됐다.
4. 다시 편집해 2024~2025년으로 좁힌 새 버전은 4범위·16단어, 이전 버전은 5범위·20단어로 유지됐다. 과거 버전 태그도 해당 범위에 맞게 바뀌었다.
5. 잘못된 연도 구간과 빈 이름은 입력 오류·저장 잠금으로 표시됐다. 이름 입력의 실제 오류 테두리 색상 `rgb(178, 58, 47)`, `aria-invalid=true`를 확인했다.
6. 모바일 단어장 묶음에는 DAY 조건이 표시되고 모의고사 조건은 나타나지 않았다. 없는 DAY를 고르면 0결과와 저장 불가를 안내했다.
7. 상위 배정 창 닫기를 취소하고 다시 들어갔을 때 작성 중인 DAY 시작값 2가 유지됐다.
8. 모바일 페이지 너비 390px, 가로 넘침 0. 브라우저 오류/경고 기록 0.

가짜 DB 저장 요청은 새 구성 1회·새 버전 1회, 합계 2회이며 모두 메모리 안에서 성공했다. 학생 배정·시험 시작·답안 제출은 0회다. 학교 일정은 이 검사 환경의 지원 대상이 아니어서 로컬 응답 403 2회가 기록됐다. 해당 일정 기능의 정상 확인으로 해석하지 않는다.

검사 탭과 화면 크기 설정을 정리했고, 이번에 만든 서버만 종료한 뒤 기존 빌드 폴더를 복구했다.

### 독립 검토

읽기 전용 검토에서 발견한 기존 태그 삭제, 자료 재조회 실패 후 저장 재확인 잠김, 동일 필터의 불필요한 재계산, 상위 창의 초안 보호 누락 등을 보완했다. 마지막 태그 보존 재검사에서는 이름/대상 수정·새 버전·이전판 복사·복합 검색·새 구성 초기화를 확인했다. 마지막 서버 검토에서도 남은 실질적 문제를 발견하지 못했다.
