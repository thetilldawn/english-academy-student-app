## 구현 결과

- 새 템플릿은 자료별 필터 조건을 저장한다. 다시 사용할 때 현재 자료를 계산하고, 추가·제외·순서 차이가 있으면 확인 뒤 새 고정 판을 만든다. 기존 직접 선택 판의 범위·판·제외·순서는 유지한다.
- 템플릿 삭제는 목록에서 숨기는 상태 변경이다. 원자료·생성 단어장·학생 배정·문항·응시·답·오답 큐를 보존한다. 새 생성은 거절하고 이미 시작한 정확히 같은 요청만 복구한다.
- 일반·일괄·오답·배정 수정에서 원자료 순서의 오름차순·내림차순·무작위를 선택하고, 이전 시험 조건에서도 복원한다.
- 자료별 조건과 자동 태그/이름, 학생 대상 기본값, 수동 변경 보존, 필수 입력의 오류 표시를 유지한다. 검색 변경·로그인 계정 변경·늦은 응답·저장 재확인·충돌 후 새로 불러오기에서 다른 구성에 결과를 붙이지 않는다.
