# 학생 조건 보완 반영 명세

이 문서는 로컬 검증한 결과의 외부 반영 범위를 구체화한 것이며 외부 적용 완료나 새 배포 승인을 뜻하지 않는다.

- 앱: 학생 필수 입력과 오류 표시, 배정 학생의 자동 조건 및 정보 보완 연결, 신규 구성 대상 기본값, 새 배정 누락 정보 안내.
- DB: `supabase/migrations/20260921010000_require_student_profile_for_new_assignments.sql` 1개. 신규 학생·프로필 저장과 새 배정 경로에 필수값 검사를 추가한다. 기존 행을 수정하지 않는다. 기존 함수가 예상된 형태일 때만 적용하며 다른 형태이면 중단한다.
- 권한: 보조 함수는 일반 사용자·학생·서비스 역할의 직접 실행을 차단한다. 공개 배정 경로는 기존 관리자 권한을 유지한다.
- 보존: 과거 완료 응답을 먼저 반환하며 기존 시험·학생 기록·자동 후속 회차는 유지한다. 빈 프로필 일괄 보정·자료 등록·템플릿 삭제·실제 학생을 통한 시험 검증은 포함하지 않는다.
- 순서: 검토 환경의 현재 함수/권한과 기존 표 확인값 확보 → SQL와 동일 앱 적용 → 공개 배정 17경로 및 완료 응답 보존 확인 → 가짜 학생의 관리자 화면 검증 → 승인된 범위의 동일 변경만 운영에 반영 → 기존 기록/권한/배포 확인.
- 복구: 앱은 직전 실행판으로 되돌릴 수 있다. DB 검사는 기존 데이터에 손대지 않으므로 일괄 데이터 복구를 하지 않는다. 필수 검사 원복이 필요하면 실제 배포 당시의 함수 원문과 비교한 별도 변경으로 처리한다.
