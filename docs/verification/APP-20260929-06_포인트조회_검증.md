# 포인트 조회 실패 표시 보완

F06은 필수 응답 누락과 null/빈 문자열/불리언을 0점으로 처리할 수 있던 문제다. 읽기 서비스만 보완했다. 요청 학생별 정확히 한 행, 시험 요약 한 행, 유효한 정수와 부호/합산 관계를 검사한다. 잘못된 응답은 기존 오류 표시로 전달하며 실제0과 과거 포인트 사건 없음은 구분한다.

학생에게 음수 시험 합계를 0으로 보여 주는 규칙과 관리자 부호, 서비스 역할 권한, React 요청별 중복 제거, 원장/지급 계산은 유지한다. 디렉터리 LEFT JOIN에서 행이 없는 별도 계약은 변경하지 않았다.

- 서비스/표시6파일75검사, SQL·가짜 원장3파일12검사 통과. 독립 검토자도 서비스/SQL/가짜 원장3파일60검사를 재실행했고 추가 지적 없음.
- null/빈값/불리언/잘못된 정수, 누락/중복/다른 ID, 음수·합산 모순, 사건0에서의 잘못된 값, 실제0/순변화0/안전 정수 경계를 검사했다.
- 타입/lint·기능지도·설계 검사 통과. 입력 확인값과 완료 관문은 같은 번호 기록에 있다. 기존 확인 불가 UI를 사용하며 새 운영 화면 시험은 하지 않았다.
- SQL/운영/실학생 쓰기·배포0. 다음 근거는 F07 알림 공개 조건이며 현재 상태·순서는 루트 대장만 따른다.
