# 앱 구조 수리 결과

대상: 승인된 재점검 보고서 R1–R7. 기존 사전과 학생 기록을 유지하면서 중복 저장·조회와 화면 복구를 수정했다. 새 사전·본문 보관층·용량 한계 실험은 추가하지 않았다.

| 항목 | 수정 내용 | 확인 근거 |
|---|---|---|
| 구형 복사 입구 | 과거 동일 접수 조회는 유지하고 새 본문 복사를 거절. 미사용 생성 화면·전송 제거 | 권한·과거 접수·충돌 검사 |
| 새 구성 문항 | 기존 원키·선택지키·확인값으로 저장/해석. 기존 본문형 문항과 중단된 준비는 그대로 읽고 이어 처리 | 구성 26, 구형 조합 9, 단계 5, 직접 배정 7 검사 통과 |
| 내 단어장 | 직접 주소 첫 문서는 첫 자료를 제공하고 내부 이동은 기존 브라우저 자료를 사용 | 첫 문서/내부 이동의 서버 조회 분리 검사 |
| 창 복귀·학생 목록 | 복귀 신호를 한 번 처리. 현재 검색과 펼친 페이지 수 보존, 새 커서/현재 포인트 사용. 재시도 강제 조회가 다음 검색에 남지 않음 | 숨김→복귀·뒤로가기·확장 목록·늦은 응답 검사 |
| 오답·발음 조회 | 같은 뜻·출처 계산과 같은 원키 발음 조회를 요청 안에서 공유 | 기존 정렬/합계/필터/권한과 결과 대조 |
| 배정 준비 화면 | 같은 인증과 대상의 준비를 기존 15초 안에서 재사용. 자료 변경 뒤 옛 응답 차단. 화면 코드와 자료 준비까지 동일 로딩/취소 창 유지 | 배정 관련 56검사 통과, 검색 보호 분기 5검사 통과 |
| 시험 준비 | 미리 받기와 클릭 요청 공유. 서버 준비 한 번. 필요한 기기 키 직접 조회 | 실제 Chromium: 미리 받기1/준비1, 재전송 본문0/표시자료0, 전체 저장소 검색0, 개별 취소·기존 답 보존 |

실제 로컬 빌드 화면에서도 풀이 중 시험 요청 0회, 정답 표시 264ms, 중단/계속, 390px 화면, 배경 흐림을 확인했다. 구조 검사 77개와 Next.js 빌드 통과. 빌드는 설치된 구형 Node의 외부통신 종료 문제를 피하고 프로젝트가 요구하는 Node 24.19.0으로 실행했다.

검토 DB 반영: 두 수정 적용 전후 단어 39,624개, 기존 구성 31,902개(본문형 동일), 응시 171개, 구형 조합 5개와 대상 함수 권한 동일. 기존 행 삭제·본문 일괄 이전은 하지 않았다. 원격 이력 번호는 `20261007162013`, `20261007162054`이며 로컬 SQL 파일의 확인값과 함께 배포 근거에 남긴다.

현재 이 문서를 작성하는 시점에는 새 Preview 인증 흐름 및 운영 배포 확인이 남아 있다. 예전에 보고된 특정 심석고 범위의 약 7천 개 표시가 재현·해결됐다는 주장은 하지 않는다. 그 현상의 재현 자료와 이번 구조 수정의 확인 근거는 구분한다.
