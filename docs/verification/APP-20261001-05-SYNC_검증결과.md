## 검사와 한계

첫 실행에서 새 검사의 M03 재현 문자열을 잘못 작성해 2개가 실패했다. 원래 M03의 객체 결합식으로 검사 입력을 수정했고, 제품 SQL은 바꾸지 않은 채 실제 검토 본문 확인값 재현 및 최종 36검사를 통과했다. 전체 5,121검사는 앞선 APP11의 기존 근거이며 이 작은 동기화에서 다시 실행한 검사로 세지 않는다.
