## 실제 두 연결 검사

임시 공개 검사 함수는 service_role만 실행할 수 있고 위 가짜 키로 범위를 제한한다. 기존 앱의 생성·확정·배정·시험 시작 함수를 실제로 호출한다. 다른 PID와 DB 잠금/차단 근거를 기록한다.

1. 운영자 준비·전환 중 새 고정판 복사가 잠금 해제 뒤 같은 내용으로 완료되는지 확인한다.
2. 새 구성 생성·완료 확정·신규 배정·신규 시험 시작이 먼저 실행될 때 운영자가 잠금 충돌로 빠르게 취소되는지 확인한다. NOWAIT 거절은 대기 차단 증거와 구분하여 기록한다.
3. 먼저 보인 큰 키보다 낮은 키가 늦게 확정되어도 전체 미연결 후보 재조회에 포함되는지 확인한다.
4. 전환 뒤 생성한 가짜 학생의 새 시험/답을 그대로 둔 채 외부 사본에서 지정 본문만 복구하고 전열 확인값을 비교한다.

## 종료와 실패 처리

실패한 거래는 전체 취소한다. 전환된 본문 복구는 외부 사본에 기록된 지정 열만 처리한다. 고정판·뜻 정체성·학생 결과를 과거로 덮어쓰지 않는다.

실행 중 사본 도구가 루트의 기존 `.git`을 감지하여 하위 자료 폴더 저장을 거절했다. 가짜 사본은 모든 Git 조상 밖의 접근 제한 TEMP 폴더로 옮겨 저장·재읽기했다. 운영 사본 경로로 사용하지 않는다. 원자료 배정은 기존 capability 묶음이 없는 가짜 입력의 전체 앱 경로 대신 실제 FK 삽입 잠금을 검증했고, 구성 배정은 실제 v7 함수를 사용했다. 최종8개 두 연결 사례와 부분 복구·보존·검사 도구 보완은 [결과](APP-20261003-03_검증결과.md)에 구분한다.
