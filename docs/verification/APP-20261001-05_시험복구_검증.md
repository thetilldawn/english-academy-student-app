확인된 것은 HTTP 응답 시간과 종료 DB 오류57014다. 첫 답만의 전용 SQL 분기나 7초 pg_sleep는 없다. 정답 처리의 학생 잠금, 오답 상태/대기열 확인, 종료 후 후속 배정 준비가 측정 후보지만 실제 병목으로 확정하지 않았다. 인덱스 추가나 잠금 순서 변경을 추정만으로 적용하지 않았다. 운영 학생 시험·답안·강제 종료로 부하를 시험하지 않는다.
