## 실패 재현과 보완 이력

- 변경 전 원문 오류 표시, 이전 0건과 실패의 혼동, 구역 재조회 재시도 부재를 코드/독립 검토와 실패하는 회귀 검사로 먼저 확인했다.
- 독립 검토에서 필수 응답 구역이 빠져도 통과하는 경우와 개요의 인증 오류가 새 서버 응답에도 남는 경우를 발견했다. 필수 구역 계산을 서버/브라우저가 같은 계약으로 사용하도록 하고, 인증 숨김을 서버 응답 버전에 귀속시켰다. 두 문제의 회귀 검사를 추가한 뒤 재검토를 통과했다.
- 첫 전체 실행은 377파일 중 1개, 2,167개 중 1개 실패했다. 구역 계산 함수를 옮긴 뒤에도 예전 서버 파일의 문자열 위치만 찾던 검사였다. 학생 구현은 바꾸지 않고 공통 함수의 실제 반환값과 서버 연결을 검사하도록 보완했다. 최종 전체 재실행은 377파일·2,167개 모두 통과했다.
- 검사 도구의 첫 실행에서는 Vite의 개발용 JSX 의존성 준비 누락이 있었다. 기존 설치 패키지의 사전 준비 목록을 보완한 뒤 위 브라우저 흐름을 확인했다. 앱 문제로 집계하거나 설치 의존성을 추가하지 않았다.
- 첫 조회 오류의 “내역은 변경되지 않았습니다”는 확인하지 못한 저장 결과를 단정하므로 제거했다. “시험 내역을 확인하지 못했습니다. 잠시 뒤 다시 불러와 주세요.”로 변경하고 기존 오류번호/다시 시도를 유지했다.
