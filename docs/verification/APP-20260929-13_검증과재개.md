# 교사 개인별 오답시험 — 로컬 검증

## 구현과 확인

- 학생 선택 바구니에서 개인 오답을 일괄 배정한다. 학생별 첫 풀이 오답을 횟수·검색 조건 전체에서 고르고, 출제 가능 수·제외 이유·실제 단어를 저장 전에 확인한다. 단일 배정은 의도적인 학년 차이를 허용하고, 일괄 배정은 한 명만 남아도 다른 학년 책 포함을 확인한다.
- 실제 책·단원·단어·원학생 오답·사전 식별자·당시 뜻·발음을 보존한다. 복제 단어장을 만들지 않는다. 기존 시험용 승인표도 수정하지 않는다. 원천 변경·다른 학생 오답·변조 문항·이중 요청·저장 유실을 검사한다.
- 기존 응시·성적·미통과·교사 상세 조회에 연결하지만 이 배정만 포인트를 주지 않는다. 배정과 응시의 포인트 정책은 서버와 DB에서 고정하고 0점 포인트 이벤트도 만들지 않는다.
- 인증 재확인 시 입력과 전송 중 요청을 보존하고, 실제 계정 변경 시 폐기한다. 저장 중 닫기/이동을 막고 결과가 불확실하면 같은 요청으로 확인한다. 전체 시간의 0.5분 등 소수 입력도 공통 조건 입력과 일치한다.
