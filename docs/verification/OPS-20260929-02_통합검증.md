서버 컴포넌트의 직접 서버 조회, 작은 클라이언트 상호작용, 기능 공개 경계, 인증 후 개인별 no-store, 변경 성공 시 관련 목록 갱신을 유지한다. 기존 관리자의 큰 제어기 분리 과제는 해결했다고 표시하지 않았다. 이번 기능의 연결만 좁게 추가했다.

교사 PC·학생390px 통합 확인과 APP11/12의 화면 검사는 연결 근거다. 실제 기기, 실제 계정 전환, 운영 인증 후 사용, PostgreSQL 다중 연결 경합은 미실시로 남긴다. 실학생 응시/답안/배정은 검사하지 않았다.

외부 반영할 SQL은 APP10~13의 추가4건뿐이다. Supabase MCP와 기존 공식 Vercel CLI 인증을 확인했다. 검토/운영 DB 이력이 다르므로 전체 db push는 사용하지 않는다. 배포용 명세·전후 보존 검사·검토/운영 식별·응답은 별도 DEPLOY-20260929-03 기록에 남긴다.
