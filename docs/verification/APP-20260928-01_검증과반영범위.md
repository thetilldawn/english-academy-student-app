## 확인한 원인

정상 Vercel 대시보드의 2026-09-28 01:01:14~32 KST 단어장 query 요청에서 `admin.auth.profile` timeout 약5초와401 응답을 확인했다. 인증 서버 조회 지연을 비로그인으로 바꾸어 입력 화면이 닫히는 경로다. 최초의 단순 로그인 만료 추정을 정정한다. 같은 시각 query의60초504와503도 존재하므로 모든 조회 지연까지 해결한 수정으로 보지 않는다.

## 수정과 검사

- 인증 조회 지연/장애는 기존503 안내·재시도 경로로 연결한다. 실제 비로그인401/다른 관리자403·개인 응답 no-store·인증 확인 전 업무 호출0을 보존한다.

- 변경6파일 lint 통과. Next16.2.12/Node24.19.0의 격리 빌드에서 TypeScript와40개 페이지 생성 통과. 빌드는 localhost 가짜 설정만 사용했다.
