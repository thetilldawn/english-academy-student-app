# 문항 공유 검토 DB 검사

대상은 Preview `wojxpruvbjzbhrpmsbuy`뿐이다. 운영 환경은 변경하지 않는다. 새 SQL 한 건의 로컬 SHA-256은 `3e195f7ea237a4ef42d2cdab144573f444b51296817074c8f5f8ef5b171b6b79`다.

변경 전 기존 55개 표 174,836개 행의 개수·내용 확인값을 저장했다. 새 참조 열만 비교에서 제외하며, 변경 직후 기존 행의 새 참조가 모두 NULL이고 공용 문항이 0개인지 별도로 확인한다. 기존 자료 이전·삭제는 없다.

동시 등록 검사는 접근 코드와 로그인 세션이 없는 명시적 가짜 학생 2명, 비활성·배정 불가 단어장 1개, 가짜 단어 4개만 사용한다. 동일한 4문항을 서로 다른 학생의 준비 요청으로 보낸다. A는 MCP 거래에서 등록을 미확정 상태로 유지하고, B는 기존 Preview 서비스 연결로 같은 공용 문항을 등록한다. A가 B의 실제 transactionid 잠금과 차단 프로세스 번호를 확인한 뒤 확정한다. 서로 다른 연결의 준비 기록 2개가 공용 문항 4개를 함께 쓰는지 대조한다.

이 검사는 준비 자료의 동일 문항 등록 경쟁을 확인한다. 실제 시험 시작, 출제 원자료의 적격성, 실제 학생 동시 수용 인원 시험은 아니다. 가짜 자료는 기존 원문을 복사하지 않는다. 시험·답안·점수·포인트·오답 사건은 만들지 않는다.

검사 후 가짜 학생을 차단·소프트 삭제하고 준비를 만료시킨다. 가짜 단어장은 비활성·배정 불가로 유지한다. 기존 55개 표 확인값을 다시 대조한다. 새 불변 공용 문항과 가짜 준비 근거는 삭제하지 않고 검사 자료로 남긴다.

M11의 완료 확정 SQL은 아직 Preview에 적용하지 않았다. 이번 검사는 M02의 저장·복원·동시 등록 범위이며, M11 원격 완료 검증과 배포 완료를 의미하지 않는다.
