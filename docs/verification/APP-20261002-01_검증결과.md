## 이전 중간 검증 지점

- 뜻별 실제 답 접수·현재 구간·누적·해결·재오답·재전송을 분리하는 SQL과 학생 현재/이력·연습은 로컬 구현 상태다. 이전 조회 형식에 새 문항 유형을 무조건 더하던 부분은 새 연습 문항에만 추가하도록 고쳐 기존 응답을 보존했다.
- 관리자 오답 화면을 새 조회로 연결했다. 단어 카드 안에서 뜻을 각각 선택하며, 자료 필터는 해당 자료의 현재 구간에 속한 문항·최초/재시험 단계만 보낸다. 현재 전체 횟수와 선택 자료의 횟수를 구분한다.
- 조회판 변경 시 첫 페이지부터 한 번만 자동 복구하고, 검색 중 입력창과 포커스를 유지한다. 저장·문제지·준비 취소가 권한 거절을 받으면 개인 표시와 선택을 즉시 폐기한다. 취소 응답을 잃었을 때 목록을 다시 조회한다.
- 문제지 요청 v2는 공용 본문 참조·원문항·단계·뜻·구간·판·횟수만 개인 표에 저장한다. 같은 구간의 선택 순서나 UUID 대소문자가 달라도 기존 요청을 재사용하며, 해결 뒤 재전송도 원래 요청을 반환한다. 새 구간은 새 요청을 만든다. 생성·내보내기는 정규 답안·오답·포인트를 바꾸지 않는다.
- 문제지 v1과 기존 내보내기 해시는 유지한다. v2와 Drive용 출력 v2는 현재/누적/예전 횟수와 실제 시험한 기본 뜻·영영 뜻·예문을 구분한다. 승인된 기본 뜻은 불변 시험 출현의 근거까지 확인해 제작 가능 상태를 유지하고, 근거 부족 자료는 확인 필요로 남긴다. 실제 Drive 쓰기는 수행하지 않았다.
