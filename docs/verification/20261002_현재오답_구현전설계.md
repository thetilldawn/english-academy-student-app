# 현재 오답과 과거 이력 — 구현 전 설계

APP-20261002-01 / M03. 기준 7275b71716c2951e2210239e0e7ad673d70ee76f. 승인된 유지보수의 기존 기능 보완이며 사용자 미결정은 없다. 이 문서는 구현·검증 완료나 운영 반영을 뜻하지 않는다.

## R1 / D1 — 단어와 뜻을 구분

단어 카드는 기존 공용 사전/단어 식별자로 묶는다. 실제 해결 단위는 동결된 승인 뜻 또는 원출현의 선택이다. M01의 `reviewed-meaning-v1` 확인값 공식을 그대로 쓰고, M02의 공용 문항판으로 원값을 읽는다. 현재 사전이나 비슷한 문자열로 과거의 뜻을 바꾸지 않는다. 승인되지 않은 자료는 원판·원출현·시험한 필드·선택값 확인값으로 구분한다. 한국어 뜻의 승인은 영영 정의/예문의 동일 뜻 승인을 대신하지 않는다.

새 공용 문항판을 확정할 때 뜻 연결도 고정한다. 조합 문항은 동결된 M01 연결을 사용하고, 개인 오답 문항은 실제 원문항의 시험 필드와 뜻을 이어받는다. 출제 방식이 달라져 같은 뜻임을 입증할 수 없다면 이전 뜻의 해결 근거로 쓰지 않는다. 과거 문항에 이미 동결된 연결이 없으면 보수적 원출현 키로 읽고 미확인 상태를 표시한다. 학생별 문항 본문을 다시 복제하지 않는다. 검사 T1/T6/T8.

## R2 / D2 — 답 접수, 순서, 재전송

모든 공개 답 함수와 만료 진입에서 학생 행을 먼저 잠근다. 이미 학생을 잠그는 자동 만료·학생 삭제·준비 시작은 순서를 유지한다. 응시/문항 소유를 검사한 뒤 저장 영수증을 현재 단계·시계 검사보다 먼저 확인한다. 문항+initial/retry가 같은 요청은 원래 선택과 강제 시간초과 여부까지 대조하여 원래 결과만 반환한다. 서로 다른 요청은 충돌이며 과거 답으로 현재 상태를 다시 계산하지 않는다. 기존 답에 새 영수증이 없으면 상태를 바꾸지 않고 기존 충돌 처리를 유지한다.

기존 점수·최초 종료·재시험 통과·7초 피드백 시간을 유지한다. v4뿐 아니라 v3/v2/base 호환 진입도 같은 공통 처리로 들어간다. 최종 문항행을 읽어 실제 오답 선택·정답·시간초과·만료 미제출을 구분한다. v2가 내부적으로 만든 임시 오답 번호를 실제 선택으로 기록하지 않는다. 실제 새 답만 서버 순서를 얻는다. 같은 거래에서 여러 답을 처리해도 각각 반영하고 마지막 답만 남기지 않는다. 검사 T2/T4/T5.

## R3 / D3 — 현재 구간과 누적 횟수

학생+뜻 상태에는 현재 구간, 현재 실제 실패 수, 보존된 누적 실제 실패 수, 마지막 서버 순서, 해결 시각을 둔다. 실패를 받으면 구간이 없을 때 새로 열고 횟수를 1 더한다. 정답이면 해당 뜻의 현재 구간만 해결한다. 전체 시험의 통과 여부와 별개다. 다시 틀리면 새 구간 1회로 시작하고 누적은 이어진다. 짧은 사건은 공용 문항과 답의 키를 참조한다.

시간초과·미제출은 기존 성적에서의 오답 처리와 구분하여 원인을 보존한다. 실제 선택 실패 횟수에 임시 선택 번호를 더하지 않는다. 학습이 필요한 미해결 상태는 유지하되 실제 실패와 시간초과/미제출 수를 다른 이름으로 전달한다. 자율연습은 정규 상태·사건·포인트를 바꾸지 않는다. 기존 `wrongCount`, `prior_wrong_count`, 교육용 큐 단계의 의미는 보존하며 새 현재/누적 필드로 소비자를 명시적으로 전환한다. 검사 T1/T2/T3/T7.

## R4 / D4 — 과거 자료와 현재 조회

기존 사건·답·포인트·배정·문항을 일괄 이전/갱신/삭제하지 않는다. 과거 답과 원문항으로 읽기 전용 기준선을 구성하고, 새 뜻 상태가 생긴 단위는 새 상태를 우선한다. 새 접수와 옛 일괄 오답 사건은 문항+단계로 중복 제거한다. 과거 처리 순서를 확정할 수 없는 경우 임의로 합쳐 해결하지 않고 확인 한계를 남긴다. 기존 단어 단위 상태는 호환 자료이며 새 뜻 상태의 해결 근거로 재사용하지 않는다. 과거 처리 뒤에 도착한 묶음 사건이 새 구간을 다시 열지 못하게 한다.

현재 목록·검색·횟수 조건·요약·배정 가능 수를 같은 미해결 뜻 집합에서 만든다. 단어 카드 안에서 뜻과 출처를 구분하고 전체 현재 횟수와 선택 출처 횟수를 다른 이름으로 보낸다. 과거 이력에는 해결된 뜻도 남는다. 현재 커서는 학생·보기·필터·정렬·학생 상태판과 묶는다. 변경 시 409로 첫 페이지부터 다시 읽고 목록과 선택을 교체한다. 이력은 조회 상한을 고정한다. 읽기에서 상태를 쓰지 않는다. 검사 T3/T6/T8/T9.

## R5 / D5 — 선택·재출제·대기열

문제지, 개인 오답, 직접 오답, 혼합 배정, 큐 예약은 대표 카드 키만 쓰지 않고 선택한 뜻·현재 구간·상태판을 함께 사용한다. 저장은 학생 잠금 뒤 다시 검사한다. 완료 영수증의 재조회는 최신 상태 검사보다 먼저 실행한다. 지난 구간의 진행 시험은 고치지 않으며, 그 연결이 새 구간의 출제를 막지 않게 한다. 교육용 큐 단계는 기존 정책을 유지한다. 이미 시작한 시험의 새 유효 답은 서버 순서대로 처리하고, 이전 답의 재전송은 새 구간에 영향이 없다. 다음 회차 자동 배정 큐와 오답 큐를 혼동하지 않는다. 검사 T4/T5/T8.

## 화면·권한·복구

혼합 배정의 일반 문제는 기존 raw/exam-use 생성기의 최종 출처·보기·방향 검증을 재사용한다. 새 내부 삽입 함수는 기존 배정을 생성하거나 설정·학생·단원·감사 기록을 바꾸지 않고, 같은 관리자의 비어 있는 임시 배정에만 넣는다. 대상과 모든 보기의 원행·출제 가능 판정을 저장 거래 끝까지 잠근다. 전체 방향 개수는 한 번만 정하고 일반/오답 부분마다 다시 반올림하지 않는다. 전체 요청은 최소4문항이며 다른 뜻 때문에 나뉜 개별 시험은 1~3문항도 허용한다.

일반 문항의 뜻 미리보기는 식별자만 받고 서버에서 현재 검증 자료를 읽는다. 새 문항 승인 판정과 순수 원출현 확인값 계산을 저장과 공유하되 INSERT 표시·동결 참조 검사는 실제 새 문항 확정 경계에 남긴다. 과거 문항에 현재 승인 정보를 소급하지 않는다. 미리보기는 배정·본문·뜻 연결·신규 표시·원고 연결을 만들지 않으며 승인 근거 변경을 계획 확인값에 포함한다. 기존에 혼합이 처리하던 raw/exam-use 범위만 연결하고 새 자료 종류를 임의로 확장하지 않는다.

혼합 오답 후보는 예약되지 않은 pending 큐의 원문항·최초/재시험 단계·뜻·구간·현재 판을 유지한다. 교육용 단계는 큐의 원래 단계다. 예약 초안 화면은 기존 확인 후 예약 해제→pending 복구→새 배정으로 이동하는 동작을 유지하며, 기존 초안을 새 저장에 몰래 붙이거나 예약 큐를 소비하지 않는다. 이 설계 보완은 R5/D5/T4/T5/T6/T8/T10에 연결한다.

학생과 관리자는 기본 ‘현재 오답’, 보조 ‘지난 오답 이력’을 사용한다. 학생은 자신의 단어/뜻/횟수/출처만 받고 관리자 문항 ID·정답·다른 학생 자료는 받지 않는다. 관리자 선택은 미해결 뜻 단위다. 기존 공용 Tabs·Field·EmptyState·PanelLoadFailure와 각 기능의 상태 관리/전송 계층을 재사용한다.

성공한 0건에만 ‘현재 오답이 없습니다. 새로 틀린 단어가 생기면 여기에 모입니다.’를 표시한다. 장애는 ‘오답 목록을 불러오지 못했습니다. 다시 시도해 주세요.’, 오래된 선택은 ‘오답 목록이 바뀌었습니다. 최신 목록에서 다시 선택해 주세요.’로 안내한다. 저장 결과 불명에는 결과 확인을 먼저 제공한다. 권한 실패/로그아웃/학생 변경에는 개인 표시를 폐기하고 미전송 답 기록은 건드리지 않는다. 새 서버 조회 실패를 빈 목록으로 대체하지 않는다. T7/T9/T10.
