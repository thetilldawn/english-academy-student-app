# 수능 검수 원고 등록 지원 검증

기준 e48db66. 기존 검수형 가져오기에서 거절되던 수능을 별도 자료 종류로 지원한다. 실제 원PDF에 따라 2024~2026학년도는 2023~2025 시행으로 저장하며 11월과 25개 지문 범위를 함께 검증한다. 기존 월별 모의고사 원고·원뜻·독립 검토·승인 확인값 계약은 유지한다.

- T1/T2: 최종 관련 6파일 79검사 통과, 실패·보류0. 기존 모의고사, 수능 3개년, 원고/연도/학년도/월 불일치, 누락·중복 범위, 승인 없는 등록과 일반 경로 우회 거절, 같은 요청 재실행, 카탈로그·사전 보충정보·단어장 조합·필요 시 조회를 검사했다.
- T3: 가짜 기존 장문 자료, 학생, 배정, 배정 문항, 응시, 답안, 오답 큐를 실제로 각각 1개 이상 저장한 상태에서 정상·실패 수능 등록 전후 내용이 일치했다. 텅 빈 표의 일치로 대체하지 않았다. 실제 학생 자료는 읽거나 쓰지 않았다.
- T4: 타입, 변경 파일 lint, 기능 지도, 설계 관문, 기준 커밋 이후 9개 변경 연결 검사를 통과했다. 읽기 전용 독립 검토에서 보존 검사의 초기 빈 이력이 발견돼 실제 가짜 이력으로 보완했고 재검토했다. 화면 변경이 없어 이번 작업의 화면 검사는 해당 없음이다.

최종 실행은 `.codex-tmp/app05-regression.json`의 79검사다. 앞선 SQL 생성 문자열 오류와 SQL 별칭 충돌, 가짜 이력 준비 실패를 수정한 뒤 다시 검사했다. 초기 결과를 최종 통과 수에 더하지 않는다. 전체 앱 검사는 선행 APP04 기록과 구분한다. PGlite 단일 연결 검사로 실제 두 DB 연결의 동시성이나 운영 규모 성능까지 확인한 것은 아니다.

새 SQL은 함수 2개를 교체하며 원자료·학생 행을 변경하지 않는다. 외부 DB 적용, 실제 원고 승인/등록, 배포는 수행하지 않았다. 최종 입력 확인값과 완료 관문은 앱 작업 기록에 결속한다.
