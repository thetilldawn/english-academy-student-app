# 검토된 의미 충돌의 보기 제외

기준 cc56d06. 실제 수능 원고에서 description/묘사, context/상황처럼 정답으로도 해석될 보기가 재현되어, 검토한 방향별 제외 값을 출처의 불변 근거와 함께 전달했다. 원뜻·단어 목록·전역 발문 충돌 정책은 유지했다.

- T1/T4: 방향별 실제 표시값 제외, 같은 영어의 다른 출현, 3개 보기 부족, 가능 수와 실제 생성 일치, 0/50/100 비율과 순서, 유사도 후보 및 오래된 색인을 검사했다. 별도 커서 조회는 정책 없는 항목도 null로 반환하며 누락·중복·잘못된 대상·부분 실패를 거절한다.
- T2: 가짜 수능 등록 → 두 준비 API → 실제 생성 → 완전 계획 검증 → 구성 저장 → 실제 배정/오답 재출제를 연결했다. 정책 근거가 구성 문항의 해시에 포함되고, 정답 위치/발문 변조와 제외 보기 주입이 최종 저장에서 거절된다. 익명·학생의 근거 조회와 수능 정책 누락 등록도 거절한다. 마지막 통합7검사 통과.
- T3: 기존 가짜 학생·배정·문항·응시·답안·오답이 각각 있는 이전 보존 검사와, 새 수능 원문/원출현의 전후 일치를 통과했다. 원래 저장된 문항을 다시 쓰지 않았다.
- T5: 검사별 최신 결과 합산3,809통과/남은 실패0/기존1보류다. 타입·변경 파일 lint·기능 지도·현재 변경 연결·독립 검토·40페이지 격리 빌드를 통과했다. UI 모양이나 새 입력 흐름의 변경은 없어 이번 화면 검사는 해당 없음이다.

전체 첫 실행은3,715통과/20실패/74보류였다. 실패 및 실행되지 않은7개 DB 파일은 독립 검토에서 발견한 CRLF 본문 치환 문제와 연결되며 수정 뒤93검사를 전부 통과했다. 관련3파일29검사 재확인 뒤 정규화 일치1검사를 추가했고, 마지막 통합7검사를 통과했다. 초기 실패를 최종 통과로 덮거나 중복 합산하지 않았다. 기록은 `.codex-tmp/app06-full.json`, `app06-regression.json`, `app06-final-focused.log`, `app06-last.log`다.

Windows 줄바꿈을 실제 DB 함수에 남긴 상태로 마이그레이션을 검증했다. 기본 검사 도구의 줄바꿈 정규화에만 의존하지 않는다. 전체/축약 준비 API의 검토 정보 전달도 함께 검사했다. 저장 방어와 브라우저 출제기의 공백·전각·별표 처리 일치도 확인했다.

기존 학생과 자료를 변경하는 외부 실행은0이다. PGlite 로컬 단일 연결 검사는 운영 규모의 성능·실제 다중 연결 동시성·운영 관리자 화면 확인을 대체하지 않는다. 이번 완료는 앱 코드의 로컬 검증 범위이며 실제 수능 원고의 시험 사용 승인·자료 등록·DB 적용·배포와 별개다. 최종 입력 확인값은 작업 기록에 결속한다.
