# 직전대비 분류·학기 필터 검증

APP-20260913-01. 학교·학년·직전대비·학기를 함께 고른다. 교과서 필터 버튼은 제거했고, 원자료 종류와 교과서 표시는 유지한다. 고1 형용사500개도 직전대비 용도로 조회된다.

검사한 동작: 선택 학교의 자료만 표시, 고2·2학기에서1과/2과/모고3권, 검색0건/초기화, 같은 자료 재선택과 취소에서 통과점수85 및 기존 입력 유지, 학교 미기재/학기 미분류를 임의 추정하지 않음. 서버는 허용된 용도·숫자 학기만 공개하며 전체 메타나 원문 경로를 전달하지 않는다.

로컬 실제 Next 빌드를 가짜 읽기 전용 서버에 연결해 PC1365×900와 모바일390×844에서 확인했다. 자료 준비 응답만 가짜6권으로 교체했고 배정 저장·학생 응시·답 제출은 하지 않았다. 화면 겹침을 확인하여 선택창 안내를 짧게 수정한 뒤 재빌드/재촬영했다. 가로 넘침·브라우저 오류0, 초기화/선택/취소/초점복귀 통과.
