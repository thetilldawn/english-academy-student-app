# 내 단어장 — 화면과 학습 방식 검토안

사용자가 요청한 브레인스토밍의 원안이다. 2026-09-29 후속 `ㅇㅇ`로 아래 두 운영 기준을 확정하고 [순차 개발 계획](../work-orders/20260929_내단어장_순차개발계획.md)으로 이어간다. 아래 수치와 단어는 화면 설명용 예시이며 실제 학생 자료가 아니다. 구현·검증의 현재 근거는 단계별 지시서와 검증 기록을 따른다.

2026-09-29 후속 요구를 포함했다. 학생의 횟수별 조회·자율 연습 시험 생성, 교사의 같은 자료 조회·학생별 오답 일괄 배정은 필요한 기능으로 확인됐다. 구체 집계/운영 규칙은 아래 확인 항목에 구분한다. 기존 수리 작업의 완료 상태를 다시 열지 않으며, 새 기능 작업 등록과 구현은 결정 확인 후 진행한다.

## 먼저 제안하는 방향

‘내 단어장’을 새 단어를 수동으로 모으는 곳보다 **내가 틀린 단어를 다시 익히는 곳**으로 시작하는 편이 현재 목적에 맞다. 첫 화면에서 단어·뜻·틀린 횟수가 바로 보이고, 원하는 단어를 골라 짧게 연습할 수 있게 한다. 점수판이나 긴 설명은 넣지 않는다.

```text
내 단어장                           [연습하기]
틀린 단어 38개 · 두 번 이상 틀림 12개

[틀린 횟수 ▾]  [단어장별 ▾]
[단어 또는 뜻 검색                  ]
최근 틀린 순 ▾          [영어 가리기] [뜻 가리기]

□ accurately                 [듣기]
  정확하게
  첫 풀이에서 3번 틀림 · 최근 9/29
  심석고2 · 2024~2025 모고 …  [출처 펼침]
────────────────────────────────────
□ mentality                  [듣기]
  사고방식, 정신 상태
  첫 풀이에서 2번 틀림 · 최근 9/28
────────────────────────────────────
              [10개 더보기]

[선택한 단어로 시험 만들기] [현재 조건으로 시험 만들기]
포인트에 반영되지 않아요
```

화면은 모바일 한 열이 기본이다. PC에서도 긴 범위를 매번 펼치지 않고 같은 순서를 유지한다. 첫 10개·10개 더보기, 최근 오답순을 기본 제안으로 둔다. 영어와 뜻을 동시에 가리지는 않는다. 단어 출처가 길면 두 줄로 줄이고 필요한 경우에만 펼친다.

## 현재 있는 것과 새로 필요한 것

| 구분 | 확인된 현재 구조 | 제안 |
| --- | --- | --- |
| 오답 기록 | 학생·단어·틀린 시각·첫 풀이/재시험 구분·사전 연결을 저장 | 기존 기록을 읽어서 사용. 과거 답안을 새로 계산해 덮어쓰지 않음 |
| 반복 횟수 | 관리자 조회는 첫 풀이 오답 문항 수와 최근 오답을 집계하며 전체·1회·2회 이상 필터가 있음 | 학생·교사가 같은 집계를 사용하고 횟수 조건을 확장 |
| 단어 학습 | 배정별 단어장에서 영어/뜻 가리기·발음 듣기 제공 | 표시와 음원 조회 재사용. 누적 오답장 진입은 새로 필요 |
| 연습 시험 | 정규 답안 저장은 오답 상태와 다음 배정에도 연결됨 | 화면·문항 생성 계산은 재사용하되 연습 결과 저장은 별도 경로 |
| 본인 확인 | 관리자 조회는 관리자만 사용하도록 막혀 있음 | 기존 관리자 주소를 학생에게 열지 않음. 서버가 현재 학생을 확인하는 본인 전용 조회 필요 |

가장 중요한 점은 **포인트만 0으로 만드는 것으로 끝나지 않는다는 것**이다. 현재 정규 답안 저장은 복습 상태와 후속 시험에도 연결된다. 자율 연습이 이것을 바꾸지 않게 별도로 처리해야 한다.

## 첫 버전 제안

1. 배정 시험에서 틀린 단어를 자동으로 모은다. 수동 단어 추가·친구 공유·순위는 첫 버전에서 제외한다.
2. 단어별 횟수와 최근 오답일을 보며 외운다. 예문·영영풀이는 기본 목록을 길게 만들지 말고 단어를 펼쳤을 때 보여 준다. 시험에 사용한 뜻과 검증된 학년/출처별 자료를 우선하고 임의로 새 뜻이나 발음을 생성하지 않는다.
3. 선택한 단어 또는 현재 조건의 단어로 짧게 연습한다. 화면에 보이는 10개와 필터에 해당하는 전체 단어를 혼동하지 않도록 버튼 문구를 구분한다. ‘현재 조건에서 10개’는 서버에서 해당 조건 전체를 기준으로 고른다.
4. 결과는 ‘10개 중 8개 정답’과 ‘틀린 2개 다시 연습’ 정도로 보여 준다. 정규 점수·포인트·출석·배정 완료·다음 회차 공개에는 영향을 주지 않는다.

| --- | --- | --- |

| 익힌 단어 처리 | 원래 오답 기록을 보존. 자동 ‘익힘’ 판정은 후속 검토 | 몇 번 맞히면 익힘인지 정하지 않았으므로 이번 요청에 임의로 포함하지 않음 |

## 화면의 세부 동작 제안

- 여백·색상·글꼴은 기존 `--pad`, `--space-3/4`, `--ink`, `--muted`, `--line`, `--card`, `--font-kr`를 사용한다. 터치 버튼은 기존 최소 44px, 767px 이하에서는 한 열이다. 새 디자인 체계를 따로 만들지 않는다.
- 제목 → 필터 → 검색 → 가리기 → 단어 선택/듣기 → 더보기 → 연습 시작 순으로 키보드 이동한다. 체크박스와 듣기 버튼에는 단어 이름을 포함한 이름을 준다. 뜻을 가리면 보조기술에도 뜻이 그대로 읽히지 않게 한다.
- 처음 0개면 ‘아직 틀린 단어가 없어요’. 검색 0개면 ‘조건에 맞는 단어가 없어요’. 요청 실패를 0개로 표시하지 않는다.
- 더보기 실패는 이미 본 단어와 선택을 보존하고 다시 시도한다. 학생 변경·로그아웃·권한 거절이면 이름과 목록을 즉시 숨긴다. 계정이 다른 기기에 선택 상태를 공유하지 않는다.
- 뜻·예문·음원이 없으면 해당 항목만 없다고 표시하고, 선택지 부족이면 중복 오답을 만들지 않는다. 같은 철자라도 뜻이 다르면 출처와 뜻을 확인할 수 있어야 한다.
- 연습 시작을 반복해서 눌러도 하나만 시작한다. 연습을 끝내거나 중간에 나와도 정규 시험에는 영향을 주지 않는다. 속도나 익힘 판정 때문에 고정된 대기를 새로 넣지 않는다.

### 횟수 필터 제안

- 빠른 선택은 `전체 / 1회 / 2회 / 3회 / 4회 / 5회 이상`, 추가로 `3회 이상` 또는 `2~4회`처럼 직접 범위를 지정한다. 이 세부 모양은 화면 시안 제안이다.
- 단어장 조건과 함께 쓸 수 있게 한다. 정렬은 최근 틀린 순/많이 틀린 순을 구분하고 같은 횟수는 최근 시각·고정 식별자로 순서를 유지한다.
- 현재 단어장 필터는 해당 단어의 **전체 누적 횟수**로 판정한다. 선택한 단어장에서 틀린 횟수만 다시 센다고 표시하지 않는다. 학생·교사의 숫자와 배정 후보가 같은 기준이어야 한다.
- 필터는 서버 전체 자료에 먼저 적용하고 첫10개/10개 더보기로 읽는다. 화면에 보이는 10개만 걸러서 전체 결과처럼 보여주지 않는다.

### 교사의 일괄 배정 흐름 제안

```text
학생 선택 → 오답 조건 → 학생별 미리보기 → 시험 조건 → 일괄 배정

조건: 3회 이상 틀림 / 선택 단어장
가상 학생 A   해당 18개 · 출제 가능 18개
가상 학생 B   해당  7개 · 출제 가능  5개 · 제외 이유 2개 확인
가상 학생 C   해당  0개 · 배정할 단어 없음
```

- 단어장 전체 오답을 다시 배정하는 기존 기능과 ‘횟수 조건으로 고른 특정 단어’ 배정을 구분한다. 현재 미해결 큐만을 전체 누적 오답장으로 대신하지 않는다. 해결된 과거 오답도 다시 연습할 수 있는 후보 설계가 필요하다.
- 교사는 미리보기에서 학생별 실제 단어와 수량·출제 불가 이유를 확인한다. 0개이면 시험을 만들지 않으며, 조회 실패를 0개로 표시하지 않는다. 일부 단어 제외는 기존 명시 확인 방식을 유지한다.
- 현재 필터 전체를 대상으로 하는 경우에도 서버가 각 학생의 후보를 확정한다. 학생/조건/문항 자료가 바뀌면 옛 미리보기로 저장하지 않는다. 조회 결과와 저장된 단어가 일치해야 한다.
- 단어 수·출제 방향·순서·시간·공개/마감은 기존 시험 설정 부품의 재사용 가능성을 검토한다. 학생 자율 연습에 교사의 정규 배정 권한을 그대로 열지 않는다.
- 반복 클릭·시간 초과 뒤에는 저장 결과를 먼저 확인한다. 이미 만들어진 시험을 다시 만들지 않는다. 정상 저장 시 영향받은 학생의 목록만 갱신하고 모달을 닫는 것만으로 목록을 새로 읽지 않는다.

자동 ‘익힘’ 판정·몇 번 정답 후 자동 숨김은 사용자 추가 요구가 아니므로 첫 구현에 임의로 넣지 않는다. 이후 맞힌 단어도 과거 오답 기록은 보존한다. 연습 기본 문항 수 등 위 첫 버전 제안은 아직 승인된 설정이 아니다.

### 설계 확인과 검사 기준

- T1: 횟수 경계(1·2·3·5), 범위 조건, 단어장 조건, 전체 개수/페이지 경계를 검사한다. 학생·교사가 같은 조건에서 같은 단어와 횟수를 보아야 한다.
- T2: 학생A/B의 오답을 섞지 않는다. 다른 학생 식별자 위조는 거절하고 자율 연습에서 정답을 미리 보내지 않는다.
- T3: 학생 자율 연습은 포인트·정규 시험 완료·다음 회차·기존 복습 큐를 바꾸지 않는다. 연습 전후 보존 검사와 중단/재개/중복 시작 검사가 필요하다.
- T4: 교사 일괄 배정은 0개·출제 불가·권한 부족·대상 변경·저장 결과 불명확을 구분하고 학생별 미리보기와 실제 배정 결과를 대조한다. 새 개인별 오답 시험의 포인트0과 기존 정규 시험의 포인트 규칙 보존을 검사한다.
- T5: PC/모바일의 필터, 첫10개/더보기, 선택 보존, 정상0개/조회실패, 로그아웃 숨김, 실제 시험 생성/결과 확인까지 가짜 자료로 먼저 검사한다.

최초 검토 당시에는 화면 설계·시스템 설계 지침으로 공유 집계, 권한 분리, 학생별 미리보기와 실패 복구를 정리했으며 실제 시험·학생 자료·운영 앱·작업 대장을 변경하지 않았다. 이후의 계획 등록과 공통 조회 구현은 별도 단계 기록이며 이 과거 설명을 현재 미구현 상태로 읽지 않는다.
