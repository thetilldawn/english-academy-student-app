## 자료와 시험의 보존 방식

- 연도·월·유형·문제번호는 같은 원출처의 범위에 연결한다. 단어에 흩어진 태그를 섞어서 존재하지 않는 출현을 만들지 않는다.
- 저장 시 범위·원자료 버전·원출현·포함/제외·확인값을 고정한다. 새 자료판이나 다른 월이 추가되어도 저장된 책은 바뀌지 않는다.
- 범위를 먼저 고른 뒤 검토된 같은 표제어·품사·뜻만 한 출제 대상으로 정리한다. 검토되지 않은 행에는 독립 식별자를 주며 동일성 승인 근거는 빈 값으로 보존한다. 같은 사전 ID만으로 합치지 않는다.
- 원출현을 모두 보존한다. 제외 행은 새 단어 ID나 동일성 승인 근거 없이 제외 상태로 남긴다. 시험 저장 시 원뜻·출처·발음과 중복 판정값을 별도 고정한다.
- 새 단어 ID의 원래 단어·자료판·해시를 검증하고 기존 발음 선택 함수를 그대로 사용한다. 연결 조회가 실패하면 재시도 오류를 반환하며 발음을 조용히 누락시키지 않는다.
- 영영풀이·예문 등 기존 학습 필드는 원출처의 값을 보존한다. 새 책의 현재 출제 모드는 교재 뜻이며, 빈 보충 필드를 새로 작성하거나 승인한 작업은 아니다.

새 관리자 조회/저장 경로는 비공개·캐시 금지이고 원천을 저장 거래 안에서 다시 검증한다. 같은 저장 요청의 재시도는 같은 결과를 돌려준다. 응답이 불명확한 뒤 인증 오류가 나더라도 같은 요청 키를 보존한다. 뒤로가기·닫기는 저장 중 보호를 공유하며 이전 인증 소유자의 늦은 응답을 적용하지 않는다.

3. 기존 오답 대기열의 사전 단위 유일 규칙 자체는 유지한다. 같은 영어의 다른 뜻을 다시 연결하는 보호는 추가했지만 운영의 오래된 오답 대기열과 새 책을 함께 사용하는 검증은 남아 있다.
4. 원본 사전·음원·PDF와 학생·시험 기록은 변경하지 않았다. 자료 등록 수를 고유 단어 수나 실제 방향별 출제 수로 표시하지 않는다.

## 최종 확인값

요구·결정·설계·검사10개를 연결한 로컬 완료 관문이 통과했다. 관련 구현 입력1,058개의 확인값은 `0215844853fc495512d0bd3d2390efe7c3786d801ebb747b39eaa804ae037336`이다. 새 webpack 빌드도 TypeScript·37페이지 생성을 통과했다. 이번 새 빌드의 종료 실행기가 하위 프로세스 확인에 실패하여 확인된 해당 프로세스만 종료하고 기존 `.next`를 수동 복구했다. 마지막 포트3037·3038·3040은 모두 닫혔다. 앞선 UI 검사 서버의 정상 종료와 이번 수동 정리는 다른 실행 기록이다.
