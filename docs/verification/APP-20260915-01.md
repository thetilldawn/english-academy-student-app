# 누락 발음과 앞 공백 처리본 연결 검증

누락 발음은 검토 원천으로 추가하고 기존 생성 음원의 처리본은 원음·품사·한글 표기를 보존해 새 자산으로 연결한다. 기존 학교 원고·문항·학생 자료를 변경하지 않고 새 연결판으로 전환한다.

R1~R4 / D1~D4 검사: 신규 통합23, 기존 연결33, 학교60으로 총116개 통과. 타입 검사·변경 파일 lint 통과. 독립 검토가 지적한 JSON null 처리, 기존 분류 예외 보존, 측정값 숫자 강제, 새 음원과 별도 표기 대응을 수정한 최종 SQL을 재검토했다. 오류0이다.

공유 발음 표시/재생 함수는 바꾸지 않는다. 조회는 identity의 음원·표기·구간 계약을 사용하며 강세 원천 필드를 임의로 CMU 값이라 표시하지 않는다. 일반 묶음 업로드 도구에는 새로운 검토 전용 강세를 허용하지 않고 제한된 private 승인 경로에서만 받는다. frontend 재배포는 필요하지 않다.

자료/운영 증거는 영어 구역의 발음보완 폴더에 별도 보관한다. 실제 학생 음원 snapshot은 보존한다. 자동 검사는 실제 사람의 청음이나 관리자 화면 확인을 대체하지 않는다.
