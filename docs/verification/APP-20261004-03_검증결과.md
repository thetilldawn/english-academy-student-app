# 새 시험의 중복 상태 저장 제거 결과

운영 반영 완료. 신규 기기시험은 공용 뜻별 상태를 갱신하고, 맞은 단어까지 옛 단어장별 상태에 중복으로 저장하던 호출을 제거했다. 기존 관리자·학생·학습 조회 세 곳도 같은 뜻 키의 현재 상태를 우선 읽는다. 다른 뜻의 오답은 유지한다.

기존 학생 기록·옛 시험 쓰기·접수/시각·점수·포인트·함수 권한과 응답 형태를 보존했다. 기존 데이터 삭제와 접수 규격 추가는 없다. 앱 화면/배포 파일 변경이 없는 DB 수리이며 운영 앱51e0141은 그대로 동작한다.

관련 기능 검사55개(기기시험33·적용/보존2·구형 조회20), 타입/기능 지도/설계 검사, 독립 검토를 통과했다. 새 검사 자료의 필수 범위/응시 연결과 응답 키를 바로잡은 뒤 통과했으며, 제품 SQL의 확인값은 변경하지 않았다. 기존 전체 검사와 용량/부하 실험은 반복하지 않았다.

같은 SQL을 검토 환경에서 먼저 적용·조회한 뒤 운영 migration **20261004045306**으로 적용했다. 함수4개의 최종 본문이 검토 환경과 같고 소유자·실행권한·설정이 유지됐다. 운영의 기존 응시89·문항7,617·단어장 상태4,168·오답 사건1,901·포인트 사건3,930·합계4, 총17,709행의 내용 확인값이 전후 동일했다. 실제 학생 시험 생성/답 제출은 하지 않았다.

현재 완료 결과와 개별 접수에는 재접수 보호에 필요한 번호/답 확인값과 당시 응답이 남는다. 전체 결과를 문항마다 복사하는 구조라는 이전 추정은 현행 코드 대조로 정정했다. 이미 배열 중복을 제거한 규격을 다시 바꾸지 않았다.
