# 시험 응답 대기 보완 검증

F01 원인은 응답 헤더를 받자마자 2초 제한을 해제하고 JSON 본문을 무제한 기다리던 코드였다. 공용 요청 제한을 재사용하여 답 제출·상태 복구·피드백 재개를 헤더+본문 합산 2초로 바꿨다. 만료는 기존 호출자가 Response.ok만 사용하므로 헤더까지만 제한한다.

시험 기능 6파일115검사 통과, 독립 실행은 공용 제한까지 7파일122검사 통과. 취소를 무시하는 본문/헤더, 늦게 도착한 본문, 1.5초 뒤 헤더, 성공/오류의 잘못된 JSON, 만료 Response 계약과 타이머 제거를 검사했다. 타입/lint/지도 통과.

현재 학생 검증·진행 시험 no-store·성공 응답 스키마·100ms 답 확정·750ms 정답·250ms 결과·150ms 음성 여유·문제/전체 시간은 변경하지 않았다. 기존 저장 실패→서버 상태 복구와 재개 실패→GET 복구도 보존했다. 새 자동 답 재전송·DB 변경·학생 쓰기·외부 배포는 없다.

입력과 해시는 같은 번호 작업 기록에 저장한다. UI/서버 코드를 바꾸지 않은 전송 수리라 새 브라우저 시나리오는 추가하지 않았고 실제 시험 부품 회귀 검사로 확인했다. 전체 빌드는 순차 수리 통합판에서 다시 수행한다. 다음 입력은 F04 최초 저장 응답 유실과 APP04이며 현재 상태·순서는 루트 대장만 따른다.
