# 종류별 단어장과 화면 정리 — 검증 결과

2026-10-03 / APP-20261003-01 / M07. 수행평가·직전대비·모의고사·기타를 독립된 종류로 저장하고 검색·생성·배정 표시까지 전달하도록 구현했다. 로컬 구현과 검토 DB 검증 결과이며 운영 앱에는 아직 배포하지 않았다.

## 달라진 동작

- 종류와 교사의 자유 설명을 분리했다. 기존 미분류 자료는 ‘분류 확인’으로 남기며 임의로 직전대비나 기타로 바꾸지 않는다. 새 구성·복사는 종류 선택이 필요하다.
- 처음에는 저장한 구성의 요약을 보여 준다. 자료 묶음을 직접 편집할 때만 해당 연도·월·DAY·과 조건을 연다. 교과서와 모의고사를 섞은 범위, 숨겨진 학교 정보, 이름, 순서, 제외 항목을 유지한다. 휴대폰 종류 탭은 2열이다.
- 이름·종류만 바꿀 때 새 내용판을 만들지 않는다. 과거 판에서 시작했다면 저장 충돌을 복구해도 그 판을 유지한다. 표시한 저장 범위에서 순서·단어 제외를 바꾸면 최신 원자료가 몰래 추가되지 않는다. 수동 저장 태그도 보존한다.
- 목록 표시정보만 갱신할 때 배정의 자료·단원·문항 수·출제방식·열린 창을 유지한다. 저장은 성공했지만 목록 갱신이 실패한 경우 DB 저장을 반복하지 않고 목록 연결만 다시 시도한다.
- 원자료 항목·포함 항목·고유 단어·뜻별 학습 항목·실제 출제 가능 문항 수를 구분한다. 공용 참조가 깨지면 오류로 처리하고, 구형 자료에서 확정할 수 없는 수량을 0으로 표시하지 않는다.

## 실패를 처리한 내역과 한계

첫 전체 실행의 검사 제한시간 초과와 읽기 계약 파일명 때문에 생긴 구조 검사 오류를 고친 뒤 최종 전체 검사를 통과했다. 구조 보호선의 허용 목록은 늘리지 않았다. 실제 화면에서 발견한 모바일 탭 줄바꿈도 수정했다.

첫 원격 동시 검사에서는 제한된 실행 환경의 네트워크가 거절되어 SQL 거래가 취소됐다. 외부 연결이 허용된 동일 가짜 검사로 재실행했고 PID/Lock 증거가 있는 세 사례만 결과에 포함했다. 네 종류 왕복 검사의 첫 시도는 모든 과거 내용판을 한 덩어리로 비교하다 통신 제한시간을 넘겼다. 검사 대상 가짜 판의 행별 확인값으로 바꾸고 다시 통과했으며 실제 제품 쿼리 실패와 구분한다.

관리자별 학생 분리는 이번 작업이 아니다. 기존 전역 관리자 범위를 유지한다. 음원 내용 검수는 사용자가 학생들에게 맡기기로 했으므로 추가하지 않았다. 운영 배포·실제 오래된 자료 정리·물리 용량 감소는 아직 수행하지 않았다.
