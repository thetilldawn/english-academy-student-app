# 공용 사용값과 출처 참조 검증

APP-20261001-06 / M01. 원자료에서 선택한 뜻·예문·발음을 공용 불변 값으로, 출처와 선택 근거는 별도 불변 연결로 저장하도록 구현했다. 새 범위 등록과 새 단어장 구성부터 적용한다. 기존 사전/학생/배정/시험 기록과 준비 중인 판은 이전하거나 삭제하지 않았다.

## 보존과 호환

- 실제 원행 ID, 문자열 사전 ID, 옛 UUID, 원출현 ID, 의미 ID와 원본 확인값을 구별해 보존한다. 큰 정수 앱 ID는 문자열로 연결한다. 검토 자료의 payload 안에 있던 ID도 보존하며 원래 dictionary=null을 임의 사전 연결로 바꾸지 않는다.
- 승인된 의미는 기존 승인 행과 원래 키 계산식으로만 공유한다. 미승인 자료는 원출현·판·뜻/품사 기준이며 철자만으로 합치지 않는다. 발음/예문만 바뀌어도 같은 학습 의미가 쪼개지지 않게 했다.
- 저장값과 출처 연결은 내용 확인값+본문 대조 후 재사용하며 기존 행을 덮어쓰지 않는다. 원문 전문·사전 전문·proof.value·음원 본체를 새 참조 저장에 복제하지 않는다. 목록/검증용 작은 원행 색인과 실제 단어 표의 9개 호환 표시 열은 남는다.
- 잘못된 새 참조는 실패한다. 최신 사전·빈 뜻·기존 형식으로 우회하지 않는다. 기존 실패 영역은 “이 자료의 연결을 확인해야 합니다. 다른 자료로 바꾸거나 관리자에게 알려 주세요.”를 표시하고 선택/확인된 진행 상태를 보존한다.
- 구형 sparse SQL 자료는 읽기·비교·이미 시작한 작업에서 보존한다. 필수 항목이 없는 구형 자료로 새 참조를 만드는 작업은 명시적으로 거절한다. 기존 앱/등록기 계약도 전체 필드를 요구했다. Preview 원범위 22,324행은 필수 키 누락0·다른 형식0이다. 운영 동일 집계는 연결 시간 초과2회로 미확인이며 운영 적용 전 확인한다.

## 외부 반영과 남은 경계

운영 자료 형태 조회 재확인, 같은 환경의 새 앱 배포·인증 관리자 검증은 배포 단계에서 수행한다. 기존 M11의 종료 SQL도 아직 미적용이다. 새 참조가 생긴 뒤 참조를 모르는 옛 앱/읽기 함수로 되돌리지 않는다. 권한이 확인된 현재 배정을 통해서만 공용값을 읽으며 자료 공유가 학생 기록 공유로 이어지지 않는다. 전체 유지보수 완료·운영 용량 절감·최대 학생 수를 이 단계 결과로 선언하지 않는다.
