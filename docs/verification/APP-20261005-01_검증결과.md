# 시험 화면과 자료 재사용 보수 결과

2026-10-05 · APP-20261005-01. 기존 사전·학생 답·배정 키를 유지한 화면 및 조회 경로 보수다.

## 반영 내용

- 목록을 유지하는 준비 모달에 회전 표시와 **취소**를 제공한다. 취소 후 늦은 응답이 도착해도 시험으로 넘어가지 않는다.
- 시험 중지 → 배경 흐림·좌측 시험 중단/우측 시험 계속. 중단은 답 삭제·시험 포기가 아닌 목록 복귀다. 제한 시간은 계속 흐른다.
- 카드 위 시간 막대는 남은 비율에 따라 초록/노랑/주황/빨강으로 변한다. 빨강이며 3초 이하면 초당3회 부드러운 점멸, 움직임 줄이기 설정이면 점멸하지 않는다.
- 정오답은250ms 표시한다. 막대는100ms ease-in-out으로 꽉 찬 초록/빨강으로 바뀌고 다음 문제까지 유지한다. 기존100ms 기기답도 서버가 계속 받는다.
- 단어보기의 기존 전체 본문 반복 조회를 작은 권한·배정 판 확인으로 바꿨다. 같은 계정·배정·판의 목록과48시간 공용 본문을 재사용한다. 재방문·재hover 본문 요청0회, 누락/만료/배정변경은 필요한 자료를 다시 받는다.
- 시험 중 뒤쪽 알림·세션 갱신·마감 자동 새로고침을 쉬게 한다. 문제마다 서버에 답을 보내는 경로를 추가하지 않았다.

## 확인 근거

- 변경 기능 및 DB 호환 검사:40파일389검사 통과. 별도 구조·조회 경로3파일70검사 통과.
- 중단 상태를 기존 상태 관리에 합친 마지막 수정 뒤 화면2파일99검사, 타입 검사,51파일 ESLint 통과.
- 기능 지도·설계 기록·UI 구조 검사와 운영 방식의 로컬 빌드 통과. 공용 오프라인 파일25개 확인.
- 실제 Chromium·실제 로컬 빌드·기기 저장소, 가짜 HTTP 응답으로 PC와390px 화면 확인. 중단/계속/목록 복귀, 정오답 막대,257.1ms 표시, 시험 중 요청0건, 오류0건. 실제 배경 blur(5px),3Hz ease-in-out, 움직임 줄이기 점멸 없음.
- 실제 학생의 시험 시작·답 제출은 검사에 사용하지 않았다. 화면 기록은 가짜 학생이다.
- 검토 DB 변경20261004165331: 기존100ms·새250ms 허용, 첫 문항0 조건 확인. 새 작은 접근 조회는 service 전용, anon/authenticated 실행 권한 없음. 새 테이블/사전/본문 복사 없음.
- 단어자료/접수 호환 읽기와 화면 분리 경계는 읽기 전용 독립 검토를 거쳤다.
