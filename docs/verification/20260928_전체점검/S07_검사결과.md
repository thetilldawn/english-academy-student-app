## 알림 재현

실학생 없는 PGlite 최종 스키마에 날짜 없는2회 배정 관계를 생성했다.
두 번째 회차는 waiting_initial인데 최초 알림이2개 반환됐다(기대1).
첫 풀이 완료(initial_completed_at 설정, 재시험 전 review 단계) 후 두 번째가open인 것을 확인했지만 신규 알림은0(기대1).
시험 공개 여부 판정과 알림 판정이 어긋난다. 운영 자료에는 시험/알림을 생성하지 않았다.
이 재현은 실제 운영 역할/RLS 또는 복수 DB 연결 경합을 검증한 것이 아니다.

추가 설계 공백: DB 수령기록을 먼저 쓰고 화면 전달 전에 응답이 유실되면 재요청은0을 반환한다.
표시 확인 또는 미확인 알림 재전달 방식이 없다. 이 항목은 별도 정책/설계 검토 후보이며 F07에 섞어 결함 수를 늘리지 않는다.
