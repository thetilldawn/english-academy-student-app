# S07 — 학교 일정·포인트·알림

## 입력

map:feature school-schedules, learning-points, notifications와 가까운 AGENTS.
학교 일정은 entrypoint가 비어 있어도 지도 소유 파일과 실제 호출자를 따라간다.
일정 원천/검토본/운영 자료의 경계, 포인트 집계와 알림 API 계약을 확인한다.

## 검사 순서와 기대 결과

- S07-A 일정: 학교/학년 미선택, 정상 0건, 기간/학기 경계, 겹친 일정, 수정/취소된 일정, 조회 실패를 구분한다.
  정상 빈 결과와 원천 확인 실패의 문구·재시도를 다르게 보여야 한다.
  검토 후보가 승인 없이 운영 일정으로 노출되거나 사용자가 고른 조건이 늦은 응답에 덮이지 않는지 검사한다.
- S07-B 포인트: 최초/중복 완료, 재시험, 실패/응답 유실 후 재처리, 날짜 경계·음수/누락 입력을 격리 자료로 확인한다.
  포인트가 두 번 적립되거나 다른 학생의 집계가 섞이지 않고 결과와 표시 합계가 맞아야 한다.
  실제 서버 규칙과 UI가 따로 계산하여 어긋나는지도 확인한다.
- S07-C 알림: 목록·읽음 상태·페이지 경계·중복 이벤트·권한 없음·전송 실패/재시도 계약을 모의 응답으로 검사한다.
  구현되지 않은 외부 발송을 구현 완료로 보지 않는다. 실제 푸시/문자/이메일 전송은 하지 않는다.

## 방법과 종료 기준

기능별 단위/컴포넌트/Route·DB 검사를 실행하고 실제 호출 경로와 대조한다.
생성/수정/읽음 처리도 운영 쓰기이므로 가짜 자료에서만 수행한다.
현재 구현/미구현/문서상 계획/미확인 외부 연결을 구분한다.
