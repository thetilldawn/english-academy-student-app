# S06 — 단어장·예문·영영풀이·발음

## 입력

map:feature wordbook-compositions, map:owner shared-quiz-domain, 단어장 API/서버 진입점과 가까운 AGENTS.
맥락 선택·보기 생성·원문/출처·음원 교정 계약의 기존 검사, 앞선 발음 교정 근거.
실제 원문과 학생 자료는 앱 저장소나 보고서에 복사하지 않는다.

## 검사 순서와 기대 결과

- S06-A 단어장: 범위 필터·복수 범위 합침·중복 출현·보류/미검수 항목·빈 결과·페이지 전환을 검사한다.
  자료가 있다는 것, 등록되었다는 것, 배정 가능이라는 것을 구별한다.
  템플릿 생성/재사용/변경/삭제를 모의 API와 격리 DB로 확인하고 기존 시험 문항/답안이 바뀌지 않는지 검사한다.
  아직 시행되지 않은 연도/월, 누락 태그, 같은 제목 다른 내용도 별도 사례로 둔다.
- S06-B 문항: 학년·학교·학기/고사별 예문/영영풀이 선택 순서와 기본 사전 대체 규칙을 실제 계약에서 확인한다.
  모두 일치/일부 일치/서로 충돌/태그 없음/사전 없음으로 가짜 항목을 만들어 기대 출처와 선택 출처를 대조한다.
  학생과 단어장 학년 차이의 선택 기준이 합의되지 않았다면 임의 규칙을 만들어 정답 처리하지 말고 검토 필요로 남긴다.
  뜻/영영풀이/영어 양방향, 품사·동형어·유의어·빈 필드, 선택 범위 밖 오답, 두 개의 정답 가능성을 검사한다.
- S06-C 음원: mentality, accurately, fiercely 같은 기존 신고 사례와 일반/다단어/품사 다른 항목을 점검한다.
  사전 ID만 같은 경우가 아니라 표제어·품사·원출처·승인 교정 조건이 맞는지 검사한다.
  잘못 연결된 음원, 음원 없음, 외부 요청 실패에서 다른 단어 음원을 대신 재생하지 않는지 확인한다.
  URL 응답/연결 일치/버튼 재생/사람이 들은 발음 정확성을 분리한다. 청음하지 못한 것은 미실행이다.

## 방법과 종료 기준

가짜 문항으로 선택·정답/보기 계약을 전수 조합하고, 실제 자료는 허용된 최소 읽기 전용 대조와 익명 집계만 사용한다.
표본으로만 확인한 음원을 전체 정상이라고 보고하지 않는다. 기존 승인 음원/원사전 값을 바꾸지 않는다.
