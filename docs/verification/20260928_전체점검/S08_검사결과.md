# S08 권한·DB·캐시·외부 연결

검사일: 2026-09-29. 운영 DB는 메타정보만 READ ONLY 거래로 조회했다. 학생 정보/답안 내용 열람·변경 없음.

## 오류와 보호 경로

- F08: 학생 세션 DB 조회 실패가 실제 세션 없음과 같은null로 반환된다. 인증 장애와401을 구분해야 한다.
  관리자 getAdminContext 호환 경로도 장애를null로 바꾼다. 단어장3API의 기존503 보완을 앱 전체 완료로 확대하면 안 된다.
- F09: 학생 로그아웃 DB철회 error를 무시하고 쿠키를 지운 뒤 성공 반환. 모의 오류로 재현.
  관리자 signOut 반환error 무시도 코드에서 확인했다. 관리자 쿠키가 항상 남는다고 단정하지 않는다.
- 결과 DB오류→404는 S03의 F03과 같은 원인이므로 중복 집계하지 않는다.
- 다른 학생 응시/결과는 studentId+attemptId 동시 필터. 미응답 정답/음원 힌트 숨김.
- 개인 목록은 사용자ID·로그인세대·현재요청을 대조하며 실제 권한실패에 폐기하는 경로가 있다.
  단 학생 완료내역 F02는 별도 남은 경로다. 모든 캐시가 안전하다는 결론이 아니다.

  [경고 의미](https://supabase.com/docs/guides/database/database-linter?lint=0029_authenticated_security_definer_function_executable).
