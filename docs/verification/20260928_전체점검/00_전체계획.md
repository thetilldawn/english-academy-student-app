## 검사 범위와 권한

- 이번 승인은 **검사·재현·리포트**다. 발견한 결함의 앱 수정, 새 배포, DB 구조/권한/자료 변경, 운영 테스트학생 생성·응시·답안 제출은 하지 않는다.
- 재현은 로컬 가짜 자료와 격리 임시 DB를 우선 사용한다. 필요한 운영 확인은 좁은 읽기 전용 조회만 한다. 인증된 화면을 못 보거나 청음 등을 못 하면 미검사로 적고 다른 검사는 계속한다.
- `test:e2e:authenticated`, E2E/fixture 생성·정리, import/publish, db reset/push, migration 적용 명령을 일반 검사처럼 자동 실행하지 않는다. 특히 E2E는 학생·배정·답안 생성과 삭제가 가능하다.
- 로컬 화면 도구는 .next를 이동하고 복원할 수 있다. 기존 산출물/다른 세션을 먼저 확인하고 안전한 전용 임시 위치를 사용한다. 정리 대상 경로를 확인하지 않은 삭제 금지.
- 학생·단어 원본·인증값을 앱 Git, 로그, 보고서에 복사하지 않는다. 보안/비용/공개 범위의 새 결정이 필요하면 해당 검사만 미실행 사유로 남긴다. 검사 통과를 만들려고 기준·테스트·과거 결과를 고치지 않는다.
