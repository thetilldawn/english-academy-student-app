## 자동검사·코드 대조

학생 검색/학교·학년/빈 결과/더보기/늦은 이전 응답, 개인 캐시 로그인 세대,
상세 404/권한 오류·입력 보존·저장불명확·무효화의 기존 컴포넌트/Route 검사는 전체 실행에 포함된다.
모달 닫기만으로 router.refresh를 호출하지 않는 경로와 실제 조회0을 함께 확인했다.

등록/수정/차단/삭제의 실제 관리자 저장, 긴 이름 전 화면, 마지막 페이지의 실제 브라우저 반복,
이전 목록보다 최신인 상세·404·401·503의 모든 화면 조합은 브라우저 미실시다.
기존 모의 검사가 통과했다는 것과 운영에서 직접 저장했다는 것을 구별한다.

이번 브라우저 성공을 ‘모든 캐시·모든 상세 오류 정상’으로 확대하지 않는다.
