# 배정 조회와 창 전환 수리

확인된 원인은 범위 분류 메뉴에서 전체 원행 내용을 검사하던 비용, 닫힌 범위 화면의 계속된 요청, 접속 재확인 실패 뒤 작성창 복구 안내 누락이다. 자료 목록의 다음 페이지 배열 처리에도 기존 연산 우선순위 오류가 있었다.

- 접속 재확인 중 개인정보 없는 안내창을 같은 자리에 띄우고, 조회 실패 때 `접속 다시 확인`을 제공한다. 성공하면 기존 작성 내용을 복원한다. 실제 인증 거절/계정 변경은 기존대로 내용을 폐기한다.
- 닫힌 범위 조회를 중단하고 재진입에 초안과 정상 자료를 재사용한다. 실패한 범위를 0개라고 표시하지 않는다.
- 분류 메뉴는 등록 상태·사용 여부·원판 버전만 읽는다. 실제 범위 상세/미리보기/저장에는 기존 원행 변경 검사를 유지한다. 같은 원키의 계산을 요청 내부에서만 공유한다. 새 사전·본문 사본·DB 캐시표는 만들지 않았다.
- 검토 DB의 같은 모의고사 분류 조회: 수정 전 12초 제한 초과 → 최종 수정 647.7ms. 운영 반영 후 985.7ms. DB 조회 한 번의 관측이며 전체 화면 표시 시간이나 부하 시험 수치는 아니다.
- 기능 검사: 배정/단어장 화면 74개, 최종 목록 SQL 8개, 원출현 호환/범위별 판정 13개 통과. 구조/연습 85개, 타입/lint/기능 지도·UI 구조·54페이지 빌드 확인.
- 기존 `vocabulary-learning-migration.integration.test.ts`의 옛 생성 저장형식을 기대하는 1검사는 수정 전/후 동일하게 실패했다. 기준선에서 4통과/1실패를 다시 확인했으며 이번 오류를 숨기기 위해 검사를 바꾸지 않았다. 원행 본문 변경을 잡아내는 나머지 관련 검사는 통과했다. 근거는 비공개 작업 폴더의 `app03-baseline-test.log`다.
- SQL은 기존 네 함수의 본문만 변경했다. 두 환경 모두 OID·실행 권한·검색 경로·보안 실행 방식 보존, 최종 본문 일치. 보안 점검의 기존 관리자 공개 RPC 경고는 역할/함수 내부 관리자 확인을 유지한다.
- 운영 SQL: `20261005035936_speed_library_reads_and_preserve_assignment_drafts`. 검토 환경에 먼저 적용했다. 학생 기록 쓰기 0.

## 운영 화면 최종 확인

검토 배포 `dpl_965zvnQJR3fp1oHXumouHdRSd5AZ` → 운영 배포 `dpl_7Rsjc1SYLM63yFsHt7R7TfMs5e4J`, 모두 READY·구현 `c3796730456bcc732db820c5333676e0e1d4b61b`. 정식 주소는 https://english-academy-student-app.vercel.app 이며 해당 운영 배포 연결을 확인했다. 운영/검토 DB 연결도 서로 구분됨을 확인했다. 검토 환경은 DB 기능 검사와 로그인 화면까지, 로그인된 관리자/학생의 실제 화면 읽기는 운영에서 확인했다.

- 테스트 학생 배정창과 단어장 찾기, 템플릿 목록, 심석고2 범위 편집을 열었다. 범위 편집에서37개·원자료671개·포함671개, 추가/제외/범위 추가·제외 모두0을 확인했다. 템플릿 저장/적용/시험 배정은 누르지 않았다.
- 테스트 학교 필터에서는 별도 고3 공용 자료7,532개가 검색됐다. 이것은 목록의 다른 자료이며 사용자에게 보인7천개의 원인이라고 단정할 수 없다. 최종 적용 전 취소/실패 때 기존 선택이 남는 현행 경로는 별도 기록한다.

## 동일 저장판 재선택 보완

같은 템플릿의 기존 저장판을 다시 사용하면 서버가 같은 자료 ID를 반환한다. 기존 연결은 이때도 자료 변경 처리를 실행하여 선택 범위·직접 문항수·회차별 일정 덮어쓰기를 지웠다. 동일 ID에서는 입력을 보존하고 표시정보·화면 복귀만 갱신하도록 수정했다. 다른 자료 ID는 기존대로 초기화한다. 새 저장판·사전·본문 복사·DB 변경 없음.

가짜 자료를 사용하는 실제 배정/템플릿 화면 검사에서 수정 전 같은 자료의 범위 선택 소실을 재현했다. 다른 자료 초기화 분기는 수정 전부터 통과했다. 수정 후 해당 파일33개, 타입/lint·격리된54페이지 빌드와 독립 읽기 검토 통과. 목록 갱신 응답이 늦게 돌아오는 경우에도 선택한 DAY01과 직접7문항을 보존했다. 이번 검사는 실제 관리자 저장/새판 DB 발급까지 검증한 것은 아니다.

운영 읽기에서는 실제 심석고2 학생의 자료 선택창에 모고278개가 표시되고 배정 조건에도 같은 자료 이름과278개가 전달됐다. 저장된 심석고2 현재 지필 템플릿은37범위·671개·추가/제외0으로 확인됐다. 최종 적용·배정 저장은 실행하지 않았다. 조회 중 만든 초안은 버리고 닫았으며 학생 기록 쓰기는 없다.73개 단어키와671개 뜻별 집계의 확인 필요 표시는 구자료 집계 기준에 따른 것으로 기존 원단어 참조키 누락이나7천개 전환의 근거로 사용하지 않는다.

같은 자료 재선택 초기화는 확인·수정된 별도 원인이다. 사용자 보고의671→7천개 전환을 재현했다고 주장하지 않으며, 전체 작업을 완료로 올리지 않는다. 변경하지 않은 DB/원키 연결·용량 검사는 반복하지 않았다.
