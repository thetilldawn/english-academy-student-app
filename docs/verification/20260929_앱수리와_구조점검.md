## 결론

오래 켜 놓거나 화면을 왕복했을 때 무조건 로그아웃·자료 없음으로 끝날 이유는 없다. 이번 코드에서는 **일시적인 조회 장애를 인증 상실로 처리하는 경로**, **시간초과 응답이 인증 SDK의 세션 삭제로 이어지는 경로**, **서버 오류 재시도가 실제 재조회로 연결되지 않는 경로**를 재현했다. 단순히 캐시 시간을 늘릴 문제가 아니었다.

큰 구조 방향은 Next.js 지침에 맞지만 오류 처리·일부 모달 경계와 문서의 현재 상태 표시는 고칠 부분이 있었다. APP01~07로 수리했고 OPS01에서 지도·지침·통합 검증을 정리한다. 파일이 많다는 이유만으로 구조가 좋다거나, 자동검사 통과만으로 모든 운영 상황이 정상이라고 결론 내리지 않는다.

코드 기준은 `58af62cdc56f399419d4a1ea56a6282b3e10493a` 이후 현재 작업 파일이다. Next.js16.2.12/React19.2.8을 유지했다. 이 문서는 로컬 작업 결과이며 **운영 DB 적용·새 배포·실제 학생 시험/배정/점수 변경은 하지 않았다.**
