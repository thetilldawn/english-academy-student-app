# 학교 일정 표시와 수동입력 검증

수행·지필·수능을 왼쪽 색상 태그로 구분하고, 겹치는 기간을 한 카드에 나열한다. 가장 가까운 날짜 묶음을 먼저 표시하고 이후 일정은 펼친다. 관련 학생 수를 유형별로 집계하며 선택 과목 수강 여부는 학교 편제표에서 구분한다.

수동입력과 날짜 확인 필요 링크는 같은 경로 모달로 연결된다. 학교·학년·학생 수와 평가 정보를 선택하며, 직접 주소와 새로고침에서는 독립 편집 페이지를 연다. 저장 이력은 학교 원천을 보존하며 원천 갱신보다 우선한다. 학교/학년의 실제 등록 자료와 상세 출처 검토는 앱 밖 운영정보에 보관한다.

## 실행 결과

- 전체 3,402개 중 3,401개 통과, 실패 0, 기존 선택 검사 1개 제외. 초기 실행에서 발견한 두 구조 오류를 수정했고, 부하로 시간 초과한 항목은 분리 재검증 후 최종 전체 검사도 통과했다.
- 학교 일정 관련 63개 검사: 겹침, 학생 수, 고3 수능, 원천 보존, 권한, 버전 충돌, 같은 요청 재시도, 응답 유실·복구, 인증 만료, 초기 실패 재시도, 저장 성공 뒤 탐색 갱신.
- 외부 요청과 실제 환경 파일을 차단한 가상 서버 검사 33개 통과. 가상 저장 요청 식별자 허용 범위를 좁혀 실제 데이터 식별자는 계속 차단한다.
- 제품 타입·린트·기능 지도·UI 구조·서버 경계·React 요청 캐시 검사와 Next16.2.12 격리 빌드 통과. 새 패키지 설치와 버전 변경 없음.
- 실제 CUA 화면: PC 및 390×844 모바일, 밝은/어두운 색상, 겹친 지필·수행과 수능, 두 편집 진입점, 날짜 미정→확정 저장, 개요 즉시 갱신, 뒤로/앞으로가기의 최신 날짜, 직접 주소·새로고침, 미저장 취소·입력 원복, 자료 없는 학기의 신규 양식 확인. 모바일 가로 넘침 없음. 최종 검사 탭의 콘솔 오류 0.
- 원천 대조, 저장 SQL, 입력/복구 UI를 읽기 전용으로 독립 검토했다. 지적된 SQL 변수 참조·원천과 수동 합산 상한·인증 만료 이탈·최초 오류 재시도·탐색 보관값 문제를 수정 후 확인했다.

## 학생 상세 제목 추가 보완

운영 읽기 점검에서 제목 영역이 폭 0으로 접혀 이름이 세로로 나뉘는 오류를 확인했다. 공통 Dialog 제목 행·제목 본체에 남는 공간을 배정하는 CSS 선언 두 개로 수정했다. 업무 코드와 데이터 변경은 없다.

- 추가 관련 검사120/120 통과: 공통 Dialog, 경로 모달, 학생 상세, 학교 일정, 구조 경계. 타입·격리 Next 빌드·기능 지도·UI 구조와 독립 코드 검토도 통과했다. 위 전체3401검사는 이전 구현 검증이며 이번에는 변경 영향에 맞춰 검사했다.
- 가상 학생 실제 화면의 제목 폭은 PC1280에서683.3px, 태블릿768에서493.3px, 모바일390에서300.86px이며 이름 한 줄을 유지했다. 모바일에서는 남은 기간만 이름 위로 이동한다. 밝은/어두운 테마·닫기·일정 입력 모달 제목812.86px를 확인했다. 가로 넘침0·콘솔 오류0. 운영 데이터로 저장 검사를 하지 않았다.

## 반영 범위

이 문서는 구현과 로컬 검증 근거다. 운영 배포와 원천 등록·보존 확인은 별도 배포 기록으로 관리한다. 가상 저장 외 실제 학생 변경·배정·시험 시작·답 제출을 하지 않았다.
