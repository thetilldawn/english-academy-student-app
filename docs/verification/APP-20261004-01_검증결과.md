## 검사 중 확인한 한계

모든 표의 행을 비교하는 적용 요청에서 MCP 응답 시간이 먼저 끝났다. 곧바로 다시 적용하지 않고 실행 중 연결과 원형 본문을 조회한 뒤, 연결 종료·새 본문·저장된 이력을 확인했다. 이력의 같은 거래에는 행/함수 불일치 시 취소하는 검사가 들어 있다. 원격에서 완료 SELECT의 행수·전체 확인값 응답은 회수하지 못했으므로 총 행수는 보고하지 않는다.

처음 로컬 도구는 지도 컬렉션 이름과 임시 실행기의 최상위 await 때문에 실패했으며 고쳐17검사/보존 거래를 통과했다. 검토 배포 선택의 첫 호출은 잘못 전달한 전체 커밋 문자열로 안전하게 거절됐고, git에서 실제 커밋을 읽어 재실행했다. Git 전송 자동 승인은 목적지 근거 부족으로 거절됐으나, GitHub 연결에서 사용자가 해당 저장소 소유자/admin임을 확인한 뒤 같은 대상 전송이 승인됐다.

독립 검토는 검색 의미·지문 가드·메타/자료 보존·R/D/T 일치에서 차단점0이었다. 실제 전체 시험/운영 전환은 M10 별도 검증이며 이번 결과로 운영 완료를 주장하지 않는다.
