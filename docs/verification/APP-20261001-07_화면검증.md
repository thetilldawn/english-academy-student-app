# 문항 본문 참조 화면 확인

2026-10-02, 실제 앱의 격리 빌드와 가짜 학생 서버로 확인했다. 외부 인증·DB 요청을 차단하는 기존 검사 도구를 사용했다. 실제 학생이나 운영 데이터는 사용하지 않았다.

화면 캡처: [PC 진행 유지](APP-20261001-07_화면/01_PC_새로고침.jpg), [만료 안내](APP-20261001-07_화면/02_모바일_준비만료.jpg), [지연 중](APP-20261001-07_화면/03_모바일_응답대기.jpg), [지연 후 복구](APP-20261001-07_화면/04_모바일_복구.jpg), [예문 재시험](APP-20261001-07_화면/05_예문_재시험.jpg). HTTP·본문 호출·가짜 저장 횟수는 `.codex-tmp/m02-browser-metrics.json`에 저장했다.

이 검사는 로컬 가짜 화면이다. 원격 로그인·실기기·실제 음원 재생 품질·시험 최종 결과 상세 화면은 이 검사로 확인했다고 하지 않는다. 가짜 서버의 미제공 추가 발음 조회는 경고로 남으며, 문항에 고정된 검사 발음과 표시를 사용한다. 데이터와 응시 경계는 최종 SQL·권한 검사로 별도 확인한다.

독립 검토에서 발견한 준비 재조회 null 처리와 본문 바로가기 대상을 보완했다. 예상한 준비 만료만 목록 복귀 안내로 처리하며, 서버 장애·깨진 참조·다른 예외는 기존 오류 경로로 전달한다. 자율연습 목록 안내는 동일한 예외 분기를 사용하며 해당 화면의 만료 상황을 브라우저에서 별도로 만들지는 않았다.
