# 학교 검색과 단어장 찾기 로컬 검사

2026-09-08. [지시서](../work-orders/APP-20260908-04.md) R10/R11/R16에 대한 로컬 구현·검사 기록이다. 실제 Preview·Production 반영과 실제 자료 태그 수정은 포함하지 않는다.

## 적용 결과

- 학생 등록과 학생 정보 수정이 같은 학교 검색 부품을 사용한다. 기존 학교명은 그대로 표시하며 검색하지 않는다. 입력 후 350ms에 조회하고, 학생 교체·닫기·입력 초기화는 이전 요청을 취소한다.
- 학교 이름과 지역으로 동명 학교를 구별한다. 조회 중·검색 결과 없음·연결 오류·로그인 필요를 구분하고, 없음/연결 실패에도 직접 입력할 수 있다. 학교 선택만으로 학생 정보나 학년을 저장하지 않는다.
- 학교/학교급/학년/자료 종류/검색어를 함께 적용한다. 학교를 고르면 그 학교 자료와 확인된 공통 자료를 별도 목록으로 보여준다. 최근 선택에도 같은 조건을 적용한다.
- 유효한 `metadata.school`만 학교 자료로, 학교 미지정 + `metadata.audience === "common"`만 공통으로 인정한다. 미태깅·잘못된 태그는 학교 미분류다. 실제 DB 태그는 바꾸지 않았다.
- 기존 검증된 제목·출판사로 교과서 이름을 보기 좋게 표시하고, 표시 제목으로도 검색된다. 제목과 겹치는 부가설명은 제거했다. 원래 자료명·저자·과·범위는 임의 수정하지 않는다.
