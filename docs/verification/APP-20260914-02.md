# 학교 일정 월별 표시·영어 시험일 확인

사용자 첨부의 지필 바 누락, 아래 학습 기록과 다른 둘레 테두리, 한꺼번에 접히는 이후 일정을 보완했다. 같은 공용 접기 요소로 당월은 펼침·미래 월은 접힘이며 유형별 바는 모든 행에 표시한다. 지필의 영어 시험일은 선택 필드로 분리했고 학교 전체 기간은 설명으로 보존한다.

## 검증

- 전체 회귀: 3,413통과·실패0·기존 선택1미실행. 이후 축약 월 범위 처리 보완 및 가상 일정 검사14통과.
- 학교 일정 도메인·계약·편집·SQL·컴포넌트: 실제 영어 날짜/미확인/학교기간 보존, 원천 등록과 수동 저장 검증, 잘못된 날짜·미실시·유형 전환, 월경계·같은 날짜 묶음·이전 자료 호환을 확인했다.
- TypeScript, 변경 코드 lint, 기능 지도, UI 구조, 설계 및 전체 변경 연결50기록, 격리된 Next.js 운영 빌드 통과. 추가 의존성0.
- 실제 가상 화면: 기본802px, 모바일390px, PC1280px. 당월 펼침/미래 닫힘·개별 월 토글, 모든 유형4px 바·둘레0·모서리0·호버 배경과 아래 학습 기록 공통 접기 동작 확인. 밝고 어두운 테마, 가로 넘침0.
- 영어 시험일을 가상10/15로 저장 후 개요에 영어10/15와 학교기간10/12~10/16을 별도 표시, 학생 이름 옆31일로 갱신, 학생 상세 제목 폭672.39px·정렬 정상. 실제 학교/학생 자료를 테스트 저장하지 않았다.
- CUA의 date fill만으로는 React 변경 이벤트가 발생하지 않는 도구 동작을 확인해 날짜 필드의 실제 키보드 증가/감소로 입력을 확정했다. 정상 입력 저장/조회가 확인됐으며 구현 오류로 숨기지 않았다.
- 독립 검토의 '10~11월'을11월로 좁히는 문제 수정 후11개 입력 재확인, 추가 필수 미해결0. SQL의 기존 두 함수는 선택 날짜 검증 추가 이외 로직 동일 대조.

로컬 구현과 가상 화면 검증 기록이다. 운영 DB/자료 등록 및 Preview/운영 화면 결과는 별도 DEPLOY-20260914-03에 기록한다. 실제 학생 시험 시작·답안 제출·학생 자료 변경은 수행하지 않았다. 학교 원본과 검토 데이터는 앱 Git 밖에 보관한다.
