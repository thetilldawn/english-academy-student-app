# 시험 준비와 전환 검증

2026-10-01. 로컬 구현과 격리 검사 결과이며 운영 반영은 DEPLOY-20261001-02에서 별도로 기록한다.

## 변경

- 최초 문항·필수 코드·폰트·화면 배치를 준비한 다음 서버 시작을 한 번 확정한다. 준비 자료만 만들 때에는 실제 시험·답안·포인트가 생기지 않는다.
- 정오답 확인 목표를 200ms에서100ms로 줄였다. 선택 확정20ms는 유지한다.
- 빠른 응답이면 블러 없이 전환한다. 정상 응답이 왔으나 서버 예약이100ms이하 남았으면 기존 정답 표시를 유지하고 실제 예약이 끝나는 즉시 전환한다. 통신을 포함한 정확한100ms 상한을 보장하지 않는다. 새 지연을 넣거나 서버 시간을 앞당기지 않는다.
- 응답이 늦거나 복구 중이면 기존 문제 위에 블러/‘다음 문제 준비 중’을 표시하고 입력·음성을 막는다. 표시했던 경우에만80ms로 걷는다. 모션 줄이기 설정에서는 효과를 끈다.
- 만료/변경된 준비는 목록으로 돌아가 다시 시작하도록 안내한다. 불명확한 응답 유실만 동일 준비 ID로 재확인한다.
