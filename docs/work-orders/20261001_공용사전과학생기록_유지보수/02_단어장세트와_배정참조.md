## 2. 저장 계약

공용 세트는 실제 시험에 사용한 **불변 판**이다. ‘단어장 이름’만 가리키거나 조회할 때마다 최신 뜻으로 다시 구성하면 안 된다.

| 자료 | 남길 값 | 반복하지 않을 값 |
|---|---|---|
| 범위·선택 | 원범위 ID·자료판·선택/제외 키·조건·원자료 확인값 | 시험용 원행 `to_jsonb` 전체 |
| 단어장판 | 선택값 참조의 순서, 출제 방향·규칙판, 원자료 판·내용 확인값 | 새 단어 뜻/검토 근거의 별도 사본 |
| 공용 문항판 | 질문 선택값·보기 선택값/고정 사용값·정답 규칙·음원 참조 | 동일 근거·원문·음원을 배정별 복제 |
| 학생 배정 | 기존 배정 ID, 학생 ID, 공용 판, 범위/순서·필요한 섞기 정보·일정·상태 | 질문·보기·발음·출처 묶음 전문 |
| 응시 문항 연결 | 기존 문항 ID, 공용 문항판, 실제 제시 순서·선택 답·시각·회차 | 표시 본문 복사 |

보기는 ‘최신 사전 조회 시 적당한 단어를 다시 고름’으로 복원하지 않는다. 기존 보기 네 개와 그 순서가 재현되어야 한다. 선택값이 나중에 수정되면 새 공용 판을 만든다. 학생마다 다른 보기 섞기는 짧은 순서 배열 또는 검증된 규칙판+시드로 보존하되 과거 버전에서도 정확히 재현되는지 검사한다. 현재 알고리즘 재실행만으로 과거 정답 위치가 바뀌면 실패다.

공용 재사용 키에는 자료 접근 범위, 불변 선택 목록·순서, 출제 방향, 생성 규칙판, 보기 고정 내용이 들어간다. 개인정보·학생 이름·날짜는 공용 내용 키에 포함하지 않는다. 해시가 같더라도 길이/구조/실제 선택 목록을 대조한다. 학교 자료를 전 세계 공용 자료로 공개한다는 뜻이 아니다.

## 3. 구현 순서

1. 기존 v1/v2 구성 읽기 계약을 조사해 공통 반환형으로 맞춘다. v2의 `sourceScopeId+key+documentHash`를 재사용한다.
2. 공용 사용값/문항판 참조 열을 추가한다. 기존 본문 열은 M08 정리 전까지 보존한다. 적용된 과거 SQL을 수정하지 않고 새 마이그레이션을 추가한다.
3. 서버 조회는 새 참조가 유효하면 새 경로, 아직 이전되지 않은 행은 기존 경로를 사용한다. 참조가 깨진 행을 ‘아직 이전 전’으로 숨기지 말고 별도 오류로 보고한다.
4. 신규 범위·구성 생성은 긴 원출현/검토 묶음을 복사하지 않게 한다. 아직 호환이 필요한 구형 소비자는 어댑터에서 기존 형태를 구성한다. 새 영구 저장에 전체 사본을 추가하지 않는다.
5. 같은 세트 생성 요청은 DB 고유 제약·거래로 한 판만 완성한다. 부분 생성은 기존 분할 작업/재개 계약으로 처리하고 불완전한 판은 배정할 수 없게 한다.
6. 학생 배정은 공용 판과 개인 순서·시간만 연결한다. 일괄 배정의 검토 서명·`audienceMode`·학년 조건·현재 동시 배정 한도를 유지한다.
7. 과거 배정 읽기, 학생 학습, 정규 시험, 오답 시험, 결과·관리자 상세를 한 경로씩 전환한다. 실제 호출자가 0이 되기 전에 구형 저장 필드를 제거하지 않는다.

## 5. 권한·거래·캐시·화면 영향

공용 문항판의 채점 기준본은 서버가 관리한다. 현행/M11 규격에서는 정답 키를 미리 전달하지 않는다. 새 M05 규격의 즉시 판정용 최소 정보는 D20에서 허용한 응시 범위·필드·시점으로 별도 전달한다. 일반 공용 조회에는 현재 배정에 필요한 표시 자료만 나간다. 고권한 DB 함수 안에서도 요청자의 학생/배정 관계를 검사한다. 표시용 공용 자료를 재사용하더라도 학생 진행·정답·관리자 권한을 공유 캐시에 넣지 않는다.

생성/수정은 새 판, 배정/응시는 고정 판 참조, 검색은 사용 가능한 범위만, 삭제는 템플릿의 숨김/참조 상태와 실제 판 삭제를 구별한다. 이미 배정된 판은 참조 중이므로 제거하지 않는다. 기록은 생성 판·원자료 확인값·배정 연결 수만 남긴다.

변경: domain/data/API/서버/캐시 키/검사. 확인만: 화면 경로·UI·입력 상태·스타일·오류 문구·권한, 기존 분할 진행. 새 메뉴 없음. 준비 중에는 “선택한 범위를 준비하고 있습니다.”, 일부 자료 연결 오류는 “일부 자료를 확인하지 못했습니다. 선택은 그대로 남아 있습니다.”, 결과 미확정은 “저장 결과를 확인하고 있습니다.”를 기존 진행/오류 영역에 표시한다. 같은 요청으로 결과를 확인한 뒤만 재시도한다. 공통 U1~U10을 M02-T8로 검사한다.

완료 산출물은 신규 저장 크기 비교, 공용 판 재사용 수, 과거 전수 복원 비교, 호환 경로와 남은 구형 호출자 목록이다. 복구는 구형 형식을 읽을 수 있는 호환 서버로 되돌린다. 새 참조만 저장한 기록이 생긴 뒤에는 참조를 모르는 옛 배포본으로 되돌리지 않는다.
