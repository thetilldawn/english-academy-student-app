# M07 · 종류별 단어장 만들기와 화면 정리

유형: APP, 기존 기능 보완. 선행: 기존 분류/저장 계약 대조. 공용 자료 전환과 같은 릴리스면 M01/M02 계약을 함께 대조한다. 결정 D14/D10. 네 종류는 사용자 확정이며 다시 묻지 않는다. 분류를 알 수 없는 옛 자료는 자동 확정하지 않는다.

## 1. 목표와 요구

**만들 단어장 종류를 먼저 고르고, 그 종류와 지금 편집하는 자료에 필요한 입력만 보여준다.** 기존의 ‘용도·대상→자료·범위→요약·저장’ 3단계와 저장된 범위 복원은 유지한다.

| R번호 | 완료 조건 | 소유자·흐름 | 검사 |
|---|---|---|---|
| M07-R1 | 수행평가/직전대비/모의고사/기타 공식 값과 자유 설명 분리 | wordbook-compositions · mock-wordbook-compose | M07-T1/T2 |
| M07-R2 | 종류별 필요한 입력·자료 편집의 연월만 노출 | wordbook-compositions | M07-T3/T4 |
| M07-R3 | 저장·새로고침·검색·배정의 같은 분류 | wordbook-compositions/assignments · assignment-workspace-planning | M07-T1/T5 |
| M07-R4 | 옛 용도 문장·미분류·고정 범위·과거 판·초안 보존 | 같은 흐름/assignment-edit | M07-T2/T6/T7 |
| M07-R5 | 수량 의미·빈 결과·오류·포커스·모바일 가독성 | UI/controller | M07-T8/T9 |

## 2. 분류와 저장 계약

| 구분 | 계약 |
|---|---|
| 단어장 종류 | 공식 네 값. 내부 후보 `performance_assessment / exam_prep / mock_exam / other`; 최종 이름은 엄격한 계약 전체에서 동일하게 사용 |
| 종류 설명 | 사람이 적는 보충 문장. 종류 판별에 사용하지 않음 |
| 옛 미확정 분류 | `null` 또는 명시적 미확정 상태+원래 문장. 공식 ‘기타’와 구별 |
| 원자료 종류 | 교과서/DAY/학교 자료/모의고사/수능/미분류 등 현재 계약 유지 |
| 학습 대상 | 학교·학년·학기·준비 연도·시험/평가명. 원자료 시행연도와 별도 |
| 배정/자료 처리 방식 | 범위/혼합/오답, legacy_vocab/exam_use/reviewed_exam 등 내부 의미 유지 |

현재 `purpose` 자유 문장을 즉시 enum으로 덮어쓰지 않는다. 구형 읽기/영수증 계약을 유지하며 공식 종류 필드와 설명 필드를 분리한 새 요청판을 사용한다. SQL의 ‘purpose가 있으면 exam_prep’ 조건을 없애고, 명시된 공식 종류를 목록·요약·배정까지 전달한다.

구형 자료 변환은 근거가 있는 항목만 확정한다. 단순 `직전`, `수행` 같은 부분 문자열이나 첫 원자료 종류로 자동 분류하지 않는다. 애매한 자료는 “분류 확인”으로 보여주며 기존 열람·배정은 유지한다. 사용자가 편집할 때 종류만 보완할 수 있게 한다.

## 3. 화면별 구현

| 화면/종류 | 먼저 보이는 입력 | 추가/수정 중 보이는 범위 |
|---|---|---|
| 공통 진입 | 네 주 탭, 보조 ‘저장한 구성 찾기’ | 저장된 자료는 전체 요약부터 열기 |
| 수행평가 | 이름·학교·학년·학기·평가명·기준 자료 | 학교 유인물/지정 단어장의 해당 범위 |
| 직전대비 | 이름·학교·학년·학기·중간/기말·담은 자료 요약 | 교과서 과/DAY/학교 자료/추가 지문 등 선택 자료에 맞춤 |
| 모의고사 | 원자료 학년·시행연도·월·유형 | 필요할 때 문항 번호; 수능은 별도 출처로 기존 학년도 규칙 유지 |
| 기타 | 이름·설명·자료 선택 | 선택한 자료의 DAY·과·태그 |
| 저장 확인 | 종류·대상·자료판·범위·제외/보류·수량·변경 내용 | 종류 수정과 내용판 변경을 구별 |

학교·학기·시험명 등 보조 정보는 기존에 선택 사항이면 새 필수 조건으로 바꾸지 않는다. 새 만들기의 최소 필수값은 명시적 종류·기존 필수 이름을 기준으로 한다. **범위 확정 저장은 유효 자료·포함 항목이 필요하고, ‘범위를 나중에 정할 예정’인 틀은 자료 없이 저장·재열기가 가능해야 한다.** 범위 미정 틀은 실제 단어장 생성/학생 배정이 불가하다는 기존 경계를 유지한다. 다른 필수화는 별도 사용자 정책으로 다루며 표시는 실제 서버 검증과 같아야 한다.

직전대비에 교과서2·3과와 모의고사 지문을 넣을 수 있다. 본화면에는 자료 요약을 표시하고 ‘모의고사 범위 수정’을 열었을 때만 해당 시행연도·월을 펼친다. 종류 탭은 혼합 자료를 금지하는 장치가 아니다.

탭 전환은 초안의 이름/선택 그룹/제외/순서를 보존한다. 적용되지 않는 보조값은 숨기되 조용히 지우지 않는다. 기존 저장본을 열 때 첫 원자료 자동 편집을 하지 않고 요약 상태와 편집 상태를 분리한다. 취소/뒤로가기/다른 탭 전환에서 기존 입력 폐기 확인 패턴을 재사용한다.

## 5. 읽기·수정·권한·캐시

이름·설명·종류만 수정하면 선택 단어·뜻·문항·학생 배정을 새로 만들지 않는다. 범위/보기 내용이 바뀔 때만 새 내용판을 만든다. 공용 자료 분류를 바꾸는 권한은 현재 관리자 계약을 유지한다. 향후 교사별 공유는 F02다.

종류 검색은 서버 전체 자료에 적용하고 커서에 검색어·종류·접근 범위를 묶는다. 저장 후 목록·선택판·배정 목록의 관련 캐시를 갱신한다. 개인 초안은 해당 화면 수명으로 보존하며 계정 전환 때 폐기한다. 늦은 검색 응답은 최신 조건에 합치지 않는다.

변경: UI/state/domain/data/API/cache/asyncUi/styles/tests. 확인만: routing·권한·공용 자료 내용·배정 저장·채점. 공용 Field/Tabs/Dialog/token 사용, 키보드 탭 이동·선택 상태·오류 설명 연결·닫기 후 포커스 복귀·390px 가로 넘침0·reduced-motion을 확인한다.
