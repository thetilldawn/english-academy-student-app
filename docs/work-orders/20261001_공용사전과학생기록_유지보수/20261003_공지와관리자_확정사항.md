# 2026-10-03 공지·관리자 분리 결정

사용자 답변으로 확정했다. 현재 작업 순서는 루트 대장을 따른다.

- F01: 패치 안내는 토스트 알림만 표시한다. 공지를 모아 보는 화면은 이후 작업으로 미룬다. 이번 구현에서 공지함·상세 읽음 처리·새 소식 뱃지를 만들지 않는다. 사용자 답변: “그냥 토스트 알림식으로만 보여주고 공지는 나중에 모아서 보여줄곳만들거임”. 같은 답변의 반복 전송은 한 결정으로 취급한다.
- F02 학생: 관리자마다 담당 학생을 완전히 분리한다. 전체 학생을 보는 책임자·공동 담당의 이전 권장안은 채택하지 않는다. 사용자 답변: “각 관리자의 학생을 완전히 분리”.
- F02 자료: 공용 사전은 함께 쓴다. 초안은 개인에게만 보이며 선택한 단어장만 공유한다. 기존 배정과 학생 기록 보존은 유지한다. 사용자 답변: “초안은 개인·선택한 단어장만 공유 (권장)”.
- 운영 확인: 사용자가 Vercel 브라우저 로그인을 완료했고 현재 로그인된 대시보드의 Hobby 표시와 사용량을 직접 읽었다. MCP 프로젝트 조회 실패와 별도로 사용량 확인을 진행한다.

이번 기록은 기존 질문의 답변 반영이다. 제품 구현·운영 공개·DB 권한 변경은 아직 이 파일만으로 실행되지 않았다.
