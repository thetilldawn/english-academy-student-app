# M01 · 공용 사전과 뜻·출처 연결

유형: APP, 기존 구조 보완. 선행: 없음. 후속: M02/M03/M04/M05. 공통 D01~D05/D10 적용. 사용자 미결정: 없음. 기존에 승인되지 않은 뜻 병합은 작업 결과로 지어내지 않고 원출현 선택을 유지한다.

## 1. 문제와 완료 결과

같은 단어의 앱 등록 행·원출현·사전 ID가 서로 다른 역할인데, 본문을 복사하거나 철자만으로 합치면 용량과 의미 보존을 함께 해결할 수 없다. **기존 사전 ID를 기준으로 학생에게 필요한 사용값만 온라인에서 공유하고, 각 원출현의 선택 뜻과 발음을 정확히 가리키게 한다.**

기준 자료: [사전 결정기록](../../../../../영어/00_운영/단어시스템/45_단어사전_메타데이터_결정기록.md), [공용 어휘 출처 기준](../../../../../skills/english-vocabulary-source-priority/SKILL.md), [사전 연결 검수](../../../../../skills/english-vocabulary-source-priority/references/사전연결과등록검수.md).

## 3. 구체적인 자료 계약

아래 이름은 설명용 역할명이다. 새 표를 무조건 각각 만들지 말고 기존 표·참조를 먼저 재사용한다. 최종 SQL 이름과 소유자는 설계 기록에 등록한다.

| 역할 | 온라인에 남길 최소값 | 금지 또는 주의 |
|---|---|---|
| 단어 연결 | 기존 사전 ID, 승인된 옛/새 ID 연결, 표시 철자/품사 참조 | 철자 소문자화만으로 의미 동일성 확정 금지 |
| 뜻·필드 선택판 | 공용 뜻 참조 또는 기존 원출현+자료판+선택 필드+확인값, 표시 뜻·필요한 정의/예문 | `sense_id`가 비었다고 뜻 없음 처리/가짜 뜻 ID 생성 금지 |
| 발음 선택 | 원래 발음값·변이·원출처·음원 주소/공용 파일 키·확인값 | 음원 본체를 DB JSON/base64로 복제하거나 자동 발음으로 덮어쓰기 금지 |
| 출처 연결 | 자료/원출현 ID, 태그, 로컬 상대 경로, 파일·선택 필드 확인값, 판 | 모든 학생/문항에 파일 내용 전체 복사 금지 |
| 이전 대응 | 기존 vocab entry/출현/범위 행 ID → 새 공용 사용값 참조, 연결 상태·근거 | 원래 행 삭제 또는 참조 없음 항목 임의 제외 금지 |

승인된 같은 뜻 연결은 기존 공용 뜻 기준을 따른다. 표기만 다른 뜻 문자열을 자동 병합하지 않는다. 같은 뜻인지 확인되지 않은 A/B 항목은 같은 단어 카드 아래에 별도 선택으로 유지하고, ‘선택 뜻 연결 확인 필요’를 관리용 보고에 남긴다. 기존 자료를 학생에게서 숨기지 않는다.

한 온라인 선택판은 수정하지 않는 값이다. 원문 수정은 새 판을 추가하고 새 세트부터 사용한다. 기존 시험은 이전 판을 계속 참조한다. 내부 숫자/UUID 참조는 길이를 줄이는 연결 수단일 뿐 새 영어 사전의 기준 ID가 아니다.

## 4. 구현 순서와 실제 변경 진입점

1. 읽기 전용 대응표를 만든다. 자료별 기존 ID, 선택 뜻·품사·예문·발음·원출현·자료판·확인값, 연결 상태를 수집한다. 학생 개인 정보나 전체 원문은 Git에 넣지 않는다.
2. 현재 선택값을 정해진 순서로 직렬화해 확인값을 만든다. 공백·키 순서 정규화로 의미/발음 값이 바뀌지 않도록 원본과 표시용 값의 확인값을 구분한다.
3. 기존 사전/시험용 계약을 읽는 공용 조회 어댑터를 추가한다. 원래 선택값이 있는데 새 조회에서 null이면 실패시킨다. 자동 생성으로 메우지 않는다.
4. 승인된 연결만 작은 묶음으로 채운다. 중복 실행은 같은 참조를 반환하고, 충돌은 보고 후 그 묶음을 중단한다. 시작/끝 키·수량·확인값으로 재개한다.
5. 모든 현행 소비자가 같은 공용 조회 계약을 사용할 수 있도록 공개 서버 진입점을 만든다. 이 공용 조회에는 보기 정답·서버 비밀 필드를 넣지 않는다. M05의 즉시 판정용 최소 자료는 D20에서 정하는 별도 시험 전달 계약이며 공용 내용 API를 그대로 공개하는 근거가 아니다.
6. 전수 자동 대조와 원출처 유형별 내용 검토가 통과하면 M02에 전달한다. 이 작업에서 원문/기존 행을 삭제하지 않는다.

## 5. 흐름·권한·캐시

생성은 관리자/등록 도구가 검토된 선택값을 등록하는 과정이다. 배정과 응시는 공용 참조를 읽기만 한다. 검색은 승인된 이용 범위·출처 조건에서만 제공하며 학생에게 사전 전체 관리 API를 열지 않는다. 수정은 새 판 생성, 삭제는 참조 중이면 거절한다. 감사는 등록 판·수량·확인값·실행자만 남기고 원문 전문을 다시 로그에 쓰지 않는다.

불변 공용 표시 자료는 `사용값 참조+자료판+표시 계약판`으로 재사용한다. 개인 배정 권한은 요청마다 별도 확인한다. 새 판이 생겨도 기존 판 캐시를 잘못 덮어쓰지 않는다. M05가 브라우저 수명을 정한다. 서버 보관 실패는 원문 재생성이 아니라 기존 읽기 경로 또는 오류로 복구한다.

화면 신설 없음. 등록·준비 호출에서 선택값 누락은 `WORD_SELECTION_UNAVAILABLE`, 내용 불일치는 `SOURCE_CONTENT_MISMATCH` 같은 내부 원인으로 구분하고, 화면에는 “이 자료의 연결을 확인해야 합니다. 다른 자료로 바꾸거나 관리자에게 알려 주세요.”를 표시한다. 실제 코드는 기존 오류 체계에 맞춘다. 자료 없음과 서버 조회 실패를 같은 0건으로 만들지 않는다. 공통 상태 U1~U10과 M01-T7을 적용한다.

## 6. 영향 범위

| 변경 | 확인만 | 해당 없음과 이유 |
|---|---|---|
| domain·data·서버API·보안·검사·판별 공용 캐시 키 | 경로·UI·브라우저 상태·실패 표시·스타일, 기존 권한/보기 제한 | 새 사용자 화면·로그인 방식 변경은 없음 |

기능 지도에는 새 자료 소유자와 기존 `mock-wordbook-compose`, `student-assignment-study-read`, `student-quiz-attempt`, `student-wrong-word-read`의 실제 연결을 추가한다. 기준 원자료를 고쳐야만 해결되는 항목이 발견되면 별도 WORD 작업으로 넘기며 APP 이전에서 고치지 않는다.
