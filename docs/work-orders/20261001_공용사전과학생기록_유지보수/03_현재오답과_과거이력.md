# M03 · 현재 오답과 과거 이력을 분리

유형: APP, 기존 동작 보완. 선행: M01의 단어/뜻 선택 동일성, M02의 고정 문항 연결. 결정: D04~D07/D10. 사용자 미결정: 없음. 자율 연습이 정규 오답을 해결하지 않는 현재 경계는 유지한다.

## 1. 반드시 바꿀 결과

**현재 오답은 아직 해결하지 못한 단어만 보여준다. 같은 뜻을 A/B에서 틀려도 카드 하나이며 실제 최초·재시험 실패를 모두 센다. 정답이면 해당 뜻은 현재 목록에서 빠지고 과거 기록은 남는다.** 같은 단어의 다른 뜻은 함께 해결하지 않는다.

| R번호 | 완료 조건 | 소유자·흐름 | 검사 |
|---|---|---|---|
| M03-R1 | 표시·해결·대기열·재출제가 같은 단어/승인된 뜻 기준 사용 | students/assignments · student-wrong-word-read, assignment-direct-review-create, assignment-notebook-create | M03-T1/T2 |
| M03-R2 | 최초+재시험 실제 실패 4번은 4회, 재전송은 1회만 기록 | quiz-player · student-quiz-attempt | M03-T1/T4 |
| M03-R3 | 해결된 뜻은 현재 목록 제외, 다시 틀리면 새 구간 | students/quiz-player | M03-T2/T3/T5 |
| M03-R4 | 미확인/다른 뜻·다른 학생·자율 연습의 경계 보존 | 학생 상태·권한 | M03-T6/T7 |

## 2. 상태와 횟수 계약

| 계층 | 기준 | 저장/표시 규칙 |
|---|---|---|
| 단어 카드 | 학생+기존 공용 단어 ID | A/B 책 중복 카드 없이 출처 태그를 합침 |
| 현재 뜻 상태 | 학생+단어+승인된 같은 뜻, 또는 보존된 원출현 선택 | 미해결 여부·현재 구간 ID·현재 실패 수·최근 사건·해결 시점 |
| 실제 오답 사건 | 학생·응시·문항·단계·허용된 풀이 회차 | 최초/재시험 실패 각각 1사건. 내용은 공용 문항/출처 키 참조 |
| 해결 사건 | 해당 뜻·근거 답안·서버 순서·시각 | 현재 상태를 해결, 과거 오답 행은 지우지 않음 |
| 누적 이력 | 학생+단어/뜻의 사건들 | 과거 실패/해결 날짜·결과 조회. 기본 현재 목록과 별도 |

`currentWrongCount`는 최근 해결 이후 실제 실패 수, `lifetimeWrongCount`는 보존된 전체 실제 실패 수다. API에서 이름과 의미를 구분한다. 기존 `wrongCount`를 뜻이 바뀐 채 조용히 덮어쓰지 말고 소비자를 명시적으로 전환한다. 옛 자료에 사건 근거가 없는 횟수는 임의로 부풀리지 않고 이전 수치/확인 한계를 보존한다.

기존 `prior_wrong_count`는 시험 당시 과거 완료 시험의 최초 오답 응시 수라는 별도 의미가 있다. 이를 현재 실패 수로 바꾸지 않는다. 출처 필터로 A를 찾았어도 전체 현재4회와 A출처2회를 다른 이름으로 표시한다. 교육용 큐 단계값을 4회 표시와 같은 값으로 무조건 치환하지 말고 기존 단계 정책을 유지한다.

같은 단어에 두 뜻이 미해결이면 카드 하나 안에 뜻 두 개와 해당 출처를 표시한다. 하나를 맞히면 그 뜻만 빠지고 카드에 남은 뜻을 보여준다. 승인된 같은 뜻 연결이 없는 항목은 문자열이 비슷해도 합쳐 해결하지 않는다.

## 3. 갱신 순서와 동시 요청

1. 서버가 학생 세션·배정·현재 회차·문항판을 검증한다. 클라이언트 시각이나 사용자가 보낸 정오답을 신뢰하지 않는다.
2. 답안 저장의 기존 고유 요청/문항/단계 키로 중복을 차단한다. 같은 실패의 응답 유실 후 재전송은 결과만 재반환한다. 허용된 다음 재시험은 별도 사건이다.
3. 해당 학생+뜻 상태를 잠그거나 동등한 원자 갱신을 사용한다. DB의 인정된 사건 순서로 적용한다. 화면 전송 순서/벽시계만으로 경합을 해결하지 않는다.
4. 오답이면 사건을 추가하고 현재 구간이 없을 때만 새 구간을 시작한다. 초기와 재시험을 모두 센다.
5. 정답이면 그 답안이 해결할 수 있는 최신 구간인지 확인한다. 승인된 같은 뜻의 상태·대기열·관련 미해결 대상 연결을 한 거래에서 정리한다.
6. 이미 시작한 시험의 질문·답안·시간은 고치거나 지우지 않는다. 해소된 대기 대상 표시와 향후 출제만 갱신하고, 진행 응시의 후속 실제 답은 정상 계약대로 기록한다.
7. 이전 구간에서 이미 접수된 답의 늦은 재처리/재전송은 새 구간을 해결·재개하지 못하게 한다. 현재 활성 시험의 새로운 유효 답안은 서버가 정한 순서로 새 사건이 된다.
8. 응시 결과·포인트를 새 답안처럼 재실행하지 않고 현재 오답 조회/요약만 갱신한다.

처음 오답을 만들어 아직 상태 행이 없는 경우도 직렬화되어야 한다. 학생 단위 또는 같은 의미의 안정된 잠금으로 첫 행 생성 경합을 막고, 학생→응시→문항→뜻 상태→대기 연결의 일관된 순서를 검토한다. 현행 답안/만료 경로의 잠금 순서와 충돌하면 전체 관련 경로를 함께 조정하고 실제 PostgreSQL 두 연결로 교착을 검사한다. 학생 전체 잠금이 과도하면 학생+뜻 키의 잠금 대안을 같은 검사로 비교한다.

재출제 대기/예약/대상 연결은 미해결 구간 ID를 참조한다. 과거 해결된 구간의 배정이 남아 있다는 이유로 새 미해결 구간의 배정을 막지 않는다. 관리자 미리보기 이후 학생이 해결했다면 저장 거래 안에서 구간/상태판을 다시 검사하여 오래된 미리보기를 거절한다. 재출제와 해결이 동시에 저장되는 사례를 M03-T4/T5에 포함한다.

정답 처리와 시험 전체 통과는 다르다. 전체 점수가 미통과여도 해당 단어를 정답 처리했다면 그 뜻은 해결할 수 있어야 한다. 단, 현재 자율 연습은 정규 해결 근거로 사용하지 않는다.

## 5. 읽기·UI·캐시·영향

기본 탭 이름은 “현재 오답”, 보조 진입은 “지난 오답 이력”으로 제안한다(표시 구현 선택). 현재 목록 총수·검색·정렬·페이지·배정 가능 수는 같은 미해결 집합을 사용한다. 해결 시 목록에서 빠진 만큼 페이지를 채우되 커서 중복/누락을 막는다. 과거 사건 정렬은 안정된 시각+고유 키를 사용한다.

현재 목록 커서는 학생·조건·현재/이력 구분·현재 상태 변경판에 묶는다. 해결/새 오답으로 상태판이 바뀌면 이전 커서를 거절하고 첫 페이지를 다시 받는다. 과거 이력은 조회 시작 사건 상한을 고정할 수 있다. 개인 오답 문제지·다음 시험 선택도 대표 질문 ID 하나가 아니라 선택한 뜻/구간의 실제 공용 문항을 선택하도록 함께 연결한다.

정답 확정 후 해당 학생의 오답/학습 요약/배정 후보 캐시를 함께 갱신한다. 다른 학생의 캐시까지 전체 비우지 않는다. 로그아웃/계정 전환에는 개인 목록·상세의 표시 캐시를 폐기한다. M05의 미전송 답 복구 기록은 별도로 보호한다. 새 조회 실패를 “현재 오답이 없습니다”로 표시하지 않는다.

변경: UI·state·domain·data·API·캐시·오류 화면·검사. 확인만: 경로·스타일·인증 정책·기존 시험 시간/포인트. 새 로그인/별도 자료 복사 없음. “현재 오답이 없습니다. 새로 틀린 단어가 생기면 여기에 모입니다.”는 성공한 0건에만 사용한다. 오류는 “오답 목록을 불러오지 못했습니다. 다시 시도해 주세요.”, 재배정 중 결과 미확정은 저장 상태 확인을 제공한다. 공통 U1~U10에 M03-T9를 연결한다.

## 8. 화면 진행·답 저장 분리와 연결

M05가 먼저 표시한 정오답은 공식 오답 사건이나 해결 근거가 아니다. 서버가 인정한 고정 문항판·단계·선택과 실제 접수 사건으로만 M03 상태를 바꾼다. 지연 답/중복 전송/최종 거절이 생겨도 학생의 현재 오답을 임시로 삭제하거나 과거 사건을 중복 생성하지 않는다. M03-T4/T5와 M05-T8/T9/T13에서 동일 입력의 서버 결과를 대조한다.
