# 공용 사전·학생 기록·화면 유지보수 전체 지시서

**이번 추가: [M11 답 복구·종료 반복 수리](15_답복구와_종료실패수리.md)를 분리하고, [M05](05_시험준비와_재시험캐시.md)를 공용 자료 재사용·화면 진행과 답 저장 분리·서버 최종 확정까지 확대했다.** 초판의 메모리 한정·서버 저장 대기 중심 설명은 M05의 새 계약으로 대체한다. 실제 구현·배포를 했다는 뜻은 아니다.

**목표는 공용 단어·뜻·출처를 한 번 보관하고, 단어장·배정·학생 기록을 키로 연결하는 것이다. 기존 학생의 배정·응시·점수·오답·발음을 보존하면서 반복 저장을 줄인다.** 현재 오답의 해결 기준과 종류별 단어장 화면도 함께 바로잡는다.

이 문서 묶음은 실행할 내용을 정리한 설계 지시서다. 앱 구현, DB 이전·삭제, 배포가 완료됐다는 뜻이 아니다. 이번 작성으로 작업 대장의 활성 작업과 우선순위를 변경하지 않았다. M/F 번호는 문서 안에서 찾기 위한 번호이며, 착수할 때 대장에서 독립 결과별 APP/OPS/DEPLOY 번호를 부여한다. 같은 문서를 중복 작성하지 말고 정식 번호의 지시서에서 이 문서를 연결한다.

4. 시험 문제는 [최신 진단 8·9절](../../verification/20261001_시험멈춤과자료재사용_점검.md)과 [첫 답 재현 근거](../../verification/20261001_첫답멈춤_재현근거.json)를 먼저 읽는다.

## 3. 이번에 이미 확정된 요구

- 원본 PDF·추출 전문·외부 사전 원응답·긴 검토 근거의 기준본은 로컬 `영어/`다. Drive 백업은 사용자가 관리한다.
- 학생 시험에 필요한 짧은 뜻·정의·예문·발음·음원 참조는 온라인 공용 자료로 제공한다. 학생 시험이 로컬 PC 켜짐에 의존하면 안 된다.
- 원래 사전 ID를 재사용한다. 앱의 짧은 연결용 ID와 단어의 의미를 정의하는 기준 ID를 혼동하지 않는다.
- 단어장과 배정은 선택값·세트판·문항판을 참조한다. 학생마다 같은 뜻·원문·근거를 복제하지 않는다.
- 같은 단어의 같은 뜻을 A/B 단어장에서 틀리면 현재 카드 하나로 묶는다. 최초·재시험의 실제 실패를 각각 세며, 정답이면 해당 뜻을 해결한다.
- 이후 새 오답은 새 미해결 구간으로 시작한다. 과거에 틀린 기록은 유지하되 현재 오답을 계속 붙잡지 않는다.
- 완료·만료·최종 미통과의 배정/결과는 남긴다. 학생 로그인·로그아웃을 학습 이력으로 오래 쌓지 않는다.
- 단어장 만들기의 주 탭은 수행평가/직전대비/모의고사/기타다. 종류에 필요한 입력만 먼저 보여준다.
- 단어 보기와 시험은 공용 ID·불변 판의 같은 내용을 재사용하고, 없는 내용만 미리 받는다. 미리 받기는 시험 시작이나 시간 차감을 하지 않는다.
- 공용자료는 48시간 기기에 재사용하고 전체 필수 자료 준비 후 시작한다. 기기에 답과 진행 위치를 저장해 채점·화면 전환하며, 풀이 중 답/다음 문항/시간초과 서버 요청은0회다. 풀이가 끝나면 답안 묶음을 한 번 제출한다. 답마다 배경 저장하는 방식도 제외한다.
- 서버가 공식 성적·오답·포인트를 확정한다. 미전송/미확정 답은 캐시 정리·로그아웃·롤백으로 잃지 않게 보호하고 접수 전 공식 완료로 표시하지 않는다.
- 무료 운영을 우선 검증한다. 앞선 ‘5~10명’이나 ‘학생당 월 4~6MB’를 개선 후 구조의 한계로 재사용하지 않는다.

## 6. 수치 기준과 완료 판정

2026-10-01 읽기 전용 기준선: DB 약776.33MB, 앱 등록30,073행/철자별8,965개, 학생 상태4,168·오답 사건1,807·응시88행. 핵심 세 학생 표의 내용 합계는 약0.768MB다. 이 수치는 이전 직전에 다시 읽어 최신 증가분을 분리한다.

100명·6개월·월20새응시·50문항·최초오답20%·재오답20%의 키 중심 기록 예산은 상태 보존량에 따라 약39.06~57.78MB다. 실제 물리 상한이나 무료 운영 보장 수가 아니다. [M09](09_무료운영인원과_부하검증.md)는 공용 자료·기존 선택 답안·포인트·인증·음원·전송·검색 구조까지 더해 다시 계산한다.

## 7. 이 묶음의 권한과 미결정 취급

이 문서 묶음은 상세 지시서와 검토 기록이며, 사용자는 이후 유지보수 실행도 승인했다. 현재 상태와 실행 순서는 루트 대장을 따른다. 보관 기간·기기 채점 정보·지연 답 인정·공지 전달·관리자 분리·단어장 공유는 모두 [결정표](13_공통보존과_결정검사기준.md)에 확정되어 있으므로 재질문하지 않는다. 내부 표 이름·함수 분리·배치 크기는 근거를 남겨 개발자가 정한다. 새로 발견한 업무상 결정만 같은 표에 구분해서 모은다.

미결정은 해당 기능의 구현 착수 관문에서 처리한다. 상세 설계 문서를 만드는 작업을 중단하거나 다른 독립 지시서까지 미완성으로 남길 이유는 아니다. 원자료·학생 기록 삭제와 운영 배포는 실제 대상·복구본·검토 결과가 준비된 실행 단계에서 당시 승인 범위에 맞춰 진행한다.
