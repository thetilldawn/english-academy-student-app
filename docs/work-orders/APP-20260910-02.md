D1: 사용자 ㄱㄱ와 기존 보고서의 로컬 후속 패치. 실제 회차를 임의 재개·보류·취소하거나 DB를 고치지 않는다.

D2: 서버 수정 시각을 비교해 이미 도착한 최신 처리 결과를 우선 반영한다. 복구 조회가 먼저 끝나도 첫 페이지 밖에서 요청 중인 묶음을 응답 종료까지 유지한다. 실제 요청을 보낸 시점부터 묶음별 요청 수를 기록하고 종료 시 해제한다. 복구 진행·실패 동안 추가 처리를 잠근다. 정상 성공은 해당 묶음만 교체하며 전체를 다시 조회하지 않는다. 학생 변경·화면 종료 시 늦은 응답 차단은 유지한다.

D3: 함수 이름과 오류코드가 모두 맞을 때만 읽기 v1대체. 대체까지 실패하면 빈 내역으로 숨기지 않는다. 학생자동공개의 기존 실패반환 정책은 보존하되 지정함수없음만 로그생략한다.

복구 조회가 성공하면 별도 시험 내역도 한 번 갱신한다. 초기 조회나 실패한 복구에서는 추가 갱신하지 않으며, 수동 재조회가 성공할 때까지 갱신 필요 상태를 유지한다. 배정 명령은 자동 반복하지 않는다. 이 동작은 T2에서 실제 새 배정 상태와 성공·실패 순서별 호출 수로 검사한다.
