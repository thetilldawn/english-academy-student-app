# 배정 대상 목록 개인 캐시 연결

- [기록](../../architecture/work-records/records/APP-20260906-10.json) R1~R3/D1~D6/T1~T6. 기존 승인계획의 학생→배정 확대이며 신규 업무 결정은 없다. 단어 가리기는 이후.
- 학생 목록 DTO/비공개API와 개인 캐시를 재사용한다. 소비화면별 마지막 필터를 분리해 학생 전체/배정 활성 기본값이 섞이지 않게 한다. 최초 문서만 현재 서버 인증/첫 목록을 인계하고 Client 복원은 현재 인증을 다시 확인한다. 기존 reviewDraft/학생/단어장 직접 진입은 유지한다.
- 배정 작성 상태와 요청 수명은 유지한다. 현재 권한 확인 전 표시·입력을 감추고 현재 auth 후 복원한다. 확정 인증 실패만 전체 배정 작업공간을 해제한다. 대화상자는 업무 정보를 모르는 공용 표시 경계로 숨김/닫기·스크롤 잠금·초점 복귀를 관리한다. 확인 전 제출은 UI뿐 아니라 명령에서도 차단한다.
- React19.2 Activity는 숨김 시 Effect도 정리한다. 기존 준비 요청을 취소한 후 loading이 남는 경로가 있어 단순 감싸기를 도입하지 않는다. [공식 근거](https://react.dev/reference/react/Activity). 새 기능을 이름만 적용하지 않고 실제 수명을 보존한다.
- 15/60/120초·포인트 비저장·세대/계정격리·늦은응답/커서 폐기는 APP08과 같다. 배정 저장 성공 시 알림과 직접 재조회가 중복되지 않게 하나로 만든다. 필터 전체선택210/최종서버 검증은 캐시로 대체하지 않는다.
- 별도 ASSIGNMENT_DIRECTORY_CACHE_CANARY 기본 OFF이며 STUDENT_DIRECTORY_CACHE_CANARY가 켜진 경우에만 적용한다. 고정된 최초10%/왕복30% 관문과 실제 로컬10회 검사 후 채택 판단한다. 운영 비용/실DB계측과 대역 실측은 구분한다.
- T1 저장소/조건, T2 실제 모달/숨김/복원/인증, T3 현재 필터/변경/커서/요청, T4 전체/타입/lint/구조/빌드, T5 실제IAB, T6 독립 리뷰. 이전 결과를 현재 파일 검사로 재서명하지 않는다.
- D5: 준비·선택·단위·최근 시험·오답 요약·미리보기·저장·시간 양식의 현재 401/403은 배정 내부 인증 경계로 전달한다. 조회는 취소/세대를 확인한 뒤 전달하고, 저장은 시작 시 화면 세대를 붙잡는다. 해제된 창의 실패는 새 창을 잠그지 않으며 저장 자체를 취소하지 않는다. 이 경계는 React 외 의존이 없고 네트워크/업무 계산을 포함하지 않는다.
- D6: 같은 탭의 로컬 알림과 별도 방송 수신이 중복되던 문제를 같은 난수와 구독자별 최대128건 중복 제거로 수정한다. 타 구독자/다른 탭에는 정상 전달하며 개인정보를 전송하지 않는다.
