# 학생 시험 답 선택과 정오답 표시 보완

2026-10-01 사용자 추가 요청. 완료된 포인트 정정과 분리하며 기존 학생 자료는 보존한다.

## 요구와 결정

- R1 / D1: 마지막 답 선택 뒤20ms 확정, 정오답200ms 표시후 자동이동. 답을 고른 뒤 영어 자동재생과 스킵을 없앤다. 표시 중 클릭/터치는 무시한다.
- R2 / D2: 느린 서버 준비 중 마지막 선택은 보존한다. 응답유실 후 서버에서 실제 저장답을 확인한 경우 정오답 표시를 복원한다. 불명확한 답을 임의 정답/오답으로 만들지 않는다.
- D3: 문제 음성·수동스피커·채점·포인트·시험시간·권한·DB 계약은 유지. 실제 학생 답 제출은 검사 수단으로 쓰지 않는다. 로컬 구현과 운영반영은 별도 증거로 구분한다.
- 미결정 없음. 검토 순서: 입력/표시·서버계약 독립조사→설계 관문→구현/재현검사→가짜 실제화면→마감 검수.

## 변경 영향

경로·Server Component·API/DB/보안은 확인만. UI/controller/domain/검사를 수정한다. 기존 정규 시험과 자율연습이 같은 플레이어를 사용한다. 사용 사례는 기존 controller와 전송 객체를 재사용하며 새 application/캐시/서버계층은 만들지 않는다. 오류/복구·로딩은 기존 공용 표시를 유지한다. 화면별 조건·실제문구·복구는 같은 번호 JSON의 uiStates를 기준으로 한다.

기존 코드는 답 선택100ms, 정오답 최소250ms/무음750ms, 음성종료/스킵 대기를 혼합했다. 답 요청이2초를 넘으면 재조회하며 저장된 정오답을 복원하지 않는 경로를 확인했다. 실제 학생의 개별 사건 원인은 아직 재현으로 확정하지 않았다.

## 검사

- T1:19/20ms·199/200ms 경계, 초기/재시험·정오답, 음성 유무/고장 무관, 최종결과, 늦은 응답/동기화, 유실복원, 이탈, 연타,5/8/10초·전체시간·제한없음.
- T2:기존 관련회귀·타입/lint·구조/기록·전체빌드.
- T3:서브에이전트 독립 소스 검토와 최종 재검수.
- T4:격리 가짜 실제 브라우저로 선택→정오답→자동 다음, 반복터치·음성 확인. 운영 실학생과 구분.
