# 시험 자료 재사용과 종료 제출

APP-20261002-03 / 승인된 M05. 기준 e39157c. [상세 요구](20261001_공용사전과학생기록_유지보수/05_시험준비와_재시험캐시.md)의 R1~R10/T1~T18을 같은 번호로 앱 기록에 연결한다. D19~D21이 확정되어 사용자 미결정은 없다. 실제 상태와 순서는 루트 대장을 따른다.

자료는 고유키/태그·불변판과 표시 확인값으로 기기에48시간 재사용한다. 진행 중/답 미확정 시험은 원판을 보호한다. 학생별 계획은 자료 참조·문항/보기 순서·최소 채점값·시작/마감·원래 기기 결속만 가지며 답 본문 사본을 만들지 않는다. 미리 받기는 읽기 전용이고 실제 시작에서만 준비·응시를 만든다.

새 규격은 별도의 기기 저장과 제어기를 사용한다. 답과 다음 위치를 한 IndexedDB 거래가 완료한 뒤 판정/진행하며 기기 실패에서는 원선택을 남기고 멈춘다. 시계와 선택 확정20ms·정오답100ms는 명시적으로 검사한다. 음원은 기존 CDN URL로 직접 재생하고 현재/다음 문항 미리 불러오기와 일반 브라우저 캐시를 사용한다. 별도 음원 저장소/앱 중계는 없고 오프라인 음성은 보장하지 않는다. 새 규격에서 구형 답·feedback·전체재조회·expire 제어기를 마운트하지 않는다.

서버는 새 응시의 규격·기기와 회차 계획/시간판을 고정한다. 종료 명령1개가 전체 답 집합·순서·선택·시간을 먼저 검사하고 공식 재채점→M03접수/뜻 상태→공식 단계/포인트→M04요약→제출 영수증을 한 거래로 처리한다. 같은 ID/같은 내용은 같은 결과, 다른 내용은409. 전체 답의 확인값을 대조한 뒤에만 접수 확인 상태로 바꾼다. 답별 작은 접수에 전체 묶음을 중복 저장하지 않는다.

기한 내 기기에 기록한 답은 늦게 접수해도 인정한다. 구형 자동 만료/시작/문항별 명령은 새 규격을 먼저 종료할 수 없다. 시간은 서버 시작값·고정 제한·기기 경과시간을 검증하며 수신시각과 풀이 종료시각을 분리한다. 브라우저 시각 자체는 변조 가능하므로 오프라인 선택시각을 완전한 증명으로 주장하지 않는다. 다른 기기 인계0, 접수 미확인 답 자동 삭제0이다.

네트워크 없는 전체 새로고침은 개인HTML/API/RSC를 캐시하지 않는 공용 시험 화면에서 복원한다. 현재 학생 보호 layout의 주기 세션/알림 요청과 독립한다. 기기의 지속 세대와 탭 진행 잠금으로 계정전환/다중탭을 차단한다. 오프라인 동안 서버 권한 철회를 즉시 알 수는 없으며, 관측한 로그아웃은 즉시 가리고 재연결/제출에서 현재 인증을 다시 확인한다. 계정 전환은 답 삭제가 아니다.

단어 보기·시작 버튼·재시험은 같은 자료 저장 경계를 사용한다. 구형 응시는 끝까지 기존 규격이다. 신규 시작 비활성화로 복구할 수 있으나 새 묶음 수신과 미확정 답 복원 경로를 제거하는 배포 복구는 금지한다. 실제 학생·운영 쓰기 없이 가짜 SQL/HTTP/PC/390px·오프라인/음원/두탭·저장실패·시간경합·전체회귀 검증 후 별도 M10으로 넘긴다.

음원 결정 D7(2026-10-02 사용자 교정): 기존 CDN 직접 재생·일반 캐시로 처리한다. 별도 파일 보관/웹스터 중계는 제거했다. 공개 파일 응답 확인에서 웹스터는 CloudFront, 보유 음원은 Supabase/Cloudflare와 브라우저 읽기 허용을 확인했으나, 본 작업이 새 CDN을 도입한 것은 아니다. 실제 음성·API 요청을 분리 검사한다.

미리 받기는 전역 동시2개·대기 포함8개 상한, 같은 배정 합치기, 마지막 구독 취소/계정 전환을 반영한다. 공용 화면 설치/복구는 독점 잠금, 풀이 중에는 공유 잠금을 잡아 새 화면 파일 다운로드를 막는다. 누락 공용 파일은 시작 전 재검증 복구하며 개인 답은 지우지 않는다.

완료 범위: 신규 흐름 연결에 따른 기존22경로는 HEAD 대비 코드를 수정하지 않고 T16/T18 회귀 확인 범위에 포함했다. [검증 결과](../verification/APP-20261002-03_검증결과.md)에 구현·검토 DB와 운영 배포의 경계를 기록했다.
