## 요구와 결정

- R1/D1: 학생 내역의 오답 목록은 기본 접힘이다. 펼칠 때 최신 10개를 서버에서 조회하고 다음 10개만 더 읽는다. 전체 원시 오답·배정 문항을 브라우저나 앱 서버로 전달하지 않는다.
- R2/D2: 오답 횟수는 기존 최초 오답 사건 수를 사용한다. 사건 당시 사전/정규어 식별자, 출처, 해결·대기·배정 상태와 검토된 문항 원문을 보존한다. 최신순으로만 표시 순서를 바꾼다.
- R3/D3: 출제 불가 후보는 단어와 이유를 표시한다. 가능한 후보가 있으면 ‘제외 항목을 확인하고 가능한 단어로 배정’을 직접 선택해야 한다. 모든 후보가 불가하면 저장을 막고 ‘오답 없음’으로 표시하지 않는다.
- R4/D4: 확인은 학생·자료·오답 단계·방향·실제 문항판·제외 목록에 묶는다. 저장 직전 서버와 DB가 전체 후보를 재검사한다. 같은 개수라도 다른 후보이면 다시 확인하며 과거 성공 요청은 먼저 반환한다. 제외된 오답의 상태는 변경하지 않는다.
- R5/D5: 학생용 후속 화면에 재사용할 목록·요약 계약을 분리한다. 현재 공개 조회는 관리자만 가능하며 이번에 학생용 새 화면이나 권한을 열지 않는다.

D6(내부): 커서는 학생·필터·마지막 오답 시각/단어 키·사건 상한 ID를 묶고 ID는 문자열로 전달한다. 첫 페이지 교체 때 과거 커서를 폐기한다. 더보기 실패는 읽은 목록을 유지하며 권한 거절 때는 숨긴다. 조건/학생 변경은 선택을 해제하고 늦은 응답을 버린다. 전체 집계는 현재 상태이며 과거 해결/배정 시점으로 고정됐다고 표시하지 않는다.

D7(내부): 제외 후보의 가능 여부도 보기 풀·다른 문항의 중복에 의존한다. DB 내부에서 해당 자료의 실제 단어/연결/방향/문항판과 전체 출처 질문을 확인값으로 묶고 앱에는 64자 확인값만 반환한다. 저장 중에는 dataset→version/release→entry→자식 순서로 부모와 실제 행을 잠가 새 자식 추가도 차단하고 저장 전후 비교를 한다. 별도 발음 등록부의 후속 개정은 문항판 확인과 구분한다. 실제 다중 연결의 잠금 대기 시간·운영 자료 크기의 성능은 로컬 단일 연결 검증으로 대신 주장하지 않는다.

## 조회와 저장 계약

관리자 인증 → 학생 한 명의 최초 오답 사건을 DB에서 단어별 집계 → 단어장/횟수/검색 필터 → 최근 시각·단어 키로 11개 확인 → 10개 상세와 다음 커서. 첫 페이지에 전체 요약·자료 선택 목록·유효 준비 초안 개수를 반환한다. 다음 페이지에는 필요한 단어만 반환한다. 원시 사건·모든 대기열 항목은 응답에 넣지 않는다.

출제 미리보기는 전체 후보 수/가능 수/불가 수와 구체 사유·확인값을 반환한다. 브라우저는 확인값과 제외 동의만 보낸다. 서버가 가능한 후보를 다시 계산한다. 새 저장 경로는 전체 후보 일치와 출제/제외의 정확한 분할, 순서, 관리자·학생 필수값·일정·큐·문항 수·발음/문항 스냅샷·한 번 저장을 함께 보장한다. 구형 전체 출제 경로의 엄격한 비교는 유지한다.

학생 관리가 목록/커서/표시를, 배정 기능이 진단/미리보기/최종 저장을 소유한다. 새 공개 경계가 필요할 때는 공개 계약만 노출한다. 기존 학생·시험·점수·원사전 수정과 자동 오답 해결 처리는 해당 없음이다. no-store와 현재 인증 수명을 유지하며 주기 조회와 개인 공유 캐시를 추가하지 않는다.
