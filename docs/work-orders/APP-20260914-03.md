# 학교 어휘 두 방향 등록

학교 원문의 뜻 두 방향만 쓰는 새 교재를 지원한다. 기존 네 방향 private 등록과 원문/품사/정답/발음/권한 검사는 보존한다. 승인 수량2배는 두 방향 각1개·빈 숨김만 허용하고 학교 미제공 정의만 NULL로 둔다. 기존 회차 표시와 UI/배정 계약은 재사용한다. 자료는 사용자 모고 분할 후속을 반영해1과·2과와 연도별6회, 총14회차로 준비한다.25개씩 분할은 선택 질문 미응답 뒤 알린 기본값이며 사용자 확정 수량으로 표시하지 않는다.

R1 방향, R2 원문/기존자료 보존, R3 기존 앱 연결을 T1 학교 SQL·T2 기존 검토형 회귀·T3 타입/구조/기록 검사로 확인한다. 독립 구현 검토 후 Preview→운영 자료 등록은 DEPLOY-20260914-04로 분리한다. 실제 학교 원고는 영어 자료 구역에만 둔다. 공개 코드/웹 재배포는 필요 없으며 새 SQL 한 건을 기록한다.

실행 근거: [로컬 검증](../verification/APP-20260914-03.md). 실제 DB 변경은 자동 승인 검토가 거절하여 외부 적용 전이며, 자료 원고 검토와 로컬 구현 검증을 실제 교재 등록 완료로 표시하지 않는다.
