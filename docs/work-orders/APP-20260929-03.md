# 시험 응답 대기 보완

R1: F01의 헤더 수신 뒤 본문 무한대기만 최소 수정한다. D1은 현재 사용자 승인, D2는 기존 공용 deadline 재사용이다.

답 제출·상태 복구·피드백 전환은 fetch와 JSON 소비에 합산 2초를 적용한다. 만료 요청은 응답 본문을 사용하지 않으므로 헤더까지 한도를 적용하고 원래 Response 계약을 보존한다. 표준 취소, 타이머 정리, 늦은 응답 무시를 검증한다. 성공 스키마·서버 멱등·현재 학생 소유권·개인 no-store·100ms 입력과 모든 시험 시간 규칙은 변경하지 않는다.

T1은 전송 예외, T2는 실제 시험 부품의 기존 복구/시간/입력 회귀, T3는 독립 검토와 구조/타입 검사다. 새 UI·자동 답 재전송·운영 쓰기·DB 변경·배포는 없다.
