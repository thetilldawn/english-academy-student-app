# 공용 범위·완료 구성의 과거 본문 이전과 부분 복구

승인된 M01/M08-R1~R5의 빠진 과거 자료 이전 도구를 보완한다. 입력은 M01 공용 사용값과 APP-20261003-02 파일·확인값·부분 복구 원칙이다. 새 학생 기능·업무 정책은 없다.

## 요구와 검사

| 요구 | 합격 기준 | 검사 |
|---|---|---|
| R1 | 저장된 과거 범위/구성 값만으로 공용 값을 만들고 출처·선택 뜻·발음·음원 URL·빈값/공백/순서를 그대로 보존 | T1/T2 |
| R2 | 기존 원키·고정판·documentHash·content_sha256·fingerprint 유지, 구형 확인값과 새 저장 문서 연결을 매 읽기에서 검증 | T2/T3 |
| R3 | 외부 사본 저장·재읽기 뒤 지정 키/원행 확인값의 짧은 묶음만 전환. 중단·재시도·동시 생성·늦은 확정에 누락/중복0 | T4/T5 |
| R4 | 진행/미완료 구성·배정 보호. 복구는 허용 본문 열만, 학생 답·문항·뜻 정체성·판 번호 수정0 | T5/T6 |
| R5 | 앱 역할 권한0, 불변 보호 우회0, 실제 구형 자료 입력과 파일 복구/기존 소비자 회귀 근거 | T1/T6/T7 |

## 결정

- D1 사용자 확정: 단어·출처 고유키와 선택 뜻으로 공유하고 중복된 본문만 줄인다. 자료 본문은 프로젝트의 추출/색인과 실제 복구 가능한 사본으로 관리한다. 근거는 사용자 유지보수 지시와 승인된 M01/M08이다.
- D2 사용자 확정: 학생 배정·완료·미접수 답·현재 오답·통과 기록을 보존한다. 공용 자료48시간, 미사용 준비24시간, 미접수 답 자동 삭제 금지를 변경하지 않는다.
- D3 내부 설계: 이 보완은 범위 행의 entry_snapshot/occurrence_snapshot/resources와 완료 구성 행의 source_snapshot/resources만 대상으로 한다. 원출현·검토 자료 묶음·구성 문항은 별도 소비자 이전이 필요하다. 모호한 원행·일치하지 않는 구성의 두 resources는 제외한다.
- D4 내부 설계: 과거 사본 전용 등록 경로를 만들고 M01의 순수 값 투영·검증·축약을 재사용한다. 현재 연결표/검토표를 읽는 기존 등록 경로는 과거 이전에 사용하지 않는다. 현재 사전값을 채워 넣거나 과거 뜻을 검토된 뜻으로 승격하지 않는다.
- D5 내부 설계: 고정된 판과 확인값은 갱신하지 않는다. 원래 문서 해시·전환된 문서 해시·공용 값/출처 참조를 별도 작은 이전 기록으로 연결하고 확장/고정판 확인 경로에서 검사한다. 원본문을 이전 기록에 다시 저장하지 않는다.
- D6 내부 설계: 기존 구성은 이동 전의 뜻 계산을 그대로 유지하도록 출처·선택 품사·사전 연결의 작은 사용값을 복원한다. 본문 전환 전후 기존 문항의 wordKey/meaningKey/identityKind 및 표시값이 다르면 거래를 취소한다.
- D7 내부 설계: 명시한 원행 키와 확인값으로 최대100행의 작은 묶음을 처리하고 같은 요청은 같은 결과를 반환한다. 완성 상태·구성 행 잠금·기존 생성 잠금과 원자료 보호 잠금의 순서를 대조한다. 생성 중/완료 전환/초안 배정과 충돌할 때는 제외 또는 재시도하며 추정으로 완료 처리하지 않는다.
- D8 내부 설계: 복구는 접근 제한 자료 폴더에서 실제 읽은 원문과 현재 참조/전환 해시를 대조하고 허용 열만 원래 값으로 되돌린다. 고정판·원키·최근 학생 기록·구성 문항·기존 뜻은 수정하지 않는다. 검토 DB의 가짜 연습과 실제 운영 사본을 구분한다.

## 설계 영향

변경은 DB 내부 이전·검증·제한 복구와 공용 읽기의 호환 검사다. 기존 M01 사용값·M02 문항 참조·M03 뜻·M04 결과·M05 제출을 보존한다. UI·경로·상태·CSS·브라우저 캐시·음원 내용은 변경하지 않는다. 깨진 연결을 빈값이나 최신값으로 덮어 숨기지 않는다.

구체 설계는 독립 조사와 기존 생성/시작 함수 대조를 거쳐 다음으로 정했다. 형식·설계 관문 뒤 구현한다.

1. 운영자 거래는 `READ COMMITTED`, 전체 문장30초 이하·잠금 대기1초 이하를 요구한다. 공용 버전·구성 부모·구성 행·범위 행4표에 같은 순서의 `SHARE ROW EXCLUSIVE NOWAIT`를 사용한다. 이어 원자료/생성 자료·자료 목록, 관련 구성 부모, 관련 배정, 대상 행을 정렬하여 `FOR UPDATE NOWAIT`로 잠근다. 이미 진행 중인 쓰기와 충돌하면 즉시 운영자 거래를 취소한다. 기존 앱 생성 함수의 잠금 순서는 변경하지 않고 학생 잠금도 추가하지 않는다. 모든 상태는 잠금 뒤 새 조회로 확인한다.
2. 관련 버전은 `recipe.scopes`와 구성의 `build_positions.scope_ids` 양쪽으로 찾는다. 새 판/구성/행 INSERT는4표 잠금이 막는다. 현재 read-only 상태에서 옛 값을 읽은 뒤 쓰려는 생성도 기존 고정판·문서 확인값이 유지되며, 새 생성은 M01 형식을 사용한다. 이미 만들어진 구형 미완료 구성은 제외한다.
3. 관련 배정은 원자료/생성 자료 dataset_id, 다중 출처 assignment_sources, 개별 문항 dataset_id/composition_version_id_snapshot/원단어키로 찾는다. 대표 자료가 다른 개인 오답도 포함한다. 배정 잠금 후 draft·진행·재시험·미시작 준비·M05 기기 제출/준비 연결을 다시 검사한다. 현재 시작 함수도 배정을 FOR SHARE로 잡으므로 이미 존재하는 배정에서 새 시험을 시작하는 경합을 포함한다. 새 직접 배정은 원dataset의 공유 잠금/외래키 확인, 구성 배정은 구성 부모 잠금과 충돌하므로 경합을 빠뜨리지 않는다.
4. 준비 완료 검사 함수는 기존 동작을 바꾸지 않는다. 이전 전용 검사에서 ready·question_sha256, build가 있을 때 preparation_complete/전체 커서·기존 완료 검사, plan이 있을 때 처리수, 실제 구성/단어 수와 문항 확인값을 추가 대조한다.
5. 과거 등록은 원래 E/O/R/범위 머리말에서 값·출처를 투영한다. 외부 연결/검토표를 조회하지 않는다. 기존 source-occurrence 뜻 계산을 보존하고, 기존 구성의 뜻 계산 함수는 이전 증명이 있는 참조형에서 당시 선택 품사/사전 사용값을 풀어 구형 경로로 계산한다.
6. 범위 row_document/expand와 판 확인에서 원본 문서 확인값→이전 증명→현재 작은 문서 확인값을 검사한다. fingerprint와 고정판은 유지한다. 두 본문 표의 불변 트리거만 정확한 현재 거래의 행·전후 확인값에 묶인 일회 허용을 받는다. 다른 불변 트리거와 공용 거절 함수는 변경하지 않는다.
7. 외부 사본에는 PostgreSQL이 만든 원행 JSON을 문자열 그대로 보관한다. JavaScript에서 원행 숫자를 해석했다가 다시 쓰지 않아 큰 정수 식별자의 정밀도를 보존한다. 파일 확인과 DB 원행 확인값을 둘 다 검사한다.
8. 과거 범위에서 나중에 새 단어장을 만드는 작업은 기존 신규 생성 정책을 유지한다. 실제 이전된 범위의 공용 선택값·원본 확인값은 그대로 두고, 새 구성에만 현재 연결/검토된 뜻을 대조한 별도 출처 참조를 만든다. 과거 범위·완료 구성에 소급 적용하지 않는다. 같은 범위의 이전 전후 신규 구성→신규 배정에서 단어·뜻 식별값 전체를 비교하며, 선택 사전 없음+기존 연결 있음과 검토된 모의고사 뜻을 각각 검사한다. 외부 사본은 현재 worktree뿐 아니라 조상에 `.git`이 있는 모든 저장소에서 거절한다.

네 표 잠금은 일반 읽기를 막지 않으나 짧게 공용 자료 쓰기를 대기시킬 수 있다. 기본25/최대100행에서 잠금 시간을 검토 DB로 측정하고, 충돌/시간 초과를 전체 취소로 기록한다. 큰 묶음으로 강행하거나 앱 흐름을 종료시키지 않는다.

## 검사

- T1 구형 스키마에 먼저 만든 가짜 범위/구성, 새 SQL 적용 직후 원행 불변.
- T2 학습값·발음·선택 뜻·원출처·고유키·공백/null/배열 순서 전수 대조와 큰 본문 중복 제거.
- T3 고정판 v1/v2·fingerprint/documentHash·이전 연결의 정확성, 깨진 확인값·참조 거절.
- T4 파일 저장/재읽기·지정키/원판 대조·최대100행/크기 제한·중단·같은 요청·표기만 다른 중복키 거절.
- T5 생성 중/완료 진입/새 배정과 실제 잠금 경합, 낮은 키 늦은 확정 재조회, 보호 대상 제외.
- T6 파일에서 지정 본문만 복구, 이후 새 학생 기록과 기존 문항/뜻/판/관계 전열 보존.
- T7 앱 역할 권한·직접 쓰기 거절·기존 읽기/생성/배정/학습/기록 회귀·타입/린트/구조/빌드, 실제 적용 전후 보존 검사.
