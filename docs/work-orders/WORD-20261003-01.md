# 기존 단어키에 누락 발음 연결

사용자 2026-10-03 요청과 10월5일 우선순위 확정에 따른 같은 WORD 작업의 앱 연결 보완이다. 자료 목록/원고는 영어 자료 영역의 해당 작업기록에 보관하며 현재 상태는 루트 대장만 따른다. 읽기 전용 독립 구조 검토와 범위 검토를 반영했다.

- R1/D1: 기존 사전·원단어 키/뜻/태그를 유지하고 보유 음원키만 재사용한다. 학교73은 원문 확인값이 일치하는 한 범위만 일반 발음 연결에 허용한다. 새 사전/단어본문/identity 생성은 없다. T1으로 범위와 기존등록계약을 검사한다.
- R2/D2: 신규 선택 배정에서만 빈 발음을 채운다. 선택 관계→원키→정확 원행→기존 활성 음원 참조를 대조한다. 정상 슬롯/원래 표시/기존 변이를 덮지 않는다. T2로 표적/보기와 변조 거절을 검사한다.
- R3/D3: 기존 은행 전체 확인값은 그대로 검사하고, 새 배정의 공용 문항 payload에서 발음 필드 하나만 따로 확정한다. 과거·진행 시험과 기존 표기/문항/뜻/학생 기록은 읽기·보존한다. T2에서 기존/신규와 연결판 퇴역 후 고정값을 검사한다.
- R4/D4: 같은 원키·확인값·품사·CDN 주소를 검토한 누락만 연결한다. 동일 입력 재실행 중복0, 기존 연결 삭제0. T3에서 검토→운영의 정확키/원문/학생기록 확인값을 비교한다.

현재 구조: 일반 승인 발음표, 기존 모의·수능 보충표를 사용한다. 새 표/열/사전/음원 사본은 추가하지 않는다. 공식 음원은 CDN URL, 기존 생성 음원은 현재 Storage 객체키를 참조한다. 보유 음원의 새로운 출처 연결은 자료 작업으로 별도 명세에 고정한다.

변경 경계: 기존 승인 범위 함수와 신규 구성 문항의 내용 등록/읽기 함수, 이를 지원하는 내부 발음 검사·보충 함수만 수정한다. 기존 문항 은행의 원형 복원 함수와 원본문 확인값은 바꾸지 않는다. 브라우저 화면/채점/음성중단/48시간캐시/24시간정리/미접수답 보관은 확인만 한다. 정상 입력은 기존동작, 오류는 기존 저장실패 안내와 재시도를 유지한다. UI/HTTP 계약 변경 없음.

T1: 기존 학교 발음 scope 통합검사와73키 참조 명세 검증. T2: 4문항 가짜 신규 배정의 누락만 보충·기존 배정 동일·잘못된 출처/해시/필드 거절. T3: 원고/DB기존값/함수권한 대조와 검토→운영 readback. 실제 학생 응시/답안쓰기로 검사하지 않으며 청음은 학생에게 맡긴 기존 지시를 따른다. 필요한 타입/lint/구조/빌드 외 전체 반복·부하 검사는 수행하지 않는다.

복구: 새 발음 연결판을 비활성화하고 이전판을 유지한다. 이미 새 음원을 확정한 공용 문항은 읽기 호환을 유지한다. 일반 은행 payload에 발음이 없는 기존 형식은 기존 경로로 읽는다. 준비/학생답/원음/사전 삭제는 없다.
