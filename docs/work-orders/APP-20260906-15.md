# APP-20260906-15 발음 대기 클릭·터치 중단

기존 시험 진행 보완. 기준 코드506dc7d·근거5c9f0de, Next16.2.12/React19.2.8. APP14 완료 뒤 사용자 확정 순서로 진행한다. 실제 상태·우선순위는 루트 대장 한 곳만 따른다.

## 요구·결정과 경계

- R1/D1: 모든 학생 시험(영어→뜻, 영영풀이/예문→영어, 첫시험/재시험)에서 답 저장 성공 후 음성 재생·시작 대기 중 추가 클릭/터치로 정지하고 진행한다. 탭은 터치이며 키보드 Tab은 그대로다.
- R2: 최초 답 클릭 재사용0, 저장전/실패중단0, 중단입력의 다음답 저장/예약0. 마지막 문항 결과이동1회, 자연종료150ms/무음750ms와 서버시간동기화·복구 보존.
- D2 내부: 기존 공용 진행부에 요청별 음원대기 훅과 좁은 표시부품을 연결한다. UI는 visible/callback만 알고 시험종류·답 저장/채점 규칙을 갖지 않는다.
- D3 내부: 명시적 사용자 중단 결과만 즉시 전환한다. 일반 음원 interrupted(새 재생/이탈)와 구분. 음원대기는 먼저 완료/중단 핸들을 등록하고 화면을 열며, 자연 종료 시 ref를 먼저 닫는다. 클릭에서 입력을 소비하고 pointerdown/touchend에서 다음 문항을 바꾸지 않는다.
- 사용자 미결정0. 업무·보존·공개·비용·의존성·DB 변경없음. 기존 Preview/운영 패치 승인 범위에서 로컬 검증 뒤 순차 배포하며 실제 학생을 대신해 답하지 않는다.

## 책임과 흐름

| 책임 | 연결 |
|---|---|
| 화면·입력 | QuizPlayer→QuizFeedbackSkip. 투명 클릭 영역은 기존 피드백을 가리지 않고 짧은 안내만 표시. 같은 클릭을 소비, Tab 기본동작·다음 문제 focus 보존 |
| 요청 수명 | useQuizSubmission→useQuizFeedbackInterruption. 저장 성공한 요청키에만 연결, 완료/오류/복구/이탈 폐기 |
| 음원 | QuizAudioPlayer 정지·재생세대 갱신·완료 리스너/타이머 해제. 늦은 play/ended/error가 새 문제를 재전환하거나 정지하지 못함 |
| 시간·이동 | resolveQuizFeedbackTransition의 명시중단은 delay0, 기존 resume 멱등 요청/서버시각/복구/결과 분기 그대로 |
| 생성·배정·수정·검색·삭제 | 새 기능 없음: 응시 중 로컬 음성대기만 변경. APP14 첫완료 이후 자동공개·점수·오답·재시험 기록은 기존 서버에서 유지 |

학생 인증·채점·정답 공개는 서버 소유, 중단 신호만 현재 브라우저 요청에 보관한다. API 요청/응답 필드·DB 불변. 시험 snapshot/시간/중단신호는 캐시하지 않고 새 라우트/모달/로딩 지연·공유캐시를 추가하지 않는다. 기능 지도 student-quiz-attempt의 UI/controller 경로를 연결한다.

[Next Server/Client](https://nextjs.org/docs/app/getting-started/server-and-client-components), [React 이벤트](https://react.dev/learn/responding-to-events), [음원 정지](https://developer.mozilla.org/en-US/docs/Web/API/HTMLMediaElement/pause)를 2026-09-07 대조했다. 문서 최신 버전의 새 기능을 설치 버전에 임의 도입하지 않는다.

## 상태·안내·검사

- T5 로컬 도구는 기존 격리 Next 검사 서버에 명시적 `--quiz-feedback` 선택만 추가한다. 기본 읽기 전용 모드는 그대로이며, 가짜 학생/시험6개 ID의 답/시간확인만 메모리 가짜 DB가 처리한다. 실제 Next 인증·입력검증·서버변환을 거친다. 앱 라우트/인증 우회 추가0.
- 검사용 Audio는 실제 브라우저 미디어 요소를 유지하고 고정 가짜 음원주소만 localhost의 낮은 검사음으로 연결한다. 외부 음원 호출0. 재생/정지 시각은 로컬 검사 표시·기록에만 남기며 실제 발음 정확도/청취 검증으로 표현하지 않는다.
- 독립 검토 후 전체시간/시간없음+유한마감/완전무제한 중단 회귀3개도 T3에 추가한다. 정상 배정마감/서버타이머를 중단이 늘리지 않아야 한다.

- 답 저장전/실패: 중단 없음. 기존 선택·정오표시·서버복구 보존, 답 저장 실패를 정상 완료로 바꾸지 않는다.
- 저장후 음원대기: 기존 정오표시 위에 투명 버튼, “화면을 누르면 음성을 멈추고 넘어갑니다.” 영어 내부오류·답 내용은 안내에 넣지 않는다.
- 명시중단: 실제음원 pause, 완료리스너/타이머해제, ref먼저닫기, 다음질문/결과1회. 서버동기화 중 새 문제의 별도 선택만 기존 큐 정책으로 허용.
- 자연종료/실패/무음/시간초과: 기존 대기·fallback 유지, 중단 안내는 숨긴다.
- 최초조회/갱신/없음/실패/인증/404/예외: 기존 QuizFrame·QuizSynchronizationError·라우트 경계 재사용. 상태와 실제 문구·복구는 [RDT](../../architecture/work-records/records/APP-20260906-15.json)의 uiStates를 따른다. 오류를 빈 문항으로 표시하거나 새 존재정보/정답을 노출하지 않는다.
