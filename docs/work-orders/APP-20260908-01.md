일반 문항 writer는 한국어 뜻에서 다시 문항을 만들므로 정의문을 임의로 넣지 않는다. 공통 bank 생성 경계에 검토문항 분기를 추가하고 위 회차·큐의 권한/잠금/멱등을 재사용한다. 기존 날짜없는 단일·단위분할과 예약 분할을 유지하고 예문 모드 제한은 바꾸지 않는다. 새 정의→단어는 비율0, 단어→정의는100이며 기존 방향 enum을 유지한다.

- D6: 별도 TS import 검증기를 복제하지 않고 실제 DB import/승인/해시 함수를 가짜 묶음으로 직접 검사한다. 실제 자료 검토는 WORD 기록과 분리한다.
- D7: 원문에 실제 동의어가 있으면 시험 저장을 위해 뜻을 억지로 다르게 바꾸거나 단어를 삭제하지 않는다. 새 검토문항은 질문·정답·선택지가 고정된 완성 문항이므로, 같은 질문의 다른 정답이 해당 문항 선택지에도 들어갈 때만 중복 정답으로 거부한다. 각 선택지에서 서로 배제된 동의어는 별개 문항으로 허용한다. 기존 자동생성 문항의 전역 질문 충돌 검사는 변경하지 않는다.
