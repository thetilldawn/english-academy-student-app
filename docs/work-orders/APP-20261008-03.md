# 시험 준비 요청과 기기 자료 재사용

사용자 승인: 2026-10-08 `ㄱㄱ`. [승인 수리안](../verification/20261007_앱지연과중복조회_재점검.md)의 R7.

- R1 / D1 / T1: 같은 로그인 세대·배정의 미리 받기와 클릭 준비가 진행 작업을 공유한다. 미리 받기는 시험 기기 묶임을 만들지 않는다. 클릭은 진행 중 미리 받기를 이어받고 같은 준비를 중복 시작하지 않는다. 취소는 남아 있는 다른 사용자의 작업을 끊지 않는다.
- R2 / D2 / T2: 준비된 시험과 필요한 자료 키를 우선 읽는다. 전체 저장소를 매번 훑거나 최근 500개 밖의 유효 자료를 없는 것으로 판단하지 않는다. 공용 자료48시간·미사용 준비24시간·미접수 답 삭제 금지를 유지한다.
- R3 / D3 / T3: 서버 시험 시작의 권한·기존 응시·만료/구형 문제 선택은 재사용하면서 준비 함수는 한 번만 실행한다. 구형 배정·늦은 답·다시 제출의 기존 복구를 보존한다.
- R4 / D4 / T4: 미리 받기 직후 클릭·빠른 재클릭·취소·재진입을 확인하고 시험 중 추가 요청0, 기존 답 보존, 채점·재접수의 동등성을 확인한다. 운영 학생 시험쓰기는 하지 않는다.

범위: 기존 준비 제어기·서버 시작 경계·기기 저장소와 가까운 검사를 수정한다. 사전·음원 파일·기존 학생 기록·시험 시간 규칙·캐시 기간을 변경하지 않는다. 상태·우선순위는 루트 대장을 따른다.
