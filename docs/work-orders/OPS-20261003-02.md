# 무료 운영 인원·사용량 계측 실행 명세

승인된 M09의 실행 기록이다. [원 지시](20261001_공용사전과학생기록_유지보수/09_무료운영인원과_부하검증.md)와 [M08-A 결과](../verification/OPS-20261003-01_검증결과.md)를 따른다. 현재 상태와 우선순위는 루트 대장만 관리한다.

| 요구 | 실행 방법 | 검사 |
|---|---|---|
| R1 실제 한도·사용량 | 같은 계정의 Supabase Free/Vercel Hobby·시점·실제 사용량과 공식 근거 구분 | T1 |
| R2 최종 기록 비용 | 공용50문항, 학생 A/B, 두 책, 최초50+재시험10답의 실제 함수 처리 후 모든 표 계측 | T2/T3 |
| R3 응시 반복·월 사용량 | 6회 최소 표본, 필요한 경우16/32회로 물리 페이지 증가 보완; 반복 재접수 증가0 | T2/T4 |
| R4 동시 처리·권한 | 현재 무료 예산/DB 제한을 먼저 판정. 미검사 조합을 성능 통과로 표시하지 않음 | T5/T6/T8 |
| R5 인원 결론 | 고정/개인/누적/임시/예비 비용과 실측·가정·미검증 분리 | T7 |

## 결정

- D1 사용자: 무료 유지, 비상업적 이용. 요금제 변경이나 유료 부하 도구를 사용하지 않는다.
- D2 사용자: 공용자료48시간, 미사용 준비24시간. 서버 접수 미확인 기기 답은 자동 삭제하지 않는다. 풀이 중 호출0이며 종료 때 제출한다.
- D3 사용자: 각 관리자 학생 완전 분리, 개인 초안·선택 단어장 공유. F02 미구현 상태를 다중 관리자 보장으로 표시하지 않는다.
- D4 내부: 실제 운영779.91MB와 검토 DB 약819MB는 무료 DB500MB 목표를 넘는다. 원 지시의 quota 중단 규칙에 따라100명×6개월 기록을 검토 DB에 대량 입력하지 않는다. 현 한도와 복구 공간이 확보되기 전 클라우드 부하 증가를 보류한다. 로컬 측정과 실제 월 사용량 읽기는 계속한다.
- D5 내부: 로컬 PGlite 최종 스키마만 사용한다. Windows initdb 실행·보호 트리거 해제·시험 시각 조작을 하지 않는다. 실제 경과시간 뒤 정상 RPC로 최초/재시험을 제출하고 매 RPC를 확정한 뒤 측정한다.
- D6 내부: 로컬 처리시간은 클라우드 HTTP 성능이 아니다. 원 지시의500ms/1초·2초 초과 비율과 동시10/30명+관리자1/3명 합격 여부는 실제 HTTP 검사 없이는 미검증으로 남긴다. 종료 접수 목표는 정상 p95≤2초/p99≤5초, 공식결과는 최종 제출 시작 이후 p95≤3초/p99≤6초로 기록하되 지금 달성했다고 주장하지 않는다.

## 최소 표본

A/책1, A/책1 반복, B/책1, A/책1의 다른10오답, A/책2, B/책2. 매번 새 배정으로50문항 중10오답, 재시험10문항 중2오답, 최종96점 통과. 같은 제출 키/본문을 재전송해 행과 내용 증가0을 확인한다. 최초/재시험 두 결과·문항별 접수·포인트·누적 단어 상태·회차 응답 중복 표현까지 포함한다.

모든 public/private/word_index/auth/cron 표에 행 수·행 JSON/행 표현 크기·기본표·TOAST 포함 표·인덱스·관계 전체를 함께 잰다. TOAST는 한 번만 합산한다. 준비→시작→최초 제출→재시험→완료와 공용 자료 생성/학생 생성 단계를 구분한다. 과거39~58MB 모형의 단가를 재사용하지 않는다.

제품 변경·운영 DB 쓰기·실제 학생 시험 생성은 없다. 계측 도구/익명 결과/가정별 수량표·기록 증가/미검증 범위 보고를 산출물로 남긴다.

## 실행 근거와 보완 경계

[32회 계측·사용량 중간 결과](../verification/OPS-20261003-02_무료운영_중간결과.md), [재현 입력·인원 가정](../verification/OPS-20261003-02_계측/재현명세와_인원가정.json)을 남겼다. 마지막16회는 시험당299행·행 표현115,124B·조사 표257,024B 증가다.100명×6개월 표본 외삽3.08GB이며 새 공용 자료/상태/로그인/대기열/임시공간은 별도다. 전체 운영 예측이나 최대 인원으로 확정하지 않는다.

- D7 내부 보완: 공용 본문 공유는 동작하지만 신규 종료 기록의 반복 저장이 남았다. 승인된 M02/M04/M05 요구와 학생 기록 보존을 바꾸지 않고, 작은 참조로 저장한 뒤 기존 응답을 복원하는 제품 보완을 별도 APP 기록으로 분리한다. 기존 결과·점수·거래·미접수 답을 삭제/합산하거나 보관 기한을 새로 정하지 않는다. 완료 후 같은 표본을 별도로 재측정한다.
- T1/T4 일부, T5/T6/T8 부하 검사는 미검증이다. 검토 DB가 무료 목표를 넘으므로 원격 대량 부하는 늘리지 않는다. Supabase 월 전송 로그인과 조직 평균 제한 상태도 미확인이다. M09 전체 완료나 다중 관리자 지원 인원을 확정하지 않는다.
