# APP-20260907-04 첫 시험 완료 후 공개

기준 4e7eb55 / Next16.2.12·SupabaseJS2.110.8. 사용자 미결정0건. 앞선 APP14의 12시간 조건만 최신 결정으로 대체하며 이전 증거는 보존한다.

- R1/D1: 정상 다음 회차는 앞 첫시험 완료와 다음 자체 예약시각 중 늦은 시각에 공개한다. 앞 마감+12시간만 제거. 재시험·합격은 조건이 아니고, 수동 보류 예외/취소/자체마감은 유지한다.
- R2/D2: 이미 생성된 미응시 회차도 공용 공개 함수로 즉시 새 판정한다. 시험/배정 날짜나 응시 스냅샷을 덮어쓰지 않는다.
- R2/D2 추가: 오직 옛12시간 때문에 충돌한 미생성 대기열만 복구한다. 최초 후보 학생·묶음 ID를 고정한 뒤 학생→묶음→회차 잠금 후 재확인한다. 첫 미해결 항목·실제 앞첫완료 응시 연결·자체마감 전·다른 live/attention 없음·취소/보류 없음 조건을 지킨다. 날짜는 보존하고 ready/active와 기존 사건 기록만 변경한다. 조건 불명은 자동 해제하지 않는다.
- R3: 관리자/학생 쉬운 안내에서12시간 설명을 제거한다. 목록 구조와 구성은 그대로, 단어장 제목 배지는 별도 APP0705다.
- D3: 기존 양쪽 적용 승인 범위에서 로컬 검사→Preview의 정확한 한 migration 적용·보호 검증→동일 변경 운영 순서를 따른다. 실학생으로 시험을 진행하지 않는다.

## 설계·검사

공용 SQL 공개 함수와 후속 준비 함수 두 개를 새 migration으로 교체한다. 기존 함수 search_path/권한·잠금·멱등성과 서비스 전용 조회 경계를 보존한다. UI에서 별도 공개 규칙을 계산하거나 인증을 우회하지 않는다. 개인 자료 공유 캐시/읽기 중 숨은 쓰기는 추가하지 않는다.

Supabase 공식 함수/권한 문서와 현재 설치 CLI 도움말·변경 공지를 확인했다. https://supabase.com/docs/guides/database/functions / https://supabase.com/changelog . 새 서비스/요금/의존성은 없다.

T1 최종 실제 스키마에서 자체 예약 직전/정각·늦은 첫완료·첫시험 미완료·재시험대기·보류/취소·직접 시작/단어보기 차단. T2 migration 전후 기존배정/진행시험 보호 지문과 정확한 옛 충돌만 복구·반복실행0. T3 공용 학생/관리자 안내. T4 전체/타입/lint/지도/빌드 및 독립 검토. T5 Preview에 한 migration만 적용 후 함수/권한/진행응시 보호값 확인.

초기 조회/갱신/오류·빈결과/로그인/404는 기존 경계를 유지한다. waiting_initial은 첫시험 안내, waiting_time은 실제 예약 시각, schedule_conflict는 선생님 일정 확인, held/cancelled는 보류/취소 안내다. 내부 SQL 원문은 노출하지 않는다. 저장실패는 입력 보존, 인증실패는 학생 자료 숨김을 유지한다.

복구: 기능의 이전 SQL 정의를 별도 되돌림 migration으로 적용하고, 좁은 복구 사건에 기록된 item만 원래 상태로 검토 복원한다. 이미 공개되어 학생이 시작한 시험을 잠그거나 답안을 되돌리지 않는다. 운영 전/후 상태와 미검증 범위는 검증 문서에 따로 기록한다.
