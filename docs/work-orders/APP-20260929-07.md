# 시험 공개 조건과 학생 알림

R1/D1: F07 수리는 새 SQL 한 건과 로컬 최종 스키마 검증까지다. 운영 적용·기존 수령 기록 삭제/재발급·학생 자료 수정은 제외한다.

D2: 학생 claim의 신규/8시간 마감 두 후보에서 기존 공개 판정의 open/unrestricted만 허용한다. 첫 회차/독립 시험도 자체 시작일 확인을 유지한다. 후속 시험은 앞 시험 최초 완료 뒤 열리며 최종 합격까지 기다리는 규칙을 만들지 않는다.

D3: 기존 취소/누락/삭제/활성/기존 응시 제외 조건과 마감 버전, 수령 복합키/on conflict를 보존한다. 관리자 claim·공개 함수·테이블·학생자료는 변경하지 않는다. security invoker, 빈 search_path, service_role 전용을 유지한다. 복구는 이전 함수 정의만 복원하며 수령 기록을 삭제하지 않는다.

T1은 실제 전체 migration의 가짜 DB에서 잠김/공개·예약일·보류/취소·기존 제외·마감 버전·반복·권한/불변성을 검사한다. T2는 기존 알림/공개 계약과 독립 검토·타입/구조/완료 관문이다. 개발 환경의 service_role BYPASSRLS 모사는 롤백되는 가짜 DB 안에서만 한다.
