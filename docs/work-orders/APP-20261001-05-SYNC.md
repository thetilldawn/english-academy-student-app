# 자율연습 종료 확인의 검토 환경 누락 보완

기존 APP-20261001-05(M11)의 작은 적용 누락 수리다. 새 기능·보관기간·우선순위 변경이 아니다. M10 준비 중 검토 DB에는 M11만 빠진 채 이후 M02의 공용 본문 복원과 M03의 문항 종류가 적용된 사실을 확인했다. 이전 M11 SQL 전체를 나중에 실행하면 후속 보완을 덮으므로 새 동기화 SQL로 누락된 종료 판정만 맞춘다. 현재 상태는 루트 작업 대장만 따른다.

## 요구·결정·검사

- R1: 시계가 0이어도 저장 전에는 완료로 꾸미거나 미응답 정답을 공개하지 않는다. 기존 종료 명령이 저장한 상태만 완료로 반환한다. T1/T2.
- R2: M02 공용 본문 복원, M03 문항 종류, 모든 학생 행과 함수 식별자·소유자·권한·설정을 보존한다. T1/T2/T3.
- R3: M11이 빠진 검토 본문만 고치고 이미 완성된 본문에서는 아무것도 바꾸지 않는다. 예상 밖 본문이면 전체 적용을 중단한다. T1/T3.
- D1 사용자: 유지보수 완료·계속 진행 승인과 기존 M11 종료 확인 요구를 따른다. 새 정책 결정은 없다.
- D2 내부: 알려진 미적용/완성 본문의 SHA-256을 대조하고 필요한 세 지점만 치환한다. 적용 뒤 전체 본문 확인값과 함수 메타데이터를 다시 확인한다. M11의 원래 이력을 가짜로 추가하지 않는다.
- D3 내부: 로컬 최종 순서는 원래 M11→M02→M03→동기화이며 동기화는 무변경이어야 한다. 검토는 원래 M11 전체를 재실행하지 않고 이 동기화 한 건만 적용한다. 운영은 M10에서 전체 순서로 별도 다룬다.
- D4 내부: 기존 M11 완료 화면/문구·원기기 답·48시간 캐시·미사용 준비24시간·음원 정책을 바꾸지 않는다. UI 파일을 변경하지 않는 환경 동기화이며 새 화면 검사를 주장하지 않는다. 미확정 상태는 기존 종료 재시도로만 확정한다.

T1 로컬 최종 스키마에서 알려진 누락 본문 재현→보완, 기존 완성본 무변경, 예상 밖 본문 거절, 함수 메타/표 데이터 보존을 검사한다.

T2 기존 자율연습 통합 검사의 마감 조회·저장 후 종료·미응답 정답 비공개·타인 권한과 공용 본문/문항 종류 회귀를 실행한다. 타입/lint/구조·기록 관문을 함께 확인한다.

T3 독립 검토 뒤 같은 SQL을 검토 DB에 적용한다. 같은 거래의 학생 표 개수·전체 행 확인값, 대상 함수 메타데이터와 변경 외 함수 정의를 전후 대조한다. 읽기 전용 가짜 composite 입력으로 종료·미확정 응답을 확인하며 실제 학생 시험·답안 쓰기를 하지 않는다.

## 변경 영향과 복구

변경: DB 내부 함수 동기화, DB 계약 검사, 소유권 지도와 근거 문서. 확인만: 기존 API 응답·완료/시간 정책·권한. 해당 없음: 경로·UI·스타일·브라우저 상태·캐시 구현·사용 사례 신규 설계. 이미 검증한 로컬 최종 동작과 검토 환경을 일치시키는 보완이다.

복구는 적용 전 정의를 보관하고 정확한 대상 함수만 되돌리는 방식이며 학생 표는 갱신하지 않는다. 다만 이전 잘못된 종료 표시가 재발하므로 실제 복구는 별도 원인 판단 후 시행한다. 운영 배포와 원문 이전·정리, 추가 발음 업무는 이 수리에 섞지 않는다.
