## 설계와 영향

- 소유자: architecture-meta, 문구 카탈로그 안내는 기존 shared-contract 소유를 따른다. 실제 앱 업무 흐름은 바꾸지 않는다.
  새 검사 모듈과 테스트만 보호선 지도에 등록한다.
- 입력: 앱 내부 JSON·기능 지도·로컬/CI Git 변경. 출력: 오류 목록 또는 통과 요약/지문 JSON과 종료 코드.
- 사용자 API·요청 응답·생성·배정·응시·조회/검색·수정·삭제·학습 기록 흐름: 모두 변경 없음.
  개발 기록 읽기만 추가하며 학생/문제 데이터 접근을 하지 않는다.
- 재사용: 기존 change-impact의 소유자/흐름 계산을 조용한 반환 함수로 분리, 기존 출력 함수는 보존.
  strict 형식은 기존 zod 재사용. 새 의존성 없음.
- 책임: 명령 진입점 / schema 형식 / context 지도 연결 / validation 관문 / evidence 지문으로 분리.
- 캐시·로딩·스트리밍·페이지·모달·스타일: 실행 코드 변경 없음. 기준 문서만 연결하므로 화면 상태는 해당 없음.
- 보안: 앱 밖 경로, 비밀 환경 파일, 경로 탈출 링크를 입력으로 읽지 않음. 인증 경계 파일도 변경 추적과 지문 대상.
- 호환: 기존 지도 명령 출력·빌드 순서 유지. 새 시작점 이전 작업의 소급 기록을 요구하지 않는다.
- 내부 도구 보완(D3/D4): Git 제외 임시 시안 .codex-tmp는 lint/타입에서도 제외하되 파일은 보존한다.
  CI의 기존 구조 검사 대상에 공개 자산·추가 루트 실행 설정을 포함한다. 텍스트 지문은 CRLF/LF를
  정규화하여 Windows/CI 간 같은 코드의 오탐을 막고, 이진 파일은 그대로 비교한다.
- 복구: 개발 도구/스크립트 연결만 별도 변경으로 복구 가능. 검사 실패를 피하려 시작점·권한·업무 코드를 바꾸지 않는다.
