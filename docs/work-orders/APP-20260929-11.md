# APP-20260929-11 — 선택한 내 단어장과 단어 표시

2026-09-30. 입력은 APP10 공통 조회와 사용자 확정 1안이다. 사용자는 실제 음원 연결 및 검토 후 운영 반영까지 승인했다. 이 문서는 화면/조회 구현 단계이며 자율연습 쓰기는 APP12, 교사 배정은 APP13에서 이어간다.

## 요구와 결정

- R1/D1: 학생 본인 누적 오답, 전체 후보의 횟수 내림차순 기본/최근순 선택, 횟수·책·검색·10개 더보기. 기존 관리자 집계와 원문·기록 보존. 새 읽기 함수로 이전 배포 호환을 유지한다.
- R2/D2: 1안 목록, 행은 상세/체크는 선택, 전체 선택 해제. 모바일 실제 가로채기 경로와 직접 접근 상세, 넓은 화면 오른쪽 상세. 닫기에 refresh 금지; 선택/필터/스크롤 보존. 설명·그라데이션 추가 금지.
  - 경계 검사 보완: 공용 기본 스타일의 기존 html 규칙에서 스크롤바 자리를 유지한다. 모달 잠금 때문에 가용 폭이 바뀌어 오른쪽 상세와 모달이 반복 전환되지 않게 한다. 기능 CSS에서 루트를 변경하는 방식은 구조 검사에서 거절되어 폐기했다. 공통 모달 잠금/복원은 그대로이며, 일반 스크롤바 환경의 짧은 화면에도 해당 폭을 예약하므로 학생 목록·단어보기·시험·로그인을 함께 확인한다.
- R3/D3: 본인 오답 확인 후 해당 출처의 기존 한글발음/음원/학습 예시만 연결한다. 임의 발음 생성 없음. 음원 없는 항목은 비활성·짧은 상태로 구별, 실패하면 재시도 가능. 영어 가리면 발음도 블러·음성 중지, 접근성 이름도 숨긴다.
- R4/D4: 표제어·한글발음은 실제 가용 폭과 폰트 준비/크기 변화에서 측정해 축소한다. 긴 문장/뜻은 자연스럽게 줄바꿈. 극단적으로 긴 단어/확대에서는 최소 글꼴 보장과 원문 접근을 유지한다. 시험 네 단어 보기는 같은 크기로 조절한다. 타이머·답 선택100ms·정답/점수 계산은 변경하지 않는다.
  - 확대된 사각형 폭과 CSS 폭을 같은 좌표계로 환산한다. 480px 이하 기존 단어보기는 뜻을 아래에 배치해 영어 영역을 확보하며, 영어 자체를 잘라내거나 줄바꿈하지 않는다.
- R5/D5: 서버 최초 조회, 후속 취소 가능한 전송, private/no-store, 본인 권한. 성공0건/실패/미선택/없는 상세를 구별한다. 늦은 응답·로그아웃·직접 접근·모달 왕복 검증.

## 구조와 영향

students가 공통 오답/학습자료 조회·서버 권한을 소유하고 student-dashboard가 학생 화면을 조합한다. 얇은 page/route, 공개 계약·서버 경계를 사용한다. 단어 크기/가리기는 업무를 모르는 공용 표시 부품, 재생 수명은 기존 ManagedAudioPlayer를 재사용한다. 개인 자료 공유 캐시와 정답/문항 순서 전달은 금지한다. 데이터 쓰기·응시·배정은 해당 없음(다음 단계). 생성/삭제·기존학생·사전 원값 변경 없음.

상태: 초기 ‘단어를 불러오는 중입니다’ → 정상목록; 현재조건0건 ‘조건에 맞는 단어가 없습니다’; 선택0개는 연습 비활성; 입력오류 ‘조회 조건을 확인해 주세요’; 조회실패 ‘단어를 불러오지 못했습니다. 다시 시도해 주세요’와 다시 시도; 인증거절은 개인목록 숨김·처음 이동; 없는단어는 ‘단어를 찾을 수 없습니다’와 내단어장 이동. 갱신 실패/늦은 응답을 정상0건으로 바꾸지 않는다. 음원 실패는 ‘소리를 재생하지 못했습니다. 다시 눌러 주세요’로 해당 항목에만 표시한다.

## 검사

- T1 단위/계약: 전체 정렬·동률·커서 학생/조건 결속, 기존 원문/발음 우선순위·가리기·최소 글꼴 계산.
- T2 DB/query/HTTP: 관리자/본인 분리, 0/1/10/11/21행, 전체 count순·최근순·정렬 커서, 다른학생·비공개 자료 미노출, 읽기 전후 불변.
- T3 컴포넌트: 가리기/소리/필터/선택·전체해제/실패·취소·늦은응답. 숨김시 접근성 이름/음성 조작 미노출, 실패와0개 구별.
- T4 실제 화면·경로: 320/390/810/1440, 확대, 긴 단어/구동사/폰트 준비, 보기공통크기, 숨김·소리·선택/검색 보존. 상세 클릭/닫기/뒤로/앞으로/직접 URL/새로고침, 인증/오류/404, 요청수·목록 재조회 없음.
  - 확대 확인은 격리 검사 프록시의 CSS `zoom:2`에서 실제 렌더/가용 폭을 재측정한다. 현재 브라우저 도구는 자체 확대 배율을 지정하지 못하므로 이 확인을 브라우저 자체 200% 확대나 실기기 검사 완료라고 표현하지 않는다. 좁은320px 및 최소 글꼴 단위검사를 별도로 유지한다.
- T5 타입/lint/전체검사/소유권지도/빌드/독립검토. 실제 실행 이후 결과를 기록한다.
