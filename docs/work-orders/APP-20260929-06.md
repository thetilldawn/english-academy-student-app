# 포인트 조회 실패와 실제 0점 구분

R1은 F06 응답 누락을 0점으로 만드는 문제의 보완이다. D1은 승인된 로컬 순차 수리이며 원장·배정·실학생 기록·운영 쓰기는 제외한다.

D2: 합계 RPC는 요청 학생별 정확히 1행, 시험 요약은 항상 1행이다. 누락/중복/다른 학생 행, 배열이 아닌 응답을 거절한다. 안전 정수 숫자 또는 십진 정수 문자열만 허용하며 null·빈 문자열·불리언·배열·소수·지수 문자열을 0으로 바꾸지 않는다. 합계와 기록 수/보상은 음수일 수 없고 오답 반영은 양수일 수 없다. 보상+오답=합산을 대조한다.

D3: event_count=0일 때도 모든 값을 검증하고 세 합산 값이 0이어야 과거 사건 없음(null)으로 반환한다. 기록은 있지만 합산0인 경우는 실제 0점이다. 학생 시험 포인트 하한0/관리자 부호, 기존 확인 불가 UI·권한·React 요청별 cache는 유지한다. 디렉터리의 별도 LEFT JOIN 계약은 건드리지 않는다.

T1은 잘못된 응답과 실제0/음수순변화 회귀, T2는 표시 및 기존 최종 SQL 계약 검사, T3는 독립검토·타입/구조/완료 관문이다.
