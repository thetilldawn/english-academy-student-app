# 검토된 사전·발음 연결 복구

사용자 승인(2026-09-14 `ㄱ`)은 기존 등록 교재의 누락 연결 보완이다. 학교 원문과 문항을 그대로 참조하는 별도 연결판을 만들고 기존 발음 조회가 이를 사용한다. 실제 교재 자료와 검토표는 영어 자료 구역에 둔다.

- R1: 같은 원고·행 확인값에만 사전 출현과 기존 발음을 연결한다. 표제어·품사·발음 변이·음원·표시값까지 기존 검증 함수를 통과해야 한다.
- R2: 학교 뜻·정의·문항·식별자와 기존 학생 기록을 보존한다. 보충 정의·예문은 별도 출처 필드로 보관하며 현재 뜻 시험의 유형·화면 규칙을 바꾸지 않는다.
- R3: 전체 범위를 검토한다. 연결 가능한 기존 값을 누락하면 거절하고, 실제 미확보 자료는 이유와 근거를 기록한다. 사전 뜻 ID가 없는 기존 자료에 ID를 만들어 넣지 않는다.
- R4: 승인 확인값·대상 환경·등록판을 고정한다. 승인/등록 권한은 운영자만, 조회는 기존 서비스 권한만 허용한다. 이미 적용한 같은 연결판의 재실행은 중복을 만들지 않는다.

D1: 원본 등록판은 불변이다. 별도 private 연결판과 항목별 payload에 참조를 보존하고 검토된 발음 조회에만 경로를 추가한다.
D2: 기존 발음 유효성 검증을 재사용한다. 원문 품사가 빈 경우에도 기존 검토판의 분류 근거를 함께 확인하며, 품사 불일치는 자동 허용하지 않는다.
D3: 학습 조회의 사전 ID는 새 연결의 실제 원출현에서 가져온다. 보충 자료는 서비스용 별도 조회로 접근할 수 있으며 뜻 시험에서 정의/예문을 새로 출제하거나 표시하지 않는다.
D4: 연결판 단위 비활성화로 되돌린다. 단어·문항·배정·응시·음원 삭제나 덮어쓰기는 없다.

T1: 가짜 원고를 사용해 승인/원문/태그·품사/발음·출처 변조, 빠진 연결, 중복·재실행·권한과 실제 조회를 검사한다.
T2: 기존 학교 원고와 검토 문제은행의 배정·학습·발음 회귀를 검사한다.
T3: 소유권과 R/D/T 정합성, migration 전체 적용, 원문·문항·학생 보존 및 운영 조회를 확인한다. 실제 자료 적용은 DEPLOY-20260914-05에 기록한다.

새 연결33·학교60·기존 검토55, 총148개 로컬 통합검사와 TypeScript 검사가 통과했다. 독립 코드 검토는 최종 SQL 확인값 기준 미해결 결함0이다. 운영/검토용의 실제 연결과 보호 검사는 DEPLOY-20260914-05에서 별도 수행했으며 인증 후 화면과 청음은 미수행으로 구분한다.
