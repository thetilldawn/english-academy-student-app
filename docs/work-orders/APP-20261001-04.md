# 관리자·학생 고정 화면

R1: 메뉴/제목/검색/필터는 유지하고 인증·자료 대기는 자료영역에만 표시한다.
D1: 2026-10-01 사용자 승인. D2: 표시 전용 공용 틀, 현재 인증·개인캐시 정책 유지.
T1: 실제 컴포넌트와 권한/입력 보존. T2: 구조·회귀·타입·빌드. T3: 독립검토. T4: 가짜 브라우저 PC/모바일.

정해진 절차: 설계 관문 → shell → 학생/배정/내역 경계 → 관련 회귀 → 실제 화면 → 완료 근거. 상세 R/D/T는 같은 번호 JSON이 기준이다.
개인자료를 숨김 CSS로만 가리지 않고 DOM에서 제거한다. 같은 계정 확인 중의 입력/초안은 내부 상태로 보존하되 계정 차단은 controller도 제거한다.
동적 목록의 최초 높이는 알 수 없으므로 빈자료를 실제0건처럼 쓰지 않는다. 재확인에는 직전 자료영역 높이를 보존한다.
DB/API·학생원본·캐시수명·정상모달닫기 갱신 정책은 바꾸지 않는다.
