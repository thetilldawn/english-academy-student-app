# 화면 이동과 내역 오류 보완

R1/T1~T3: 완료 내역의 진짜 인증 거절과 조회 장애를 구별한다. 결과 DB 장애는 없는 결과로 처리하지 않는다.
R2/T4~T6: 관리자 빈 detail 경로를 추가하고 가짜 브라우저와 구조 검사·독립 검토로 복귀를 확인한다.

D1은 현재 사용자 수리 요청, D2는 확인된 재현과 Next 공식 문서에 따른 최소 보수다. 새로운 정책 결정은 없다.

D3/T7: 오류 재시도는 설치 Next 16.2.12가 제공하는 서버 재조회와 경계 초기화를 함께 실행한다. 정상 닫기는 그대로다. D4/T1: 다른 학생의 이전 커서를 일반 조회 실패와 구별하여 옛 개인정보를 폐기하고 현재 학생 화면으로 이동한다. 다른 탭의 즉시 감시는 새로 도입하지 않는다.

입력은 F02/F03 재현과 관리자 슬롯 누락이다. Route/Server Component에는 계산·저장을 추가하지 않는다. 완료 목록은 controller·transport·오류 계약으로, 결과는 기존 소유 query와 결과 전용 표시 부품으로 고친다. DB 오류 상세를 학생에게 보여주지 않는다. 초기/불러오는 중/빈 결과/실패/인증/404/재시도 문구와 연결 검사는 같은 번호 JSON에 기록한다.

검사는 전체 인증 선행 수리를 보존하고 실제 소유권 확인을 유지한다. 닫기 router.back 및 목록 캐시는 그대로 두며 재조회 버튼·주기 조회를 추가하지 않는다. 운영·실학생 자료 쓰기와 배포는 하지 않는다.
