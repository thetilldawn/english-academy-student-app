## 결정

- D1 사용자: 단일 학년 차이 허용, 일괄은 포함/제외 확인. 학생 수가 아니라 진입 모드 기준.
- D2 사용자 요청을 연결: 포함하면 선택 단어장 기준. 학생 학년으로 다른 자료를 자동 배정하지 않는다.
- D3 사용자: 학생 시험을 막지 않으면 지금 수정. 이전 배포의 관리자 확인은 대기, 로컬 수정 선행.
- D4 내부: gradeLabel은 자유 문자열이므로 중1~고3·m1/h1·g7~g12 같은 확실한 표기만 비교. 빈 값/알 수 없는 값은 확인 불가이며 불일치로 자동 제외하지 않는다.
- D5 내부: 이미 쓰는 배정 모드를 요청에 전달한다. 새 UI는 항상 명시, 옛 요청은 1명=단일/그 외=일괄로 해석한다. 확인 결과는 서버 재계산 SHA와 미리보기 서명으로 결속한다. 권한 토큰으로 쓰지 않는다.
- D6 내부: 추가 DB 구조 없이 기존 students.grade_label과 단어장 gradeCode만 읽는다. 예문 후보 우선선택은 별도 APP-20260910-04에서 검증한다.

## 흐름·연결

관리자 배정 창 → 선택 학생·단어장 → 동일한 학년 정규화 → 서버 미리보기의 확인 목록/서명 → 필요시 포함 또는 제외 → 최신 미리보기·확인 결과와 함께 저장 → 서버 재조회·서명 검증 → 기존 저장 경로.

- 단일 모드는 확인하지 않는다. 일괄 선택이 1명이어도 모드를 바꾸지 않는다.
- 제외는 이번 창의 대상만 변경하며 부모 학생 목록이나 계정은 바꾸지 않는다. 학생 목록/초안/미리보기/집계에 같은 ID를 사용한다.
- 확인 창은 기존 Dialog 구성으로 만들고 배정 입력 창은 유지한다. 확인 후 자동으로 예전 요청을 재전송하지 않는다.
- 새 배정만 변경한다. 응시·조회·검색·기존 시험 수정·삭제는 기존 흐름을 확인만 하고 변경하지 않는다.
- 기존 서버 관리자 권한 확인, 삭제 학생 제외, 개인 응답 private/no-store를 유지한다. 정답 문구·비밀정보를 확인 응답에 추가하지 않는다.
- 캐시: 창 수명만 사용. 학생/단어장/모드/학년 확인 결과 변경 시 미리보기·확인 무효화. 사용자 전환/닫기에서 폐기, 공유 캐시 없음.
- 호환: 새 응답 필드는 새 모드 입력을 보낸 화면에서만 전달하여 옛 화면의 엄격한 응답 검증을 깨지 않는다. 옛 일괄 화면에서 학년 차이가 있으면 새로고침 후 확인하도록 저장을 거절한다.
- 오류 복구: 409는 기존 재미리보기 경로, 저장 결과 불명확은 기존 멱등 조회를 보존. 이미 성공한 동일 요청을 다른 학년 정보로 재실행하지 않는다.
