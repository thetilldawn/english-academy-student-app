# 승인된 학교 발음 자료 연결

자료 지시서 WORD-20260906-01의 앱 연결 부분이다. 우선순위는 루트 대장만 따른다.

## 요구·결정

- R1 / D1: 기존 공식 음원 우선, 실제 없는 것만 기존 Google 정상 속도 단어·숙어 프로필로 생성한다. 발음 표시와 강세를 같은 음원에 연결한다.
- R2: 문항·영어 선택지·단어장의 현재 서버 조회와 공용 발음 표시/스피커를 재사용한다.
- R3 / D2: 승인된 6묶음의 정확한 원자료 해시·행수만 허용한다. 기존 VOCA·학생 시험·음원은 덮어쓰지 않는다.
- D3: 개인자료 캐시는 새로 만들지 않는다. MP3만 요청 해시 주소로 저장한다. 자동 공개 기능은 별도 APP-20260906-14다.

## 책임과 검사

저장 경로 판정은 공유 순수 계산, 원자료 범위·해시는 가져오기 계약, 등록/검증/활성화는 기존 DB 절차다. 학생 UI에 단어장별 분기나 새로운 조회를 복제하지 않는다.

- T1: 승인 저장 경로/프로필/해시와 옛 경로 회귀.
- T2: 범위·행수·품사·음원/발음·해시 변조와 누락 차단.
- T3: 로컬 SQL에서 등록권한·불완전 활성화·다른 자료·멱등성 확인.
- T4: 기존 스냅샷 우선과 정확 같은 음원의 누락 표시만 보강. 기존 쉬운 안내/오류와 없음 구분 유지.
- T5: 전체 검사·타입·lint·구조·빌드·현재 코드 근거.
- T6: 자료구역의 음원 및 학생 보호 전후 근거. 변환 성공을 청취/배포 검증으로 대신하지 않는다.

검사 기록은 [작업 기록](../../architecture/work-records/records/WORD-20260906-01.json)과 [최종 검증](../verification/WORD-20260906-01.md)에 연결한다. 승인된 6개 묶음과 앱 코드의 Preview/Production 반영을 확인했다. 전 음원 실청취·음향 강세 측정과 공통 사전 승격은 완료 범위가 아니다.
