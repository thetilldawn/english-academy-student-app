## 설계와 검사

기존 서버 후보 계산의 전체 집계만 응답에 추가한다. 새 DB 조회·캐시 서비스는 없다. 서버 인증과 개인 응답의 private,no-store를 유지한다. 브라우저 집계에는 이름·답·세부 일정·저장 승인값을 보관하지 않는다. 날짜/시간 이외 조건이 바뀌거나 조회/인증 실패·새로고침·저장 성공이면 폐기한다. 알려지지 않은 수량을0으로 대체하지 않는다.

회차별 기본 수는 기존 날짜 없는 범위 계산에서 얻는다. 실제 날짜 검증은 유지한다. 서로 다른 학생의 수량/회차는 첫 학생을 대표로 확정하지 않는다.

T1 순수 집계/키/알 수 없음 검사, T2 공용 입력·안내 검사, T3 실제 제어기 요청·응답·폐기·저장 보호 검사, T4 구조·독립 검토, T5 로컬 가짜 자료 화면, T6 전체/타입/lint/빌드. 실패·미실행은 완료로 계산하지 않는다.
