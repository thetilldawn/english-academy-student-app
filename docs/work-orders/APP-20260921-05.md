# 수능 검수 원고 등록 지원

기준 e48db66. 승인된 수능 전체 유형 등록의 필수 공백을 채운다. 별도 학생 화면·일반 관리자 등록 기능을 추가하지 않고 기존 service_role 검수형 등록 계약을 확장한다. 실제 자료는 저장소 밖 WORD 검수 결과로 별도 승인한다.

## 요구와 결정

- R1/D1: 원문 확인된 2024~2026학년도 수능을 csat로 등록할 수 있어야 한다. 시행연도 2023~2025·11월·학년도+1·25범위(18~40,41~42,43~45)를 결속한다. 다른 종류/연도/학년도/월, 중복·누락 범위는 거절한다. 월별 모의고사의 기존 부분 범위 규칙은 유지한다.
- R2/D2: 기존 검수 승인표·확인값·독립검토2회·필드 수량·원뜻 보존과 재실행 멱등성은 그대로 쓴다. 기존 함수/스키마 이름은 호환을 위해 유지한다. 데이터 키만 g12-csat-시행연도-vN을 추가하고 일반 가져오기의 앞뒤 공백 포함 우회를 막는다.
- R3/D3: 새 수능 카탈로그는 csat 분류와 학년도로 표시한다. 단원 metadata에는 별도 시행연도를 보존한다. 기존 장문104개·생성 단어장·학생 기록은 변경하지 않으며 새 자료키만 허용한다. 기존 라이브러리 등록기는 이미 csat를 지원하므로 검수/등록 후 그 경로로 별도 등록한다.
- D4(내부): 새 migration에서 기존 검수형 private 가져오기와 일반 우회 방어 함수만 교체한다. 기존 승인표·자료·출현·범위 테이블이나 과거 SQL은 수정하지 않는다. 새 자료 활성화/권한 확장을 넣지 않는다.

## 설계와 경계

검수원고→타입/해시/독립검토 검사→service_role·실제 프로젝트·승인 원고 확인→원출현/필드 보존 저장→수능 카탈로그/기존 범위 등록이다. 실패는 전체 거래를 취소하며 원고 수정 후 재검토가 필요하다. 새 자료키·같은 원고의 재등록은 완료 결과를 반환하고 다른 내용의 기존 자료 덮어쓰기는 거절한다.

유형별 조합·학생 배정·응시·검색/정렬·템플릿 삭제는 기존 경로를 유지한다. 관리자/학생 화면 입력과 비동기 상태는 변경하지 않으므로 화면 검사는 해당 없음이다. import의 내부 오류는 기존 service_role 운영 경계에만 반환한다. 개인 정보 응답/새 캐시/정답 공개/학생 권한은 추가하지 않는다.

기존 일반 모의고사 원고가 재봉인 없이 검증·등록되는지 확인한다. 롤백은 앱만 이전판으로 복구하고 이미 등록된 수능·검수/승인/학생 기록은 보존한다. 수능을 모의고사로 재분류하거나 구조 삭제로 되돌리지 않는다.
