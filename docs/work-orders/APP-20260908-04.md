# 학교 검색과 단어장 찾기

사용자 승인 검토안 R10/R11/R16, 인증키 제공 후 ㄱㄱ에 따라 로컬에서 진행한다. [요구·결정·검사 연결](../../architecture/work-records/records/APP-20260908-04.json). 상태/우선순위는 루트 대장, 실행 경로는 기능 지도가 기준이다.

- 학교 검색: 학생 기능의 계약/제어기/통신/관리자 API/공식 조회를 분리한다. 기존 학교명을 표시할 때 요청하지 않고, 입력을350ms 합쳐 검색한다. 검색어만 전달하며 키·학생정보는 브라우저/외부로그에 노출하지 않는다. 입력교체·학생교체·닫기·reset은 이전 요청을 취소한다.
- 같은 출처와 관리자 인증 후 전체 남은7초 안에 응답 본문까지 제한한다. 외부주소는 NEIS schoolInfo 한 곳 고정, redirect 금지, 안전한 오류와 private no-store. 조회가 비었거나 실패해도 직접입력은 허용한다. 학교 선택이 프로필을 자동저장하거나 학년을 바꾸지 않는다.
- 등록 성공은 기존 form.reset과 학교 입력/결과를 같이 비운다. 상세 프로필의 버전/충돌/결과불명/dirty 보호를 재사용한다. 현재401/403만 기존 인증 숨김에 연결하고 이전 검색의 늦은401은 무시한다.
- 단어장은 기존 catalog metadata에서 학교 이름/명시공통 여부만 허용하여 내려준다. 미태깅 자료를 제목으로 분류하거나 공통이라 추정하지 않는다. 학교 전용과 확인된 공통을 함께 찾되 구분표시한다. 학년/학교/종류는 교집합 필터이며 필터마다 서버호출하지 않는다.
- 학교 분류는 유효한 `metadata.school`만, 공통은 학교가 미지정이고 `metadata.audience === "common"`인 경우만 인정한다. 잘못된 학교 값과 미태깅 자료는 학교 미분류로 유지한다. 이 규칙으로 실제 자료 태그를 자동 수정하지 않는다.
- 중복 부가설명은 제거하고 기존 검증된 제목·출판사만 표시한다. 확인되지 않은 저자/과/공통태그는 생성하지 않는다. 정식자료 제목·태그 자체를 수정하려면 별도 자료 작업이 필요하다.

T1 권한/정보노출/시간/안전한응답 → T2 입력수명/직접입력/reset → T3 필터/제목/메타투영 → T4 전체/구조/빌드 → T5 공식최소읽기와가짜자료실화면. 실제학생·답안·점수·DB변경·배포는 없다.

실행 결과와 미검증 범위는 [로컬 검사 기록](../verification/APP-20260908-04.md)에서 확인한다.
