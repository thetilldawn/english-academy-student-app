# 검토된 의미 충돌을 출제 보기에서 제외

기준 cc56d065a2d7f78ddff5fa51c753b224606b3be4. 기존 정답 하나 요구(D7)와 수능 전체유형 등록의 필수 오류 수정이다. 새 사용자 미결정은 없다. 실제 출현/검토표는 영어 자료 구역에만 두고 앱 검사는 가짜 데이터로 수행한다.

- R1/D1/T1: 표제어·원뜻·출제 방향에 결속한 검토 충돌만 제외한다. 학교 뜻과 단어 목록은 보존한다. 문자열 유사도로 동의어를 자동 승인하거나 동의어 그래프를 전이 확장하지 않는다.
- R2/D2/T2: 기존 context_evidence.choice_safety에 버전·근거 SHA·방향별 제외쌍을 담는다. 전체 원고/독립검토 해시와 함께 보호한다. 관리자 전용 별도 커서 조회, 기존 불변 원출현 snapshot, 구성 strict 계약, 공통 보기 생성, DB 저장 방어를 연결한다. 기존 vocab_entries 열 추가로 전체 snapshot 비교를 깨뜨리지 않는다. 검토 정보는 정책이 없는 기존 항목도 명시적으로 반환해 조회 누락과 구분한다.
- R3/D3/T3: 이전 학생 문항·정답·점수·오답과 기존 범위/자료를 수정하지 않는다. 새 고정 문항에만 적용하며 이미 저장된 문항을 사용하는 배정·오답 경로는 기존 판을 유지한다. 새 정책 검증을 저장된 옛 문항 검수 완료로 표현하지 않는다.
- R4/D2/T4: 가능 수, 실제 선택, 유사도 후보 조기중단이 같은 충돌 판정을 사용한다. 안전한 오답 3개가 없으면 기존 부족 안내를 사용한다. 전역 동일 발문/다른 정답 제외 기준은 유지한다. 원순서/역순/무작위와 비율0/50/100을 검사한다.
- T5: 타입/lint/지도/변경 연결·관련 회귀·독립 검토. UI 모양·버튼·입력·라우팅은 바뀌지 않으며, 기존 화면에 전달되는 가능 수와 부족 응답을 계약 검사한다. 외부 앱/DB 반영과 실제 원고 승인은 별도 구체 명세로 구분한다.

색인에는 후보뿐 아니라 검토판도 결속해 변조된 정책을 오래된 색인과 함께 사용하지 못하게 한다. 단어장/학생 변경 때의 현재 취소·캐시 정책은 변경하지 않는다. 정책 자료나 보기 정답을 학생의 미응시 조회에 추가하지 않는다.
