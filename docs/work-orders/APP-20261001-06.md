# 공용 사전 사용값과 출처 참조

APP-20261001-06 / 유지보수 M01. [상세 요구](20261001_공용사전과학생기록_유지보수/01_공용사전과_뜻출처연결.md)와 [최신 구현 설계](../verification/20261001_사전참조_구현전설계.md)를 정식 R/D/T 기록과 함께 따른다.

- R1 기존 문자열 사전ID·옛UUID·앱ID·원출현 연결을 역할별 보존한다.
- R2 승인된 뜻만 기존 의미키를 공유하고 미승인은 원출현/판/뜻필드 확인값으로 고정한다. 뜻ID를 새로 지어내거나 철자만으로 병합하지 않는다.
- R3 표시값 불변 표와 출처 연결 불변 표를 분리한다. 신규 사용값에 원문·사전전문·검토전문·proof.value·음원본체를 저장하지 않는다.
- R4 뜻·품사·정의·예문·발음·보기제외를 실제 생성/학습 조회에서 보존한다. 새 참조가 깨지면 기존값/최신사전/빈값으로 우회하지 않는다.
- R5 v1/v2 읽기·변경감지·중복비교를 연결하고 중간 생성 재개/동시 등록을 검사한다. 기존 preparing/ready 판과 원래 지문은 바꾸지 않는다.
- M01-T1~T8을 정식 T1~T8로 연결한다. T9는 기존 화면/실패 계약, T10은 타입/lint/구조/빌드, T11은 독립검토, T12는 실제 두 연결 중복 등록 검사다.

새 영어 사전을 만드는 작업이 아니다. 선택된 사용값의 저장 위치와 참조를 정리하는 작업이다. 원자료 정정·이전/삭제·운영 등록·학생 답안 쓰기는 각각 별도 경계로 보존한다. 개인 배정/문항의 본문 제거는 M02에서 기존 ID/FK/채점/지문을 먼저 보호한 뒤 이어간다.

새 저장 경로가 학생 학습/과거값 조회와 맞는지 검증하고 사용값 및 원출처 확인값을 전수 대조한다. 같은 보충정보가 입력과 출력 모두 null인 것만으로 보존 검사를 통과시키지 않는다. 등록된 가짜자료와 현재 원고의 형태 집계를 구분해 보고한다.
