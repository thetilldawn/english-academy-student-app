기준 264ae31 · Next.js 16.2.12 · 미결정 0건. 자료 원본 복구는 WORD-20260909-01, 운영 반영은 별도 DEPLOY 기록이다.

## 요구
- R1: 원본 표기를 source-restored로 연결하고 기존 지정과 확정 승인을 보존. 완료: 자료500행과 실제복원 대상을 대조하고 정확 원본 표기/강세만 최종표시, 기존 음원과 사전현재본 불변. 검사 T1/T2/T5.
- R2: 시험·영어선택지·단어보기·결과에서 공통 승인 표기 우선. 완료: 사전 snapshot 없는 과거 문항도 정확한 entry/source/variant/audio 증거가 있으면 같은 표기, 음원 또는 사전 ID가 다르면 적용하지 않음. 검사 T1/T3/T4/T5.
- R3: 원본 발음 누락과 잘못된 재생성 경로를 차단. 완료: 사전/PDF→전달→정확등록→과거학습/시험/선택지/결과 연결 전수검사 및 재실행/충돌/원본변경 차단. 검사 T6.
- R4: 학생 정보·정답·원음·시험 진행 보호. 완료: 권한 확인 뒤 읽기 전용 조회, 공개 실행 차단, 기존 오류/빈결과/404 구분과 개인 no-store 보존. 검사 T2/T3/T4/T5.

## 설계
- 사용자/기존 확정 승인값은 덮어쓰지 않는다. 새 생성 대신 원본을 재사용하며 원본 복원을 사용자 직접 지정으로 태깅하지 않는다.
- 기존 approved 표, 정확 entry RPC, 서버 발음 조회, 공용 pronunciation 선택기를 재사용한다. 새 화면/컴포넌트/사용자API/전역캐시/음원/채점 변경 없음.
- 기존 SQL을 덮어쓰지 않고 새 migration으로 private 함수의 허용 출처만 확장. 같은 variant라도 identity 해시/POS/원자료가 다르면 적용하지 않는다.
- 별도 dictionary-only 조회에서 source-restored도 제외해 정확 연결 우회를 막는다. 보조조회 실패는 안전한 이전 발음 유지와 서버 경고, 기본 단어장 실패는 기존 쉬운 한국어 안내/재시도.
- 자료 작성→등록 전 로컬 검사→정확 원격 읽기→최종 공용 표시까지 연결한다. 학생 새 응시/답 제출 없이 기존 테스트 기록을 사용한다.
- 기존 미응시/진행/완료 문항 snapshot·점수·답안·MP3와 사전 현재본/PDF는 쓰지 않는다. 개인 private,no-store와 원래 로딩/오류/모달은 유지.
- 회수: 이번 추가행의 정확 키·작업·해시·표시가 같은 경우만 제거, 앱 직전본으로 복귀. 원격 적용 전 정의/승인/학생 보호값 보관.
