# 배정 저장 결과 확인

R1/D1: 현재 승인된 F04 수리다. D2: 범위 배정에만 최초 완성 요청과 식별키·검증기준을 보관한다. 응답 유실·5xx·성공 본문 오류는 저장 실패 확정이 아니다. 원래 조건과 동일한 요청으로 명시적으로 다시 확인하며 새 준비/날짜 계산/학년 확인을 실행하지 않는다. 초기 확정 거절은 기존 동작, 한번 미확정 이후의 거절은 최초 미저장을 증명하지 못한다.

D3: 전송/미확정 동안 초안·별도 일정 상태·학생 제외·모드·닫기/폐기/내부 이탈을 잠근다. 기존 이탈 보호를 재사용하고 성공 때 한 번 정리한다. 새로고침/강제종료/실제인증상실 후 보존은 보장하지 않는다. 요청 개인정보를 영구 브라우저 저장소에 보관하지 않는다.

T1은 요청/식별키/원래 파서·마감 경과·모의 영수증1건, T2는 controller/실제UI와 단일/일괄1명·이탈 보호, T3는 타입/구조/관련회귀, T4는 독립검토다. 서버 멱등 저장과 권한·개인 no-store·원자료·학생 기록은 바꾸지 않는다. 운영 전송/새 배포/DB 변경 없음.
