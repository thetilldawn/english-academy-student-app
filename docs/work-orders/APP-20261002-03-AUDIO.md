# 답 선택과 시간 종료 때 음성 중단 보완

M05의 작은 오류 보완. 사용자가 채점 뒤 이전 음성을 끊고 넘어가는지 확인을 요청해, 새 화면에서 중단 연결이 빠진 사실을 발견했다. 기존 시험은 중단 함수를 호출하지만 새 화면은 자동재생 예약만 취소한다. 기존 음원·화면 회귀 검사(M05-T4/T18)의 누락을 보완하며 보관기간 결정이나 새로운 음원 저장 정책을 추가하지 않는다.

R1: 답 선택 시 현재 자동/수동 음성과 예약 재생을 즉시 멈춘다. 정답·오답과 키보드·클릭은 같은 선택 경로를 사용한다. 선택 확정20ms·기기 저장 완료 후 채점·정오답100ms와 시험 통신0은 유지한다.

R2: 시간 종료로 답이 확정되거나 채점 중일 때도 이전 음성을 멈추고 수동 재생으로 다시 시작하지 못하게 한다. 다음 문항에 음성이 없어도 이전 선택지 음성이 남지 않는다. 화면 이탈의 기존 해제도 유지한다.

R3: 실제 브라우저 미디어 재생 중에 답 선택/시간 종료를 실행해 중단 시점과 다음 문항의 남은 소리0을 확인한다. 기존 CDN2개 종료 검사는 이 경합을 확인하지 못한 검사였음을 명시한다. 합성 검사 음원은 동작 증명용이며 발음 내용·기기 스피커 출력을 증명하지 않는다.

D1 사용자 확인 의도: 답 선택·채점 후 소리가 남지 않고 다음 문항으로 진행. D2 내부 결정: 새 시험 화면에서 기존 stopAudio를 연결하고 공용 재생기를 바꾸지 않는다. 브라우저 음성 상태 판정/발음 내용 검수 기준은 설명하며 새 실시간 로그 전송은 만들지 않는다.

T1 실제 브라우저: 자동 문제음/수동 선택지음 × 답 선택/시간 종료, 다음 문항 무음, 선택→중단 지연·중단 후 현재 재생0·풀이 시험 API0.
T2 관련 회귀·타입/lint/지도/기록: 저장→채점/100ms, 기존 음성 중단/시간초과, 새로운 API/DB/음원 저장 없음과 기존 안내 보존.
T3 Webpack 실제 빌드와 화면 자산 생성. 운영 DB·배포는 변경하지 않는다.
