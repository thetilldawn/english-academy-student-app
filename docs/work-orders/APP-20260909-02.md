# APP-20260909-02 전체 단어 교정 연결

기록: [요구·결정·검사](../../architecture/work-records/records/APP-20260909-02.json). 사용자 전체 점검·운영 반영 승인, 미결정0건.

## 요구와 설계

- R1 원본 표기/강세 복원. WORD-20260909-02의 9권5389개 자료 감사를 입력으로 사용하고 기존승인647개와 원자료·MP3를 보존한다.
- R2 응시·영어선택지·이미본 시험의 단어보기·결과는 공통 선택기를 쓴다. 표제어와 선택 음원이 정확히 맞을 때 표시만 바꾼다.
- R3 reviewed/legacy 연결 누락을 막기 위해 실제 entry 원본·품사·음원 증명으로 묶은 private 교정표와 서비스 전용 읽기함수를 추가한다. 가짜 사전 ID나 v2 identity는 만들지 않는다. 지금 필요한 identity/occurrence/registry만 지원한다.
- R4 개인 자료·정답·원음·진행 보존. 학생 권한과 공개 조건 확인 후 요청범위400개씩 병렬 조회하며 공유캐시·새클라이언트요청은 없다.

D1 사용자 승인 범위 / D2 원본·기존승인 우선 / D3 exact-entry 별도계약 / D4 로컬→Preview→Production을 확정했다. 기존승인은 최종우선, 같은 문항이라도 표제어·variant·URL이 다르면 교정하지 않는다. 음원 선택을 SQL이나 새 부품에 복제하지 않는다.

## 오류와 복구

고정 문항 DB 회귀파일은 오답 배정·배정 수정·연속 회차에도 연결되므로 이번 기록에 그 영향 경로를 포함한다. 해당 업무 규칙은 바꾸지 않고 기존 검사를 함께 실행한다. 과거 문항의 발음 교정은 현재 단어장 값이 아니라 당시 저장한 영어 문항/선택지로 대조한다. v2/v3의 사용자 지정 발음은 모두 보호한다.

기존 로딩/빈결과/404/잠김/인증 안내와 닫기를 유지한다. 선택 교정자료 조회 실패는 기존 음원을 지우거나 시험을 중단하지 않고 안전한 운영 경고만 기록한다. 내부 SQL·자료해시·정답은 브라우저에 보내지 않는다. 교정표에는 삽입 전 기존값 충돌검사, 원본·entry·음원 해시 검사와 정확 삭제 되돌리기를 둔다.
