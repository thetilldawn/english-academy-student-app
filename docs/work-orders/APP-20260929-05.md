# 배정 후보 전체 조회

R1/D1은 승인된 F05 수리다. D2: 기존/검토 문항에 명시적 정렬·페이지를 적용하고 실제 받은 수만큼 이동하여 빈 페이지에서 종료한다. legacy에는 direction열이 없으므로 문항ID를 보조 정렬로 사용한다. reviewed는 source_row·direction·문항ID 순서다. 각 페이지 형식/단원/중복/역행/출제판/최대40,000행을 검증하며 마지막 첫행을 다시 읽어 출제판 소멸·교체를 거절한다. 페이지 전부가 같은 DB 시점이라는 보장은 하지 않는다.

D3: composition은 그대로, 최종저장의 출제판 검증도 그대로다. 가짜 응답에서 단순 전체배열 반환을 페이지 계약으로 교체하여 실제 단위·서버저장 검사가 무한반복/거짓성공을 만들지 않도록 한다. 실제문항/학생/DB쓰기/배포없음.

T1은 1,000행 초과·서버300상한·오류와판변경, T2는 최종로컬DB 및 기존회차/예문계약, T3는독립검토·타입/구조검사다.
