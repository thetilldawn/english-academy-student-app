# 시험 답 복구 멈춤과 종료 반복 수리

- 번호: APP-20261001-05. 사용자의 전체 유지보수 실행 요청에 따른 첫 독립 수리.
- 상세 요구·재현·경로·검사는 [M11](20261001_공용사전과학생기록_유지보수/15_답복구와_종료실패수리.md), 정식 R/D/T와 영향·문구는 같은 번호의 JSON 기록을 따른다.
- 현재 앱/Next16.2.12/React19.2.8을 유지한다. 근거 있는 현행 오류만 고치며 자료 공유·새 답 전송(M05)·기록 정리·관리자 기능을 섞지 않는다.
- R1: 확인된 저장 답→정상 피드백/예약 정리→다음 전환. R2: 종료 원인 분류·같은 응시 재시도 상한. R3: 기존 시간·학생 기록·권한 보존. R4: 재현/운영 관측/SQL 미확인 구별.
- M11-T1~T4/T7~T9는 T1/T2/T6, M11-T5/T11은 T3와 관련회귀, M11-T10은 T8 실제 독립 연결·후속 배정 검사, M11-T12는 T7에 연결한다. T4는 정적/빌드, T5는 독립 검토다.
- 생성/배정/원자료 수정/삭제 없음. 시험 응시와 복구·종료의 흐름만 변경한다. 운영 학생을 새로 응시시키거나 강제 종료하여 검사하지 않는다.
- 실제 대기에는 다음 문제 준비 중/저장 결과 확인 문구, 종료 실패에는 다시 확인 버튼을 사용한다. 실패를 완료/0점/빈시험으로 바꾸지 않는다. 기존 404/인증 경계를 보존한다.
- 조사→설계 관문→코드/회귀→로컬 화면→독립 검토→완료 관문. 실제 운영 반영은 같은 코드 검토 결과와 별도 DEPLOY 기록으로 남긴다.
- 공식 참고: [Next Route Handler](https://nextjs.org/docs/app/getting-started/route-handlers), [Supabase 시간초과](https://supabase.com/docs/guides/database/postgres/timeouts). 설치 버전의 기존 API만 사용한다.
