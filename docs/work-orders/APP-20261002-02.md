# 종료 시험의 작은 결과 기록

APP-20261002-02 / 승인된 유지보수 M04. 기준 코드0b9cd55(M03 구현2736600). [상세 요구](20261001_공용사전과학생기록_유지보수/04_종료시험과_학생기록.md), [구현 전 설계](../verification/20261002_종료시험_구현전설계.md), 앱 기록의 R1~R5/D1~D5/T1~T8을 연결한다. 사용자 미결정은 없다. 현재 상태·순서는 루트 작업 대장만 따른다.

| 요구 | 적용 결정 | 완료 검사 |
|---|---|---|
| R1 배정·최초/재시험 결과와 날짜·오답 키 | D1 단계별 불변 결과, 기존 점수 의미 유지 | T1/T2 |
| R2 완료·만료·미통과·재시험 대기 구별 | D2 서버 접수와 최종 채점 뒤 확정 | T3/T8 |
| R3 기존 ID·답안·사건·포인트·상세 보존 | D3 기존 보관 정책과 신규 정책 구별 | T4/T5 |
| R4 결과에 본문 사본 없음 | D4 작은 정책/단계 요약과 공용 문항 참조 | T6 |
| R5 검색·개수·상세·보관 안내 | D5 명시적 결과/상세 제공 계약 | T7/T8 |

생성은 기존 응시 시작을 유지하고 새 응시의 보관 정책만 고정한다. 답·만료·삭제 중단은 기존 확정 뒤 요약을 같은 거래에서 저장한다. 결과 조회는 학생 본인/활성 관리자의 기존 권한을 유지하고 조회에 쓰기를 넣지 않는다. 검색·내역 개수의 모집단은 기존 표와 커서 계약을 그대로 사용한다. 기존 원문/답/사건/FK/포인트의 실제 이전·삭제와 운영 공간 회수는 M08이며 이 작업에서 실행하지 않는다.

M05 기기 채점은 정상 풀이 중 호출0·종료 묶음 제출이다. 이번 결과 기록 때문에 새 클라이언트 요청을 추가하지 않는다. 사용자가 D21을 승인했다. 기한 내 기기에 저장한 답은 늦게 제출할 수 있고 원래 기기에서만 이어가며 접수 미확인 답을 자동 삭제하지 않는다. 새 묶음 규격의 미확정 답은 공식 종료로 처리하지 않는다.

실제 값 보존·최초/재시험/만료·시간초과·정상 재전송·충돌/부분 실패·삭제 중단·권한·가짜100종료 시험 비용을 검사한다. 요약 없음과 조회 실패를 구별하고, 상세가 없다고 모두 정답/0점으로 표시하지 않는다. 구현·검토 DB 반영·운영 배포를 각각 보고한다.
