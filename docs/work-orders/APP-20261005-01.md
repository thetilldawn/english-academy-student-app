## 현재 경계와 변경

- 신규 시험: `StartAttemptButton` → `prepareLocalQuiz` → 로컬 기기 기록 → `LocalQuizPlayer`. 기존 hard navigation이 목록을 없애므로 soft route와 가로채기 모달을 연결한다. 직접 오프라인 주소·서비스워커 범위는 유지한다.
- 임시 중단 모달은 기존 Dialog의 focus/ESC/스크롤 잠금·뒤 흐림을 쓴다. ESC는 시험 계속으로 닫는다. 시험 중단은 제출/포기 처리나 답 삭제가 아니라 기존 이탈과 같은 목록 복귀다.
- 기존 구형/연습 화면의 공용 카드도 시간바를 재사용한다. 정규 신규 시험의250ms 계약은 위 D4대로 기존 접수와 호환한다.
- 단어보기의 권한은 서버 학생 세션과 기존 학습 공개 판정이 소유한다. `study` 응답과 접근판을 전후 대조해 변경 경합의 자료를 옛 판으로 저장하지 않는다. 잠김·없음·오류는 다른 안내로 표시한다. 자료 캐시는 정답·학생·답안을 포함하지 않는다.
- 미리 받기 성공한 배정의 본문 키를 기억해 재hover 요청을 생략한다. 캐시 만료/누락·계정 변경·실패·취소는 성공으로 취급하지 않는다.
- 서버 본문/사전/DB 새 저장표 없음. 새 service 전용 학습 접근 함수와 기존 묶음 제출의100/250 간격 조건만 SQL 변경한다. 실학생 쓰기 검사와 부하·용량 실험은 하지 않는다.
