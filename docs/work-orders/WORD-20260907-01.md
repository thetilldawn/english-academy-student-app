# WORD-20260907-01 승인 발음 교정과 공통 연결

기준 c95f6c4 · Next.js 16.2.12 · 사용자 미결정 0건. 이전 APP03/04/05 완료와 구분한다.

## 요구와 결정

- R1: 사용자가 지정한 두 한글 발음을 교정하고 출처를 보존. 완료: 지정 두 항목만 교정, 기존 음원과 사전 현재본 및 전체 원자료 불변. 검사 T1/T2/T5.
- R2: 시험·영어선택지·단어보기·결과에서 공통 승인 표기 우선. 완료: 사전 snapshot 없는 과거 문항도 정확한 entry/source/variant/audio 증거가 있으면 같은 표기, 음원 또는 사전 ID가 다르면 적용하지 않음. 검사 T1/T3/T4/T5.
- R3: 전체 지정 단어장의 자동 표기·사전 출처 점검 및 재검토 목록 보존. 완료: 1009행 원자료 해시와 정확 사전 일치/차이를 항목별 기록, 차이만으로 오류·승인으로 판정하지 않음. 검사 T6.
- R4: 학생 정보·정답·원음·시험 진행 보호. 완료: 권한 확인 뒤 읽기 전용 조회, 공개 실행 차단, 기존 오류/빈결과/404 구분과 개인 no-store 보존. 검사 T2/T3/T4/T5.

- D1: 앞선 두 지정값을 재질문하지 않고 적용. 대기시간/배지/수량 수정은 완료로 보존, 발음 교정을 재개. 근거: 2026-09-07 정확한 발음 예시 및 고쳐 ㄱㄱ, 최신 재개.
- D2: 기존 approved table의 user-directed 작업 출처로 2행만 별도 검증 거래 삽입. source_content_sha256은 원음/POS/표제어/기존표기 포함 immutable identity hash. 구 독립2검토 importer는 변경하지 않음. 근거: 기존 표/불변 identity 계약·독립 읽기 검토.
- D3: 서버전용 단일 읽기 RPC로 현재 entry+원문+default binding+identity+승인 해시를 검증. 기존 dictionary 조회는 user-directed를 제외. 최종 선택 음원과 승인 variant/URL/사전ID가 같을 때 표시만 교체. 조회실패 시 기존 정상 발음 보존, 실패를 새 승인/발음없음으로 조작하지 않음. 근거: 현재 attempt/study/result 조회와 공통 선택기 실코드.
- D4: 요청한 교정은 로컬 검사 후 Preview와 Production에 순서 적용. 음원 재생성/다른 표기 대량 교체/새 비용/학생 시험 재작성 없음. 근거: 기존 운영수정 승인, 발음 고쳐 ㄱㄱ 및 재개.

## 연결·영향·복구

- dataFlow: 권한 확인→기존 entry목록→기존발음조회와 병렬 승인entry RPC→공통 최종음원 선택→표시/강세만 교정→기존 시험/선택지/학습/결과 UI. 생성/배정/검색/삭제/채점 흐름 변경 없음; 교정 삽입은 관리자 운영거래 별도.
- reuse: 기존 approved 표와 pronunciation-snapshot 순수 선택기, pronunciation-registry server-only 및 기존 표시/음성 부품 재사용. 범용새승인서비스/컴포넌트/사용자API 없음.
- cache: 추가 자료는 요청 범위의 고유 entry500개 묶음 읽기. 기존 조회와 Promise.all; 공유캐시/새폴링/브라우저요청 없음. 학생자료 private,no-store 유지.
- compatibility: 원음 선택 우선순위와 기존v1 승인 계약 보존. 별도 user-directed 증거가 맞을 때만 overlay. 기존 문항 snapshot/정답은 업데이트하지 않음. 조회 실패는 기존 정상값을 유지하고 서버에 안전한 오류코드만 기록.
- rollback: 추가 승인 두행 중 작업ID/해시/표시가 정확히 일치하는 것만 승인취소 거래로 복구 가능. 앱 이전 커밋 복구 시 읽기RPC는 미사용으로 보존. 학생/음원/원자료 되돌림 없음.

데이터 작성은 앱 외 자료영역의 사용자 지시 manifest를 사용한다. 앱 Git에는 실제 교재 단어/학생자료를 넣지 않는다. source hash 의미는 이 작업의 user-directed 행에 한정하며 기존 v1의 의미를 바꾸지 않는다.

## 상태와 검사

- initial-loading: 첫 단어장 조회 → 단어장을 불러오고 있습니다…. 제목·닫기와 기존 로딩 표시 유지. 복구: 조회 완료 대기. 부품 src/features/student-dashboard/ui/assignment-study-frame.tsx, T4.
- refreshing: 예약 공개 시각 도달 → 별도 문구 없음(현재 안내 유지). 기존 단일 경계 갱신 유지, 반복 조회 추가 없음. 복구: 예약 시각에 기존 서버 목록 갱신. 부품 src/features/student-dashboard/ui/assignment-boundary-refresh.tsx, T4.
- unselected: 관리자 범위 미선택 → 단어장을 선택해 주세요.. 기존 미선택 표시 유지, 0건으로 계산하지 않음. 복구: 단어장 선택. 부품 src/features/assignments/ui/vocab-range-assignment-sections.tsx, T4.
- empty: 정상 조회 결과 배정 0건 → 아직 배정된 시험이 없습니다.. 정상 빈 결과와 실패를 구분하는 기존 표시 유지. 복구: 선생님이 배정하면 목록에 표시. 부품 src/features/student-dashboard/ui/student-dashboard.tsx, T4.
- validation: 교정 행의 variant/원음/출처 불일치 → 기존 정상 발음 표시 유지. 일치하지 않는 승인 표기를 적용하지 않으며 시험 입력/답안 상태 불변. 복구: 운영 검수 기록에서 출처 확인. 부품 src/lib/quiz/pronunciation-snapshot.ts, T4.
- load-error: 단어장 조회 실패 → 단어장을 불러오지 못했습니다. 연결을 확인한 뒤 다시 시도해 주세요.. 빈 결과로 바꾸지 않고 제목·닫기·재시도 보존. 복구: 다시 시도 버튼. 부품 src/features/student-dashboard/ui/assignment-study-error.tsx, T4.
- save-error: 관리자 후속 회차 처리 오류 → 처리할 회차를 확인하지 못했습니다. 최신 내역을 확인해 주세요.. 기존 오류 전달과 최신 내역 확인 유지; 명령 자동 반복 없음. 복구: 기존 최신 내역 조회. 부품 src/features/assignment-queue/ui/assignment-queue-history.tsx, T4.
- auth-error: 학생 세션 만료 또는 다른 학생 요청 → 기존 로그인 화면으로 이동 또는 조회 불가 표시. 개인 자료를 표시하지 않는 서버 인증 유지. 복구: 학생 접속코드로 다시 로그인. 부품 src/features/student-dashboard/server/components/assignment-study-content.tsx, T4.
- not-found: 조회할 수 없는 단어장 → 확인할 수 없는 단어장입니다. 현재 배정된 시험에서 다시 열어 주세요.. 기존 404 경계와 닫기 보존; 공개 대기와 구분. 복구: 닫은 뒤 현재 배정에서 다시 열기. 부품 src/features/student-dashboard/ui/assignment-study-frame.tsx, T4.
- unexpected-error: 단어장 경계의 예상 밖 오류 → 단어장을 불러오지 못했습니다. 연결을 확인한 뒤 다시 시도해 주세요.. 기존 경계의 안전한 안내 유지; 내부 SQL 원문 표시 금지. 복구: 경계 재시도 또는 닫기. 부품 src/features/student-dashboard/ui/assignment-study-error.tsx, T4.

- T1: 활성/저장/미보유 음원, 승인 우선, 다른 variant/URL/사전ID, snapshot 없는 교정. 예상: 표시/segments만 교체, 원음 불변 및 미일치 기존값 유지
- T2: 요청범위/해시/source row/POS/default/활성/모호성/권한/재실행. 예상: 정확 승인만 반환, 익명/일반사용자 실행 불가; 읽기쓰기0
- T3: chunk500/중복ID/잘못된 응답/실패/구approved보존/신승인분리/소비자 전달. 예상: 공통선택기를 사용하고 실패시 안전한 기존음원 유지, 새 권한노출0
- T4: 전체 단위·기존학습/선택지/결과·오류/404/권한/캐시 회귀·타입·lint·지도·구조·빌드. 예상: 필수 통과, 기존 쉬운 상태 UI 유지, 건너뜀/미검증 명시
- T5: Preview 후 운영 정확두행 readback·원음/학생보호 지문·실화면 또는 동일서버경로·독립검토. 예상: 양쪽 지정값·원음 불변 확인, 외부상태 범위확대0
- T6: 자료영역 1009행 출처/현재사전 정확일치 item-level 감사와 차이 재검토 목록. 예상: 원자료해시/합계재현, 차이를 검수승인이나 음원오류로 간주하지 않음

자료를 못 읽은 오류와 정상 미등록은 서버에서 구분한다. 보조 교정 조회의 실패는 기존에 검증된 발음을 계속 표시하는 안전한 기능 저하이며, 발음이 새로 검수되었다고 표시하지 않는다. 단어장 자체 조회 실패/인증/404 경계는 그대로 유지한다.
