# 직전대비 용도와 학기별 단어장 선택

사용자 확정 요구를 기존 단어장 검색에 연결한다. 교과서 원자료 종류는 보존하고 별도 교과서 필터 버튼을 제거한다. 학교 직전대비의 용도와 학기를 함께 선택하며 일반 단어장의 기존 학교+공통 표시를 유지한다.

- **R1** 직전대비 용도를 원자료 종류와 구별해 표시하고 교과서 필터 버튼을 제거한다. 완료 기준: 형용사와 교과서 원자료를 유지하며 명시한 용도로 분류한다. 검사: T1, T5
- **R2** 학교·학년·용도·학기를 함께 필터한다. 완료 기준: 선택한 학교+고2+직전대비+2학기에서 세 자료만 표시한다. 검사: T1, T3, T5
- **R3** 검색·필터·취소·같은 자료 재선택에서 기존 배정 조건과 기록을 유지한다. 완료 기준: 다른 자료의 확정 선택에서만 기존 전환을 호출한다. 검사: T2, T3
- **R4** 서버가 허용한 용도와 학기만 공개 응답에 전달한다. 완료 기준: 원문 경로나 임의 metadata가 노출되지 않고 잘못된 학기는 미분류다. 검사: T1, T4, T6

D1·D2는 사용자 확정이며 D3은 기존 정책을 보존하는 내부 설계다. 자세한 변경 경로·UI상태·권한·캐시·검사는 architecture/work-records/records/APP-20260913-01.json에 연결한다. 학교 원문 등록·현재 자료 전환은 APP-20260913-02의 별도 작업이며 이 UI 검사만으로 운영 자료가 바뀌었다고 표시하지 않는다.

T1 변환·필터, T2 선택 수명, T3 실제 준비/선택 연결과 실패 복구, T4 정적·구조·타입 검사, T5 PC/모바일 실제 화면, T6 빌드. 아직 실행하지 않은 검사는 완료로 기록하지 않는다.
