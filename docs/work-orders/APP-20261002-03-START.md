# 배포 중 새 시험 시작만 잠시 중지

기존 M05/M10-T8 누락의 작은 보완이다. 상태와 순서는 루트 대장만 따른다.

R1: 새 배정 시험의 시작만 일시 중지 — 정상 기본값·중지 확정 뒤 네 생성 경로 거절·준비/시계/문항 잔여 없음. T1/T3.

R2: 이미 시작한 시험의 진행과 접수 보존 — 시작 재전송·구형/신규 재시험·늦은 답·동일 제출 재접수 보존. T1/T3.

R3: 권한과 안내 보존 — 앱의 설정 조회/변경 권한0·쉬운 안내·기존 답/학생행 보존. T1/T2/T3.

D1 사용자: 기존 M05/M10의 누락 보완을 계속 진행. 기록/캐시/음원/관리자 정책은 합의 그대로. 근거: 사용자 ㄱ 및 유지보수 진행 승인.

D2 내부: private 단일 설정행·기본 false. 기존 신규 응시 INSERT guard의 학생 잠금 다음에 FOR SHARE. 설정 변경은 해당 행 UPDATE만 별도 짧은 거래로 확정. 근거: M10-T8과 독립 DB 검토.

D3 내부: 준비는 가능, 새 INSERT만 거절. 기존 시작 재접수/재시험 UPDATE/회차 제출은 유지. 자율연습 제외. 근거: M10 실행 명세.

D4 내부: 운영자 SQL로만 변경. 설정행 누락은 새 시작 거절. 잠금을 잡은 채 보존 검사/배포/학생 변경을 실행하지 않음. 근거: 공식 PostgreSQL FOR SHARE 문서와 잠금 순서 검토.

T1: 네 신규 시작·기존 재접수/재시험/늦은 답·설정 권한·공개 검사 → 중지 중 신규만 거절하며 기존 기록과 결과 유지.

T2: 신규/구형 시작 거절 안내와 구조·타입·lint → 알려진 중지 오류만 쉬운 안내, 기존 복구/답 보존.

T3: 독립 검토·검토 DB 보존·두 실제 연결의 중지/시작 순서 → 학생행/다른 함수/권한 보존, 중지 확정 뒤 신규0·기존답 접수 가능.

## 안내와 재개

점검 중이라 새 시험을 시작할 수 없습니다. 잠시 후 다시 시도해 주세요. 진행 중인 시험은 계속할 수 있습니다. 기존 시작 실패 영역에 표시한다. 새 화면이나 중간 로딩을 추가하지 않으며 시작 재시도로 복구한다.

## 운영·복구

설정 UPDATE는 해당 행만 바꾸는 짧은 거래로 COMMIT한다. 보존 검사나 학생행을 변경하는 거래와 묶지 않는다. 중지 확정 전에 시작된 시험은 허용된 기존 시험으로 보존한다. 기본값 false이며 false로 돌리면 새 시작을 재개한다. 앱 역할에는 설정 조회/수정권한이 없고 누락된 설정은 새 시작을 거절한다.

Supabase CLI 2.98.2 migration new로 생성한 파일명이다. 20260906 guard에만 의존하고 이후 SQL은 guard를 수정하지 않으므로 기존 20261003 파일 사이 순서에서도 동작한다. [공식 잠금 설명](https://www.postgresql.org/docs/current/explicit-locking.html)을 대조했다. Windows PostgreSQL/initdb를 실행하지 않는다.

운영 배포·정리·발음 자료 변경은 이 보완의 검증 뒤 각각 기존 작업으로 이어간다.
