# 학생 목록 개인 캐시 시험

- D7/T8 완료 보완: 기존 공용 부품의 같은 폴더·동명 .test 파일을 정확히 등록된 실제 부품 소유자에 연결한다. 임의 경로나 테스트 제외는 허용하지 않는다. 변경 영향과 완료 검사에 같은 소유 규칙을 적용한다.

- 승인된 캐시 실행계획3단계. [R/D/T 기록](../../architecture/work-records/records/APP-20260906-08.json), [앞선 실측](../verification/APP-20260906-07.md). 캐시 먼저, 학생 단어 가리기는 마지막. D1 기존사용자승인·D2–D4 내부설계, 사용자 미결정0.
- R1 재방문 중복조회 감소, R2 현재 인증·포인트, R3 변경/만료/오류/복구, R4 성능·안전 채택 판정. 완료조건과 검사는 기록의 T1–T7에 연결한다.
- 학생 첫페이지·정규조건별 브라우저메모리만 쓴다. 새패키지·DB·원자료·실학생·공개캐시·내부RSC헤더·새라우터는 없다. 기존목록UI/검색/커서/성공알림/로그아웃 이탈확인을 재사용한다.
- 시험 1차의 최초 Client 읽기는 최초 중앙값 약103ms로 기존52ms보다 느려 기각했다. D6 보완: 문서 첫 진입은 기존 서버 인증/목록 1회를 그대로 쓰고 최초 hydration에만 그 응답을 인계한다. 이후 Client 재진입은 현재 인증/포인트를 읽는다. 표준 Sec-Fetch-Dest/Accept로 조회 위치만 고르고 권한을 판단하지 않으며 Next 내부 RSC 헤더를 쓰지 않는다. OFF는 기존SSR이다.
- 최초표시 중앙값/p95 10% 악화 이내, 왕복 중앙값30% 개선과 권한확인후100ms 목표는 그대로 유지한다. 같은환경10회 비교하며 미달시 확대하지 않는다. 빌드 직후 준비1회는 별도 보존하고 브라우저 자원이 준비된 뒤 개인 메모리를 비우는 문서 새로고침10회를 비교한다. 옛 1차 결과를 덮어쓰지 않는다.
- 서버 인계는 React의 getServerSnapshot이 적용되는 최초 HTML/hydration에만 허용한다. Client 경로 재마운트/옛 RSC/탭복귀에 같은 응답을 다시 권한 근거로 쓰지 않는다. [React 공식 기준](https://react.dev/reference/react/useSyncExternalStore#adding-support-for-server-rendering), [Next headers](https://nextjs.org/docs/app/api-reference/functions/headers), [표준 문서 요청 헤더](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Sec-Fetch-Dest).
- 성공15초까지 목록RPC 생략가능, 그러나 재진입/뒤로앞으로/탭복귀는 현재인증·현재포인트를 읽는다. 60초표시상한,120초미사용제거,최대20조건. 더보기는 현재마운트에서만, 자동재시도·주기조회없음. 인증/포인트비용은 따로 기록한다.
- rawPoints를 캐시에서 제거한다. 기존 활성관리자 RLS로 현존학생과 현재집계를 묶어읽는다. 존재확인된 학생의 집계없음만0, 누락학생은목록재조회, 실패는확인불가. service-role 우회없음. 검증된 session_id의 hash로세대를구분하며 세대없으면보관않는다.
- 성공변경 전에 무효화신호를 보내 옛응답을폐기하고 첫페이지·커서를갱신한다. 실패한 저장은 캐시를바꾸지않는다. 로그아웃은 이탈확인 통과후 실제요청시작에취소/폐기/숨김, 통신실패에도복원않는다. 다른탭에는 종류/난수신호만, 이름·점수·토큰을보내지않는다.
- 표시=기존UI, 요청/수명=제어기, HTTP=전송, 응답=계약, DB=server query. 로딩 ‘학생 목록을 불러오는 중…’, 실패 ‘학생 목록을 불러오지 못했습니다. 다시 불러와 주세요.’와재시도, 인증실패는목록숨김+로그인, 정상0은기존빈목록. 내부오류원문을보이지않는다. 기존404/예상밖경계유지.
- 생성/배정/수정/삭제는 업무불변·성공무효화만. 응시/점수계산/시험기록은불변,정답을읽지않는다. T1 시간/수명, T2 세션/복원, T3 실제UI, T4 서버/HTTP, T5 실측, T6 전체/빌드, T7 독립리뷰.
