- T1: 정상/빈/null, HTTP400/401/403/503/404·잘못된 JSON/필수 필드/조건 불일치, 취소·7초 제한·원문/정답 필드 제거. 예상: 읽기 계약/안전한 실패 종류만 반환; 실패를 빈 성공으로 처리하지 않고 no-store 유지.
- T2: 이전 0건 뒤 새 검색의 대기/실패/재시도, 성공 0건, 이전 행 안내, 공백·필터 보존·취소·늦은 응답, 인증 후 조건 복원. 예상: 한국어 안내·작동하는 버튼, 실패와 없음 동시 표시/오류 원문/권한 실패 뒤 재노출 없음.
- T3: UI 구역 검사도 함께: 21건/중복 제거, 변경 후 커서 폐기·읽기 재시도, 더보기 실패 복구·인증 시 모든 구역 숨김. 예상: 서버 개수·유효 커서만 사용하며 오류/0건 구분, 같은 읽기만 재시도, 원문 미표시.
- T4: 기존 관리자 API 권한/응답 최소화/no-store 및 학생 상세 공용 표시 회귀검사. 예상: 인증 전 조회/정답/개인 진단 원문 노출 없음; 외부 DB 호출 없이 기존 동작 유지.

- T7은 기존 실계정 fixture가 아닌 격리된 가짜 데이터만 사용한다. 기존 fixture 명령은 DB 쓰기가 있어 금지. 실행할 수 없으면 미검증으로 남긴다.
- 설계 관문 → 실패 재현 검사 → 구현·좁은 회귀 → 독립 검토 → 전체 로컬 검사 → 필요한 실제 화면 → 결과/해시 연결. 과거 검사 수치는 재사용하지 않는다.
