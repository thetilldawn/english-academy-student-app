# 학생 단어장 블러 가리기

- APP13 기존 학습보기 보완. 기준 bc48313 및 선행 APP12 로컬 검증본. Next16.2.12/React19.2.8, 사용자 미결정0. 상태·순위는 루트 대장만 따른다.
- R1/D2: 영어→뜻은 영어·뜻 두 토글, 예문 없음. 동시에 둘 다 가릴 수 없으며 반대쪽을 가리면 기존 열은 다시 표시한다(사용자 추가확정). 영영풀이→영어와 예문→영어는 단어 토글 하나. 각 유형의 학습 열을 표시하며 부가 한국어 뜻 열은 일반형에서 사용한다. 숨김은 250ms blur로 크기/위치 유지, 감소 모션에서는 전환 생략.
- R2: 풀이·예문 전체는 가리지 않는다. 예문형 영어 숨김은 본문 속 해당 표현도 가리며 다시 표시하면 원문 그대로다. 영어 열의 발음·스피커도 함께 가리고 재생을 멈춰 단서가 남지 않게 한다.
- R3/D3: 기존 권한 RPC 성공 뒤 예문형만 같은 배정의 승인 prompt를 서버에서 한 묶음 읽고 원문과 정확히 정렬한다. 불규칙 활용을 추측하지 않는다. 범위 정수만 보내고 원문/정답/DB는 수정하지 않는다. 실패와 정상 문장없음은 구분한다.
- D1: 공개 업로드 질문을 포함한 직전 확인에 사용자가 ㄱㄱ로 승인하고 가리기 조건을 확정했다. 기존 공개 GitHub의 앱 코드·개발 문서만 대상, 비밀키/학생자료/원천 제외. Preview·Production은 별도 DEPLOY 검증으로 진행한다.
- D4: Client 조립부=단일 표시 선택(null/english/meaning)·음성 수명, Words/Blur/Controls=좁은 props의 표시, 기존 Frame=상단 슬롯과 모달/직접페이지. 표시 가리기는 보안기능이 아니다. DOM 공간 유지+aria-hidden/inert/선택금지로 우연한 읽기·접근성 단서만 막는다. 토글 때 네트워크/저장0.
- 생성/배정/응시/검색/삭제/점수·포인트/기존캐시는 변경하지 않는다. 모달 경로·서버인증·출제규칙·원문·404·오류 닫기는 유지한다.
- 쉬운 상태 안내: 처음/재조회 `단어장을 불러오고 있습니다…`; 선택 문장 null `등록된 학습 문장이 없습니다.`; 실패 `단어장을 불러오지 못했습니다. 연결을 확인한 뒤 다시 시도해 주세요.`→다시 시도; 위치불명은 숨김 상태에서만 해당 문장 전체를 임시 블러하고 안내, 다시 표시는 원문 그대로. 위치불명 `예문에서 가릴 단어 위치를 확인할 수 없습니다.`; 404 `확인할 수 없는 단어장입니다. 현재 배정된 시험에서 다시 열어 주세요.`→닫기. 입력/저장 자체는 없으며 음성실패는 기존 행 안내·스피커 재시도다. 인증실패는 기존학생접속/숨김404. 전체 상태·영향/T연결은 JSON에 기록한다.
- T1 원문/빈칸 구간; T2 유형별 블러/수명/접근성/쉬운안내; T3 현재권한/예문 묶음읽기/최소자료; T4 전체·타입/lint/구조/빌드; T5 실제 로컬 모달·직접페이지·고정상단. 구현 전 설계 관문, 구현 후 현재해시·실제실행을 결속한다.
