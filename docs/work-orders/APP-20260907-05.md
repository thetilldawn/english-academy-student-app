# APP-20260907-05 단어장 이름 테두리 배지

작은 UI 수정. 기준12d5585 / Next16.2.12·React19.2.8 / 사용자 미결정0. 기존 코드 길찾기 admin-history-read와 history의 공통 표시 경로를 확인했다.

- R1/D1: 공통 관리자 내역 행의 단어장 이름만 중립색 테두리 배지로 표시하고 제목과 범위 사이 구분점만 제거. 제목 자체의 `고등 · 2025개정`과 범위·오답 범위 문장은 원문 그대로 유지한다.
- R2/D1: 목록 구조·이동 링크·학생 이름·점수·마감/완료 상태·날짜는 유지한다. 학생 시험 카드와 상세 화면 제목을 개편하지 않는다.
- D2(내부): 기존 MetaTag를 재사용하되 기능 CSS로 해당 제목만 투명 배경 처리한다. AssignmentMetaTags의 명시적 datasetAppearance='badge'는 공통 HistoryActivityRow에서만 전달하고 기본 text는 상세 제목의 기존 모습을 유지한다. compact를 스타일 선택 의미로 재사용하지 않는다. 새 범용 만능 부품·클라이언트 상태·HTTP·서버 경계 변경은 없다.

데이터 흐름: 기존 서버 내역 조회→검증된 목록 자료→HistoryActivityRow→AssignmentMetaTags→MetaTag. 표시 조합만 수정하므로 생성/배정/응시/검색/삭제/기록 API는 기존 경로 유지다. private/no-store와 기존 계정별 캐시·로딩·오류·빈 결과·모달 경계는 변경하지 않는다. 별도 클릭 요소를 행 링크 안에 만들지 않는다.

T1: 제목 배지와 구분점 제거, 제목 내부 점/범위 보존, 상세 기본 text 보존, 공통 내역 사용처·점수/상태/이동 링크 회귀. T2: 관련 검사·전체 검사·타입/lint/구조·최적화 빌드. T3: 로컬 가짜 자료로 390px/1280px 제목 줄바꿈·테두리·좌우 넘침·동일 목록 구조 확인. 디자인의 실제 화면 검증과 코드 검사를 구분한다.

복구: 이 표시 변경 커밋만 되돌린다. DB/배정/학생/점수/음원 변경 없음. 자체 검토를 사용자 새 업무 승인으로 취급하지 않는다. 최종 앱 배포는 기존 승인 범위로 Preview/운영 각각 올바른 환경에서 빌드하며 앞선 APP0703/04와 별도 커밋으로 추적한다.
