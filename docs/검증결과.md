- 앱 화면에는 공개 학생 회원가입 경로가 없음
- Hosted Auth API의 이메일 공개 가입 설정은 현재 켜져 있어 배포 전 비활성화 필요
- `.env.local`은 Git 제외 상태로 생성
- Supabase URL·공개키와 앱 비밀값 4개 구성 완료
- `SUPABASE_SECRET_KEY`만 비워 두고 사용자 직접 입력 대기
- 능률보카 변환 JSON은 `data/import/` 규칙으로 Git 제외
- 앱 Git remote 연결·비공개 GitHub `main` 첫 푸시 완료
- 실제 학생정보·성적·교재 원본을 앱 Git에 넣지 않음
- 프로젝트 루트와 `영어/`에는 Git 저장소를 두지 않음
