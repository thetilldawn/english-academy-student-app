# 학생 현재 단어장 프로필 검증

> 역사 스냅샷: 자유입력 프로필 단계의 기록이다. 현재 선택형 구현은
> [학생 생성·단어장 선택 정상화](학생_생성_단어장선택_정상화.md)를 따른다.

- 검증일: 2026-07-29
- 범위: 학생 생성 정보의 필수·선택 구분, 현재 사용 단어장 기록·표시
- 실제 학생정보: 사용하지 않음

## 반영 내용

- 학생 이름은 필수 입력으로 유지한다.
- 학교, 학년, 현재 단어장, 관리 메모는 선택 입력으로 표시한다.
- 현재 단어장은 최대 160자의 운영용 표시명으로 저장한다.
  예: `능률 VOCA 어원편 2025개정`
- 비어 있는 선택값은 DB에 `NULL`로 저장한다.
- 학생 카드와 선택 학생 작업 패널에서 현재 단어장을 확인할 수 있다.
- 단어장 데이터셋과 학생 표시명을 억지로 연결하지 않는다. 실제 시험에
  사용하는 단어 데이터는 기존 `assignments → vocab_datasets` 관계로
  별도 관리한다.

## 향후 진척도·성취도 원칙

- 관리자가 수동으로 진척률을 입력하는 필드는 이번에 만들지 않았다.
- 이후 그래프와 히스토리는 배정 기록, 시험 시도, 점수, 오답,
  학생별 단어 상태를 집계해 계산한다.
- 현재 단어장 표시명은 학생이 지금 무엇을 공부하는지 빠르게 확인하는
  프로필 정보로만 사용한다.

## DB 적용

- 마이그레이션:
  `supabase/migrations/20260728213700_add_student_current_vocab_book.sql`
- `students.current_vocab_book text null`과 160자 제한을 적용했다.
- 기존 8인자 학생 생성 함수는 이전 배포 호환용으로 유지하고,
  현재 단어장을 받는 9인자 함수를 추가했다.
- 공개·익명 실행권한은 없고 로그인한 활성 관리자만 실행할 수 있다.
- 원격 Supabase 적용과 스키마·권한 검산을 완료했다.
