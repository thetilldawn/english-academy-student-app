# 한국어 UI 문구 카탈로그

화면의 정적 제목·라벨·도움말은 페이지와 컴포넌트별 TypeScript 객체에서
관리합니다. JSON은 주석을 지원하지 않으므로 `as const` 객체를 사용합니다.

- 키 위의 주석은 실제 화면 위치입니다.
- 문자열 값만 바꾸면 해당 값을 불러오는 화면에 반영됩니다.
- 오류 코드, 서버 검증 메시지, 감사 로그처럼 동작 계약에 속하는 문구는 이
  폴더로 옮기지 않습니다.
- 새 문구는 가장 가까운 페이지 파일에 추가하고 컴포넌트에서 직접 문자열을
  중복 작성하지 않습니다.

## 파일 구분

- `common.ts`: 여러 화면에서 함께 쓰는 문구
- `admin-shell.ts`: 관리자 브랜드·내비게이션·로그인
- `admin-overview.ts`: 관리자 Overview
- `admin-students.ts`: 학생 관리와 학생 상세
- `admin-learning.ts`: 학습 관리와 각 배정 모달
- `admin-history.ts`: 내역 목록과 상세 모달
- `student-app.ts`: 학생 로그인·시험 목록·응시 화면

문구를 바꿀 때 키 이름과 객체 구조는 유지하고 따옴표 안의 값만 수정합니다.
