# 시험 결과 기능 안내

- 먼저 `npm run map:feature -- results`로 결과 page, 조회 서비스, 학생 시험 흐름과의 연결을 확인한다.
- `domain`은 결과 해석 규칙, `api`는 응답 변환, `ui`는 표시만 맡는다.
- 응시 완료·오답·포인트 기록 규칙은 학생 시험 흐름의 DB 계약에 있으며 결과 UI에서 다시 계산하지 않는다.
- APP-20261002-02: `contracts/result-record.ts`와 `server/result-record-query.ts`가 보관 정책·단계 결과 및 같은 시점의 상태/점수/날짜를 소유한다. 두 상세 조회는 첫 조회의 오래된 상태를 섞지 않는다. 신규 결과의 상세는 최초 오답만 읽으며 작은 문항 배열로 전체 점수를 계산하지 않는다.
- `ui/result-record-summary.tsx`는 학생·관리자 공용 표시다. 상세 미보관과 실제 오답0을 구별하고 없는 과거 시각을 추정하지 않는다. SQL 적용은 새 응시만 정책을 등록하며 기존 답/본문/포인트를 삭제하지 않는다.

## APP-20261002-03 재시험 연결

- start-retry는 인증된 규격 조회 후 신규 규격이면 원래 기기 답/계획으로 이동한다. 기존 규격에만 옛 재시험 준비 요청을 보낸다. 새 재시험은 공식 최초 접수의 대상과 원판을 유지하며 정상 종료 때 묶음1개를 제출한다.
