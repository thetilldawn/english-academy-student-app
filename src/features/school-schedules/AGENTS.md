# 학교 시험과 수행평가 일정

- 공식 운영정보는 앱 밖 자료 구역에 보관하고, 검토된 일정만 출처 해시와 버전으로 등록한다.
- 관리자 조회는 requireAdmin, 학생 조회는 현재 자체 학생 세션만 사용한다. 개인 소속을 공유 캐시에 넣지 않는다.
- domain은 한국의 오늘 날짜와 학교 시험기간 첫날을 사용한다. 영문 과목 시험일이나 수행 미정 날짜를 만들어 넣지 않는다.
- public-server/public-ui/public-contracts를 통해 기존 학생 목록·정보·개요·학생 홈에 연결한다.
- 학교키 없는 기존 학생은 자동 수정하지 않는다. 직접 학교명을 바꾸면 낡은 선택키를 지운다.
- ui는 표시만, server/queries는 읽기만, 등록은 별도 검증 명령이다. 실제 학생 기록을 화면 검사로 변경하지 않는다.
- 수동 편집은 server/actions의 현재 관리자 확인과 DB 재확인을 거친다. 원천은 보존하고 요청 ID·저장자·기준 원천/수동 버전과 수동 전체값을 이력으로 남긴다. 원천 갱신은 수동 입력을 덮지 않으며 새 원천 여부를 편집기에 알린다.
- 공통/학교 지정과 개인 선택은 해당 입학생 편제표로 판단한다. 국가 교육과정의 선택 분류만으로 수강 미확인 태그를 붙이지 않는다.
- 수능은 학교 원천과 구분한 공식 전국 공개 자료다. 시행연도와 명칭 학년도를 구분하고 현재 고3에만 합성한다. 새 학년도는 공식 날짜 확인 후 갱신한다.
