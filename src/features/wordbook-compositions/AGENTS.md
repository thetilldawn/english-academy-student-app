# 모의고사 단어장 조합

- 원천 범위 목록, 다중선택, 이름 저장과 고정된 구성 정보를 소유한다.
- 연도/월/유형은 독립 조건이다. 같은 조건의 여러 값은 하나라도 맞으면 포함하고 서로 다른 조건은 모두 맞아야 한다.
- 표시 조건을 바꾸어도 담은 범위는 유지한다. 현재 조건 선택/해제는 보이는 범위만 변경한다.
- 단어장 저장은 원출현을 삭제하지 않는다. 시험 범위 선택 후 검토된 동일 표제어/품사/뜻만 정리한다.
- 단어 ID나 철자만 같은 후보를 같은 뜻으로 취급하지 않는다. 승인되지 않은 원천을 출제 가능 자료로 승격하지 않는다.
- 다른 기능은 public-ui/public-server/public-contracts 경계로만 접근한다. 서버만 원천 검증과 저장을 수행한다.
- 검토 원자료는 영어 자료 구역에 있고 앱 검사에는 가짜 자료만 넣는다.
