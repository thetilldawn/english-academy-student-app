# 단어장 범위 조합과 템플릿

- APP-20261008-01: 새 배정 범위는 기존 사전·원자료 키를 묶어 쓴다. 구형 복사 생성 함수는 과거 동일 접수 조회만 지원하고 새 요청을 거절한다. 신규 source-key-v3 문항/준비 계획에는 기존 원키·선택지키·확인값을 저장한다. 과거 inline 구성·중단된 준비·배정·학생 기록은 유지한다. 새로운 사전이나 본문 저장층으로 우회하지 않는다.
- APP-20261008-02: 한 요청의 원키 연결은 한 번 읽어 발음 소비자에 전달한다. 요청 간 전역 캐시로 바꾸지 않는다.

- APP-20261003-01: 공식 종류는 `templateKind`와 기존 자유 설명을 분리한다. 새 저장 v3/조회 v2/생성 요약 v3만 명시적 nullable 종류를 전달하고 구형 영수증은 변경하지 않는다. 미분류를 기타로 치환하지 않는다. 요약에서 과거 판의 범위/태그를 유지하며 실제 범위 조작만 새 내용판을 만든다. 저장 확정 후 배정 목록 표시 갱신과 실제 단어장 선택을 별도 콜백으로 처리한다. `libraryQuantitiesSchema`는 고정된 단어·학습 키와 실제 사용 가능한 문항을 구분하며 깨진 참조는 조회 실패다.

- APP-20261001-06: 입력 원고는 `libraryResourceV1Schema`로 검사하고 조회 응답만 v1/v2 union으로 읽는다. 새 형식의 proofs에는 state/ref만 있으며 value를 null로 만들어 구형처럼 다루지 않는다. 의미 공유는 승인된 기존 의미 키만 사용한다. 원행·문자열 사전 ID·옛 UUID·발음값·원본 SHA를 별도로 보존한다. 신규 참조 오류는 `X-Wordbook-Source: unavailable`과 공용 한국어 안내로 중단하고 최신 사전/빈 값으로 우회하지 않는다.

- 원천 범위 목록, 다중선택, 이름 저장과 고정된 구성 정보를 소유한다.
- 연도/월/유형은 독립 조건이다. 같은 조건의 여러 값은 하나라도 맞으면 포함하고 서로 다른 조건은 모두 맞아야 한다.
- 기존 모고 조합기의 표시 검색은 담은 범위를 유지한다. 단어장 템플릿 편집(APP-20260921-01)에서는 자료별 묶음의 조건 변경이 그 묶음을 다시 계산하며 다른 묶음은 유지한다. 잘못된 구간 입력 중에는 기존 범위·제외를 보존하고 저장을 막는다.
- 단어장 저장은 원출현을 삭제하지 않는다. 시험 범위 선택 후 검토된 동일 표제어/품사/뜻만 정리한다.
- 단어 ID나 철자만 같은 후보를 같은 뜻으로 취급하지 않는다. 승인되지 않은 원천을 출제 가능 자료로 승격하지 않는다.
- 다른 기능은 public-ui/public-server/public-contracts 경계로만 접근한다. 서버만 원천 검증과 저장을 수행한다.
- 검토 원자료는 영어 자료 구역에 있고 앱 검사에는 가짜 자료만 넣는다.
- `domain/library-editor`는 종류별 조건과 자동 태그/이름 제안을, `domain/library-criteria`는 조건 묶음과 직접 선택 참조를 소유한다. 과거 criteria=null은 scope ID/version/제외/순서를 그대로 복구하며 조건을 역추정하지 않는다.
- 템플릿 파일 불러오기 UI는 제거했다. 미확정 pending은 실제 POST 직전에만 만들며 이전 요청 결과 확인을 다른 생성 명령으로 바꾸지 않는다. 새 저장 검사는 읽기/완료 요청 계약과 분리한다. 새 DB 삽입 방어는 과거 빈 판을 수정하지 않는다.

- APP-20260920-01: `contracts/library`와 `domain/library-selection`은 교과서·DAY·학교·모고·수능의 부분 범위와 원행 선택을 소유한다. 원학년과 사용 대상, 시행연도와 학년도는 구분한다.
- `api/admin/wordbook-library`와 `server/queries/library-catalog`, `server/commands/library-command`는 관리자 전용 원범위·템플릿 목록과 저장 경계다. 단어별 제외에 필요한 표제어·뜻·상태만 목록에 포함하고 원자료 전체·발음 근거 원본·문항·정답 위치는 전송하지 않는다.
- 표시정보 수정은 템플릿 revision만 바꾸고 고정 내용 버전을 수정하지 않는다. 범위 변경은 이전 내용 확인값과 revision을 검사하여 새 버전을 만든다. 같은 요청 ID는 같은 완료 결과를 반환한다.
- `contracts/library-import`는 검토 파일·프로젝트에 고정한 서비스 전용 등록 계약이다. 원뜻·품사·발음의 근거와 보류/제외 상태를 유지하며 신규 사전 승인은 하지 않는다. 범위별로 다른 같은 원행의 연결 기록은 함께 보존한다.
- 과거 버전은 원자료가 사용 중지돼도 남긴다. 새 구성에는 현재 사용 가능한 등록판만 허용하며 저장 거래 안에서 원판을 잠그고 확인한다.
- 실제 단어장은 `materialize-composition`이 관리자 요청을 준비하고 기존 생성기로 문항을 만든 뒤 서비스 전용 경계에서 고정한다. `library-resources`는 선택된 값과 출처 증명을 분리해 보존한다. 학생 조회는 저장된 발음을 사용하며 비어 있어도 현재 사전으로 보충하지 않는다.
- 큰 목록과 이전 버전은 권한·계약 검증 뒤 연속 전송한다. 한 서버 요청은 최대4단계만 처리하고, 확인된 진행 응답 뒤 같은 요청으로 이어 만든다. 서버 요청 상한300초와 브라우저295초를 맞추며 통신 결과 미확정은 무조건 재전송하지 않는다. 저장 성공 뒤 화면 연결만 실패하면 확정 결과로 콜백만 재시도한다.

- APP-20260921-04: 현재 화면은 `/api/admin/wordbook-library/query`의 7종 조회와 `/commands`의 v2 요약 응답을 사용한다. 첫 목록20, 세부 범위30, 단어50과 과거 버전을 열 때만 SQL 페이지 조회한다. 기존 전체 조회는 과거 호출 호환용이다.
- `use-library-page`는 검색·선택·관리자·새로고침에 묶인 커서와 요청 취소를, `use-library-command`는 정확한 미확정 요청과 생성 단계 복구를 소유한다. 편집 대상 변경 때 늦은 상세 조회를 취소하고, 권한 오류 후의 늦은 성공으로 화면을 다시 열지 않는다.
- 새 템플릿의 criteria는 순서 있는 filter/fixed 묶음이다. 필터 재사용은 현재 자료를 재계산한 뒤 차이 확인과 새 불변 판 저장을 거친다. 전체 순서를 직접 바꾸면 정확한 fixed 참조로 바꾼다. 제외 단어가 범위에서 빠졌으면 사용자 확인 후 정리한다.
- 템플릿 삭제는 deleted_at/revision만 바꾸며 원자료·생성 책·학생 기록은 유지한다. 새 변경/복사/생성을 차단하되 완료 영수증과 이미 시작한 같은 생성 요청을 먼저 복구한다. 삭제 확인 창에는 이름과 보존 범위를 표시한다.

2026-09-20 MCP 관리 등록(D13): 관리 함수는 실제 postgres 세션만 사용한다. 초기 템플릿은 프로젝트·승인 번호·틀 식별자·명령 전체 SHA가 일치하는 별도 허용 목록을 먼저 대조한다. 작성자는 사용자 UUID로 꾸미지 않고 불변 관리 요청 FK로 기록한다. 기존 public 저장과 편집/새 판/복사 권한은 유지한다.

- APP-20261004-01: 내부 검색은 최신 판의 recipe와 includedKeys만 한 번 꺼내고 포함 범위 분류를 원래대로 조합한다. 메타데이터/제외/최신판/빈 결과/함수 권한을 원형과 대조하며 제목·태그만으로 검색을 축소하지 않는다.
