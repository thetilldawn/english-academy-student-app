# 학생 시험 진행 작업 안내

- APP-20260929-12 자율연습은 `student-word-practice` 흐름이다. `contracts/practice` → `domain/practice-plan` → `server/practice-source|service|http`와 private 연습2표를 사용한다. 정규 배정·응시·오답·큐·포인트는 읽기만 한다. 공통 QuizPlayer의 전송 객체만 바꾸며 기본 경로는 정규 시험이다.
- 연습 시작은 같은 요청의 완료 영수증부터 조회한다. 원천 변경409만 새 미리보기로 돌아가고 결과 불명503은 같은 요청키로 확인한다. 내역 커서는 학생에 묶으며 계정 변경409에서 기존 화면을 폐기한다. 선택 최대500개는 키 필터 한 번, 조건 전체는 최대10,000개이고 초과를 조용히 자르지 않는다. 연습표와 RPC는 서비스 전용이며 실제 학생 시험을 검사 목적으로 만들지 않는다.

- 답 선택은 마지막 유효 입력 뒤20ms가 지나면 한 번만 전송한다. 대기 중 선택 표시는 정오답 피드백과 분리한다.
- 서버가 확인한 정오답은200ms 표시후 자동 이동한다. 표시 중 추가터치/키보드로 건너뛰지 않는다. 답 뒤 자동음성/스킵은 없으며 문제음성·수동스피커는 유지한다. 선택 및 전송 시작 때 현재 음성은 멈춘다.
- 느린 다음 문항 동기화는 서버 준비와20ms 두 조건을 모두 기다린다. 정상 동기화는 선택을 보존하고, 복구·이탈·문항/단계/시험 변경은 이전 예약을 폐기한다.
- 저장 응답 유실은 서버의 같은 문항·단계에 실제 저장된 선택/정오답/시간초과가 확인된 경우만200ms 먼저 보여주고 복원한다. 미답을 추정해서 정오답으로 표시하지 않는다. 정상표시 후 복구에 중복표시하지 않는다.
- 제한시간을 늘리거나 서버 판정을 바꾸지 않는다. 마감 전에 예약한 답을 자동 무응답/만료 요청이 가로채지 않게 하며, 복구 표시 시간도 기존 남은 시간 계산에 포함한다.

- 시험 진행 전체는 `npm run map:flow -- student-quiz-attempt`로 확인한다.
- 답 제출·시간초과·만료는 학생 결과만 바꾸는 것이 아니라 이어지는 배정 큐를 물질화할 수 있다.
  관련 변경이면 `assignment-series`도 함께 확인한다.
- 판정, 점수, 오답, 재시험, 다음 시험 생성은 클라이언트 화면 결과를 신뢰하지 않고 server와 DB에서 검증한다.
- 진행 중 시험의 snapshot과 타이밍은 캐시하지 않는다. 재시도는 같은 답을 두 번 반영하지 않아야 한다.
